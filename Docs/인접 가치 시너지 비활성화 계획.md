# 인접 가치 시너지 비활성화 계획

## 목표와 범위

- 인접한 품목의 가치 증가·감소와 해당 가치 화살표를 잠시 비활성화한다.
- 드래그 중 인접 가치 변화를 예고하는 표시도 끈다.
- 냉장 효과와 냉장 화살표, 동물 효과, 보드 전체 범위 효과는 유지한다.
- 테이블, 상성표, 툴팁과 설명은 수정하지 않는다. 따라서 기존 설명은 일시적으로 실제 동작과 다를 수 있다.
- 기존에 누적된 품목 가치는 되돌리지 않는다. 이 변경 이후의 인접 가치 정산만 중단한다.

## 작업 단계

### 1. 인접 가치 계산 중단

`Assets/Scripts/Runtime/Inventory/PuzzleInventoryValuation.cs`의 `Recalculate`에서 `Adjacent` 규칙을 찾아 `CollectAdjacentEffects`를 호출하는 부분을 주석 처리한다. 복구할 때 해당 부분을 다시 활성화할 수 있도록 기존 로직은 남긴다. `Board` 규칙 수집과 나머지 가치 계산은 그대로 둔다.

완료 조건: 인접 효과가 가치 계산 결과에 들어가지 않아 이후 시간 정산에서 가치 증가와 감소가 발생하지 않는다.

### 2. 인접 가치 표시 중단

`Assets/Scripts/Runtime/UI/PuzzleInventoryPresenter.cs`에서 드래그 중 `CalculateAdjacentSynergyDeltas`와 `ShowAdjacentSynergyPreview`를 호출하는 분기를 중단하고, 해당 경로에서 `HideAdjacentSynergyPreview`를 호출해 기존 미리보기 표시도 정리한다. 다른 드래그 표시와 거래 상태 표시는 유지한다.

`PuzzleInventoryView.RenderSynergies`는 수정하지 않는다. 이 표시는 가치 계산 결과의 접촉 정보에 의존하므로 1단계 이후 인접 가치 화살표가 생성되지 않는다. 별도 경로인 `RenderRefrigeration`은 유지한다.

완료 조건: 배치된 품목의 인접 가치 화살표와 드래그 중 인접 가치 미리보기가 나타나지 않으며 냉장 화살표는 유지된다.

### 3. 현재 상태 문서 정리

`README.md`의 현재 구현 설명 중 인접 가치 효과가 활성 상태라고 단정하는 항목이 있으면 이 임시 변경에 맞게 짧게 갱신한다. 관련 항목이 없으면 문서를 추가로 바꾸지 않는다.

완료 조건: README에 변경된 동작과 모순되는 관련 설명이 남지 않는다.

세 단계는 위 순서대로 한 작업에서 수행한다. 단계별로 별도 승인이나 커밋은 필요하지 않다.

## 완료 기준

- 인접 품목의 가치 증감이 계산 및 시간 정산에 반영되지 않는다.
- 인접 가치 화살표와 드래그 중 인접 가치 미리보기가 표시되지 않는다.
- 냉장 화살표 및 인접 가치 외의 기존 효과는 해당 변경의 영향을 받지 않는다.
- 규칙 데이터와 기존 설명을 보존해 추후 비활성화한 코드를 복구할 수 있다.

프로젝트 작업 지침에 따라 테스트, 플레이 실행 및 검증 실험은 사용자가 별도로 요청한 경우에만 수행한다.
