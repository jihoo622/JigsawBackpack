# 작업 트래커와 기획 대응

프로젝트 원본은 [PENTAGON games](https://app.notion.com/p/kraftonjungle/PENTAGON-games-_-4104c6f37f8c8050b646dbc1068c0ac0), 작업 목록은 [작업 트래커의 모든 작업](https://app.notion.com/p/kraftonjungle/4104c6f37f8c80c49ee4fdd3762d1299?v=4104c6f37f8c8051bda1000ceab22815)을 사용한다. 보드에서는 오래된 완료 티켓을 숨기므로 전체 범위를 확인할 때 모든 작업 보기를 사용한다.

## 반영 원칙과 차이

- 목록에서 40개 행을 확인하고 기차 게임에 관련된 본문 32개와 트래커 가이드를 읽었다. 다른 PoC·발표·제목 없는 항목은 게임 규칙의 근거로 사용하지 않았다.
- 아래 상태는 트래커 표기다. 코드 확인·플레이 검증·수행 완료를 새로 판정한 결과가 아니다. 이번 작업은 문서 수정이며 티켓 상태·담당자·마감일은 변경하지 않았다.
- 맵·아이템 테마·운송비·누적 실제 가치 판매는 기존 기획과 일치한다. 무게 티켓은 실제 질량이 아니라 인벤토리 칸 수에 비례하는 설명이므로 점유 칸 기준 비용을 유지한다.
- 날짜 티켓의 근거리 2~4시간·먼 이동 12시간은 이후 대화에서 확정한 근거리 8시간·옆 지역 1일·먼 직통 2~3일과 다르다. 기획서는 이후 기준을 유지한다. 옛 마을 7개 표도 현재 30개 구성을 대체하지 않는다.
- 시너지 재정립의 기존 효과 표는 당시 기준 자료다. 구상안의 내구도·배설물 효과를 채택 완료로 보지 않는다. 기존 가치 누적 규칙과의 관계를 기획서 11장의 미정 사항으로 남겼다.
- Cargo를 상자로 설명한 옛 티켓은 현재 화물 공통 태그와 상품 테마 상자를 구분한 규칙으로 대체한다.
- 세부 본문이 없는 시너지 피드백·화물칸 간 이동 티켓에는 제목 수준의 목표만 반영한다. 임의의 입력키·효과 수치·완료 기준을 만들지 않는다.
- 싯가 티켓은 가격 증감 표현에 대한 문제 제기뿐이다. 랜덤 시세 공식이나 가치 시너지 제거를 확정하지 않는다.
- 테마·기관차의 부정 사건 감소·검문소·전용칸은 검토안으로, 철도 투자·물건 위치 교환은 후순위로 기술한다.
- 현재 연결된 노션 도구는 해당 페이지 조회에 404를 반환해 Orca 브라우저의 로그인 세션으로 확인·수정했다. 다음 작업도 연결 도구 접근 여부를 확인하고 불가하면 같은 브라우저로 본문을 확인한다.
