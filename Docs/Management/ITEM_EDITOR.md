# 아이템 에디터

- `Tools/MyJG/Item Editor`에서 화물 이름·ID를 검색한다. 목록은 ID 오름차순이며 이름·ID 두 줄과 줄바꿈 길이에 맞춰 행 높이를 늘린다. 품목을 바꿔도 전체 초안이 유지된다.
- 신규 작성은 고유 ID·한 칸 모양·빈 태그로 시작한다. 이름·설명·Sprite를 입력한 뒤 저장한다. 내구도 초깃값은 기초데이터의 내구도 상한을 읽는다. 복제는 기존 정의의 나머지 필드도 보존한다.
- 기존 ID는 읽기 전용이다. 신규·복제 품목은 `excludeFromMarket: true`로 저장하며 시작 객차·고정 재고·재고 프로필·행동 변환에 자동 등록하지 않는다.
- 기본 정보와 Sprite 수정은 `Undo`/`Redo`로 되돌릴 수 있다. Sprite는 프로젝트의 기존 에셋만 선택하며 GUID와 로컬 파일 ID를 함께 보관한다. 공유 이미지 키의 Sprite를 바꾸면 선택한 품목만 새 키를 받는다.
- 가운데 `모양` 도구는 0°에서 클릭·드래그로 셀을 그린다. 빈 셀에서 시작하면 추가하고 기존 셀에서 시작하면 제거하며, 한 번의 드래그는 하나의 Undo로 되돌린다. 좌표는 왼쪽 위 원점, +x 오른쪽·+y 아래다. `slotCount`는 셀 수에서 자동 계산한다.
- 빈 모양·중복 좌표·끊어진 모양·잘못된 원점과 방향 값은 게임과 같은 `GameTableRules.ValidatePieceCells`로 표시하며 저장 검토에서도 거부한다. 첫 행/열을 지운 뒤 최소 좌표가 0이 아니면 `모양을 원점에 맞추기`를 사용한다. 시작 배치·시장 슬롯과의 충돌도 기존 전체 표 검증이 검사한다.
- 0°/90°/180°/270°는 `PuzzleRotation.GetBoardOffset`의 회전 미리보기다. 회전은 원본 셀·저장값을 바꾸지 않는다. 격자 크기 슬라이더 또는 Ctrl+휠로 확대/축소하고 스크롤바·중간 버튼 드래그로 이동한다. `전체 보기`는 모양과 이미지 영역을 함께 맞춘다.
- `이미지 이동` 도구에서 이미지 프레임을 드래그하거나 오른쪽 `iconOffsetX/Y`, `iconWidth/Height`에 대응하는 값을 편집한다. 이미지 오프셋은 회전 전 기준 +x 오른쪽·+y 위다. 회전된 이미지 이동도 원래 오프셋으로 역변환해 저장한다.
- `외접 사각형 크기 사용`은 폭·높이 중 하나라도 미지정인 기존 게임 규칙을 따른다. 고정 크기는 양수이고 `원본 종횡비 고정`은 Sprite 원본 영역의 비율을 사용한다. 초기화는 오프셋 0·자동 크기로 돌아간다. 미리보기 상태·줌·종횡비 고정 선택은 품목 필드에 추가하지 않는다.
- 이미지 중심·회전·크기는 게임의 `RenderPose`와 `PuzzleIconLayout` 계산을 공유한다. Sprite 원본 영역·UV·투명 패딩은 Unity UI의 Simple Image처럼 표시한다. 십자는 이미지 중심, 실선은 지정 크기, 점선은 원본 비율 영역(투명 여백 포함)이다. 프리뷰용 GameObject는 만들지 않는다.
- `셀 고급 속성`에서 셀을 고르고 `north/east/south/west`를 편집한다. 기존 값과 알 수 없는 셀 필드는 보존하고 새 셀은 `Flat`이다. 방향별 연결 효과는 현재 적용되지 않으며 현재 테이블 검증은 `Flat`만 허용한다.
- `품목별 효과`에서 규칙 ID·설명을 검색하고 `받는 대상`/`주는 이웃`을 독립적으로 고른다. 대상·제외 대상·이웃·제외 이웃 태그와 Train/Market 범위·공간 범위·공통 배율은 읽기 전용이다. 양쪽 품목이 반대 역할을 선택하고 태그 조건도 맞아야 가치와 화살표에 반영된다.
- `현재 태그와 효과 조건`에서는 기존 등록 태그를 검색해 선택한다. `새 태그 등록`은 고유 ID·한글 표시명·RGBA 색을 입력하고 선택한 품목에 추가한다. 표시 정의는 `PuzzleTableData.tagPresentations`에 저장하고 게임에서도 `Presentation`이 읽는다. 태그 변경은 역할을 자동 선택하지 않으며 조건이 틀린 역할은 즉시 오류로 표시한다.
- 시작 내구도는 모든 품목에 유효 범위를 저장한다. 유통기한은 Food 등 기초데이터의 신선도 대상 태그에서 편집하며 0시간은 시간 소모 없음이다. 비적용 품목도 저장값과 비활성 이유를 표시한다. 기본 가치는 음수도 허용하며 -1은 기존 누락 판정값이다.
- `성장`에서 성체 ID·성장 시간·공간 확인 시간·설명을 편집한다. `번식`에서는 선택한 품목이 부모 또는 자식인 행의 부모/자식 ID·수량·설명을 편집하고 명시적으로 추가·제거한다. Baby·동물 태그, 시간 관계와 설명 인자는 기존 전체 테이블 검증을 따른다. 번식·배설 공통 시간·수량·산출물은 읽기 전용이다.
- `참조 현황`은 현재 초안의 시작 객차·도시 고정 재고·재고 프로필·행동 변환·성장·번식의 품목 ID와 가격·시너지 등의 태그 참조를 테이블 이름·행 ID·필드 경로로 표시한다. 시장 제외와 기존 시장 참조의 충돌을 표시하며 개조 검사 제외를 켜도 기존 변환은 유지한다. 도시 재고·도축·개조 등록은 원본 테이블에서 편집한다.
- `이미지 키`는 직접 편집할 수 있으며 공유 키의 Sprite 충돌은 저장 검토에서 거부한다. `고급 속성·추가 필드`는 새로 추가된 DTO 필드를 JSON 값으로 편집하고, 알 수 없는 원본 필드는 읽기 전용으로 보존한다. 셀 수는 자동 산출, 셀·아이콘 수치는 모양 도구에서 편집한다.
- `신선 효과 부여`와 감소율 0~100%를 품목별로 편집한다. 활성 여부는 공통 설정의 `Fresh` 태그와 일치해야 하며, 미부여 품목은 비활성·0%로 명시한다. 객차 냉장 감소율과 정산 주기는 공통 설정으로 읽기 전용이다.
- 기존 21개 품목은 태그 조건에 맞는 역할과 보존율을 명시했다. 효과 목록 누락은 오류이고 빈 배열은 효과 없음이다. 이전 데이터는 `기존 태그 효과를 전체 초안에 이행`으로 변환한다. 이행은 품목별 역할·보존율과 모든 품목 쌍/규칙의 변화율을 구 판정과 대조하며, 다른 필드·공통 규칙을 바꾸지 않는다. 이행 결과는 저장 검토에 품목별로 표시하고 Undo로 되돌릴 수 있다. 이미 명시된 효과를 재이행하지 않는다.
- `품목·참조·이미지 오류`와 `저장 검토`는 `GameTableRules`의 동일한 검증을 사용한다. 원본에도 있는 오류와 초안에서 추가된 오류를 나누며 배열 위치 대신 품목·규칙 ID를 기준으로 대조한다. 두 종류 모두 저장을 차단한다. `필드로 이동`은 품목을 선택하고 해당 속성으로 스크롤하며, 셀 오류는 해당 셀을 선택한다. 원본 인벤토리 목록 오류는 `인벤토리 에셋 선택`으로 참조처를 연계한다.
- `저장 검토`는 변경 품목·파일과 외부 변경·미저장 씬 등의 저장 조건 오류도 표시한다. `검토한 내용 저장`에서 원본을 다시 비교한 뒤 반영한다. Sprite 초안의 변경도 즉시 오류 캐시에 반영한다.
- 관련 테이블·인벤토리 프리팹·씬·Sprite 원본이 외부에서 바뀌면 덮어쓰지 않는다. 초안을 내보낸 뒤 다시 읽거나 편집을 계속할 수 있다. 내보내기는 원본 보호를 위해 `Assets` 밖에만 허용한다.
- 플레이·컴파일·에셋 갱신 중에는 저장하지 못한다. 관련 프리팹 편집 모드는 닫아야 하며, 열린 씬에 미저장 변경이 있으면 먼저 정리해야 한다. 창 닫기·다시 읽기는 저장/버리기/취소를 구분한다.
- 저장은 품목·태그 표시 정의와 `PuzzleSynergyTableData.animals.breeding`을 함께 검토·백업하며, 번식 이외의 공통 규칙 변경은 거부한다. 알 수 없는 필드와 다른 품목·도시 데이터를 보존하고 모든 `PuzzleInventoryView`의 아이콘 목록에 반영한다. 사용하지 않는 기존 이미지 키도 유지한다. 초안 내보내기·Undo/Redo·다시 읽기·버리기에 번식 초안도 포함된다.
- 저장 후 표 캐시를 갱신하고 `RequireValid()`로 확인한다. 두 JSON 전체가 초안과 같은지, 모든 관련 View의 이미지 키·Sprite가 초안과 같은지, 사용하지 않는 기존 키의 참조가 보존됐는지를 대조한다. 대조 실패도 저장 예외로 처리해 이번 작업의 파일·메타를 복원하고 변경한 열린 씬을 다시 읽는다. 복구 실패는 경로·오류로 표시하며 초안은 남긴다.
- 현재는 1~5단계 구현과 인계 항목 정리를 마쳤다. Unity 컴파일·실행 확인은 남아 있다.

## 사용자 확인 항목

- 기존 품목의 무변경 저장, 신규 품목의 미출시 저장, 공유 Sprite 분리, 모양·이미지의 네 회전 미리보기와 Undo/Redo.
- 효과 역할 선택·해제, 서로 다른 두 보존율, 기존 소금·냉장 프레임 이행, 잘못된 성장 참조·시장 슬롯보다 큰 모양의 오류 표시와 필드 이동·저장 차단.
- 외부 파일 변경 충돌, 저장 실패 복구, 다른 품목·도시·사용하지 않는 이미지 키 보존, 저장 후 게임의 값·툴팁·화살표·시간 진행 연결.
