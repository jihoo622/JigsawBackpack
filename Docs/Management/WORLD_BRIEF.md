# 세계관 작업 안내

세계관·스토리를 맡는 작업자(다른 세션 포함)가 지금 게임 시스템을 이해하고 설정을 짜도록 돕는 안내서다. 세계관 본문은 [세계관 기획서](<../세계관 기획서.md>), 게임 규칙은 [게임 기획서](<../게임 기획서.md>)가 원본이다. 이 문서는 시스템 쪽 사실과 데이터 위치만 다룬다.

지리·품목 표는 작성 시점의 테이블에서 뽑은 것이다. 지도와 품목은 Map Editor·Item Editor로 계속 바뀌므로 수치를 인용하기 전에 원본 테이블을 다시 확인한다.

## 1. 먼저 읽을 것

1. [세계관 기획서](<../세계관 기획서.md>): 확정 방향과 초안.
2. [게임 기획서](<../게임 기획서.md>) 1·2·3·11장: 목표, 지역, 확장 검토안(술집 의뢰·거래 숙련).
3. 이 문서 2~6장: 이야기가 닿을 수 있는 지점과 제약.
4. [현재 구현 상태](CURRENT_STATE.md): 무엇이 실제로 동작하는지.

## 2. 한 판의 구조 (세계관이 지켜야 할 틀)

- 플레이어는 기차 한 대로 마을을 오가며 화물을 사고판다. 화물은 격자 칸에 모양대로 끼워 싣는다.
- 빚 1,500, 시작 자금 200. 14일(336시간) 안에 **금융마을**에서 직접 '상환'을 누르면 승리, 기한을 넘기면 패배다.
- 출발은 에른아 공업역 고정이다. 재시작하면 모든 상태가 초기화되고 판 사이 연속성은 없다.
- 하루는 06:00 시작, 낮 18시간·밤 6시간(00:00~06:00). 밤에는 시장이 닫힌다.
- 이동은 직접 연결된 역으로만 하며 시간과 운임이 든다. 이동 중 사건은 아직 없다.
- 전투·온라인·기차 운전 시뮬레이션은 범위 밖이다. 이야기에 싸움이나 조작 미니게임을 요구하지 않는다.
- 플레이어 행동은 시장 거래, 화물 배치, 술집(소문·의뢰), 휴식, 이동, 마을 작업대(도축·정제·개조), 화차 구매뿐이다. **대화 선택지 UI는 없다.**

### 이야기에 쓸 만한 지리적 사실

- 공업 마을에서 금융마을로 가는 최단 길은 모두 **헤일하임 → 테라폴 → 이브트 → 메르트 → 금융마을**을 지난다. 헤일하임은 교차로, 메르트는 수도의 관문이다.
- 카르포트가 수도에 가장 가깝다(최단 27시간). 에른아는 35시간, 헤일포드는 41시간이다.
- 해안은 디아안으로, 광산은 라스부르크–트렌포드로 수도와 이어진다. 오스베르–테라카(26시간), 발렌리에–다르트(23시간)는 멀리 도는 장거리선이다.
- 경제 분석 봇의 승리 경로는 헤일하임↔카르포트 왕복에 몰린다([BACKLOG](BACKLOG.md)). 이 축에서 사람이 가장 자주 오간다고 설정해도 자연스럽다.

## 6. 문구를 쓸 때 지킬 규칙

- 화면 문구·색은 `BasicDataTableData`가 원본이고 코드에서는 `Presentation`을 거친다. 코드에 문구를 직접 쓰지 않는다([BASIC_DATA](BASIC_DATA.md)).
- 기존 키의 `{0}`·`{1}` 인자 수와 순서를 바꾸지 않는다. 인자 수를 바꾸거나 키를 추가하면 `Tools/MyJG/Tables/Generate Basic Data Contract`로 계약을 다시 만들어야 검증을 통과한다.
- 품목·작업대 설명은 테이블의 `description`이 원본이고 비우면 테이블 오류다.
- 리치 텍스트(`<b>`, `<color>`)를 쓸 수 있다. 화면 폭이 좁은 곳(지도 역 이름, 상태 줄)은 짧게 쓴다.
- 지금 통화 표기는 화면 `$`, 게임 기획서 "원"이다. 화폐가 정해지면 `$`가 들어간 문구를 함께 바꾼다.
- 술집 말투는 전해 들은 존댓말("~대요")이다.
- 새 테이블이 필요하면 `Trainventory` 접두사를 쓰고 AGENTS.md의 테이블 추가 절차를 따른다.
- 수치(가격·시간·보상)는 세계관 작업에서 바꾸지 않는다. 바꿔야 하면 게임 기획서의 규칙을 함께 고친다.

## 7. 기획서와 데이터가 어긋난 곳

- 게임 기획서는 테라그라드·오스베르를 일반 마을로 적었지만, 데이터에서는 테라그라드가 공업, 오스베르가 광산이고 광산 마을 라스부르크가 더 있다.
- 게임 기획서 3장의 교역 간선·통과 간선(에른아 → 라센턴 → 피오아 항 …)은 지금 노선과 다르다. 지도를 고치며 연결이 바뀌었다. 3장 노선 표가 현재 데이터다.
- 게임 기획서의 귀함은 구매·판매 130%이지만, 도시 데이터의 귀함 행은 구매 150%·판매 130%다.

세계관 문서는 데이터 쪽 사실(3장 노선 표)을 기준으로 쓴다.

## 8. 작업 절차

1. 세계관 결정은 [세계관 기획서](<../세계관 기획서.md>)에 쓴다. 초안을 확정하면 해당 항목을 '확정'으로 옮긴다.
2. 게임 규칙이 바뀌면(예: 세력 기운이 가격을 바꿈) [게임 기획서](<../게임 기획서.md>)를 함께 고치고 노션 동기화 규칙([NOTION_SYNC](NOTION_SYNC.md))을 따른다.
3. 문구만 바꾸는 작업은 테이블 JSON을 고치고 `Tools/MyJG/Tables/Reload Tables`로 검증한다.
4. 구현이 필요한 항목은 [BACKLOG](BACKLOG.md)에 과제로 남긴다.
