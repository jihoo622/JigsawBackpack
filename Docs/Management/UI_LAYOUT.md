# 게임 UI 배치

UI 배치 원본은 프리팹이며 에디터 UI 배치 생성 도구는 폐기되었다. Game 씬 UI는 패널별 프리팹(`Assets/Art/UI/`) 인스턴스이며 배치는 프리팹에서 수정한다.

역 하위 화면의 돌아가기는 상환 가능 여부와 독립적으로 활성화한다. 버튼은 배경색을 직접 저장하고 ColorTint 전환을 명시한다. 상태별 tint는 기초데이터의 절대 색을 배경색으로 나눈 배율이므로 편집 화면과 실행 화면 모두 같은 테마를 유지한다.

UI 오브젝트와 Layout Group은 프리팹에서 배치·저장하며 런타임에 생성하지 않는다. 새 배치는 프리팹에서 직접 수정한다.

| 영역 | 배치 계약 |
|---|---|
| 상단 | 현재 마을·시간·자금·상환·지도 순서. 지도 버튼 폭은 별도로 예약해 다른 Canvas의 버튼과 겹치지 않게 한다 |
| 좌측 본문 | 기차 카드와 화물칸 바. 보드는 카드 중앙, 가치와 조작 안내는 하단에 배치 |
| 우측 본문 | 역 행동 카드. 제목·뒤로 가기와 내용 영역을 나누고 시장·술집·휴식 중 한 내용만 표시 |
| 하단 | 거래/야간/종료 상태 안내. 예측 목적지 선택 버튼은 두지 않음 |
| 우측 소문 로그 | 480×744 접이식 패널. 게임 날짜·시각 - 들은 마을 - 소문 내용을 기록 순서로 스크롤하며 접으면 로그 탭만 유지 |
| 툴팁·모달 | 고정된 툴팁 폭과 줄바꿈, 커서 간격·화면 여백. 지도 < 이동 확인 < 일시정지 순서로 표시 |

- UI 배치(여백·크기·폰트 등)의 원본은 프리팹이다. 전용 배치 수치는 기초데이터에서 제거되었으며, 런타임 수치와 문구·색상은 `Presentation`을 거쳐 기초데이터에서 조회한다.
- CanvasScaler는 1920×1080 기준 Expand 모드다. 최소 기준 영역을 확보하면서 남는 폭/높이를 앵커와 Layout Group이 분배한다. 본문은 같은 폭의 두 열이며 UI 전체 Transform 배율을 축소해 맞추지 않는다.
- 버튼 글자는 부모 영역에 맞춰 늘어나고 내부 여백·자동 글자 크기·줄바꿈·말줄임을 사용한다. 역 행동 버튼의 제목·설명·아이콘은 각각 독립 영역이다.
- 기차 보드는 520×520, 시장 보드는 616×496이다. 보드의 고정 영역을 기준으로 기존 셀 크기·드래그 좌표를 계산한다. 두 보드의 별도 스케일 보정은 없다.
- 화물 아이콘은 원본 종횡비를 유지하고 테이블의 표시 크기 안에 맞춘다. 표시 오프셋도 물품과 함께 회전하며 실제 배치와 드래그 미리보기가 같은 계산을 쓴다.
- `feature/아트리소스`는 화물칸 선택 바에 POC_06 화물칸을 90도 돌려 표시한다. 슬롯 폭/높이와 원본 비율로 그림을 맞추며 숫자·선택/호버 테두리·입력 영역을 유지한다. 실제 퍼즐 보드에는 삽화를 깔지 않는다. 기차 카드 제목 우측에는 기관차 장식을 사전 배치한다.
- 역 행동 아이콘은 시장=화물, 술집=사람, 휴식=벤치, 이동=출발이다. 그림은 입력을 받지 않는다. 지도 이동 연출은 같은 train RectTransform 아래에 측면 열차 RawImage를 저장하고 원본의 왼쪽 방향을 UV 반전해 기존 이동 방향과 맞춘다. 기존 도형 부품은 비활성화해 보존한다.
- 술집은 제목·소식·대화 버튼을 세로 배치한다. 휴식 버튼·설명도 세로 레이아웃을 사용한다. 사용하지 않는 원격 마을 화면은 비활성 상태로 보존한다.
- 툴팁은 현재 적용 효과, 일반 효과, 가능 가치 시너지를 별도 영역에 표시한다. 일반 효과와 가능 가치 시너지는 프리팹에 각각 TMP 슬롯 6개를 배치한다. 슬롯을 넘는 설명은 마지막 슬롯에 줄바꿈해 표시한다. 거래 예상은 모델 견적이며 미방문 마을의 전 품목 배율은 지도에서 숨긴다. 시장의 전 품목 배율 안내를 위해 정보 영역 높이와 보드 위쪽 여백을 함께 조정했다.
- 소문 로그는 전체 화면 덮개 없이 우측 패널만 입력을 받는다. 지도보다 위, 이동 확인/일시정지보다 아래에 표시한다. 로그 위 휠은 지도 줌을 막는다.
- 지도 지명과 역의 대응은 노드별 LabelConnector로 표시한다. 이름/배지의 실제 크기·역 테두리·안내선을 함께 예약하며, 공간이 없어도 서로 겹쳐 강제 표시하지 않는다. 안내선은 프리팹에 사전 배치한 Image를 사용하고 입력을 가로채지 않는다. 지도 이름·시간 배치 및 줌·우선순위 원본은 지도 프리팹(`Assets/Art/PuzzleWorldMap.prefab`) 컴포넌트이며 연결은 [MAP](MAP.md)의 지명과 역의 대응을 따른다.
- 지도 축소 시 지역별 핵심 역을 우선하고 확대 시 일반 역명을 추가한다. 현재/호버 상태와 도시 중요도·지역 가중치, 같은 지역에서 이미 표시한 이름 수를 함께 사용한다. 핵심 역의 굵기/폰트와 줌 기준, 상태 가산점은 지도 프리팹(`Assets/Art/PuzzleWorldMap.prefab`)의 `PuzzleMapView` 컴포넌트가 소유한다.
- 툴팁과 모달은 의도적으로 본문 위에 표시한다. 툴팁은 인벤토리 카드 밖의 Canvas 좌표를 사용하고 입력을 가로채지 않는다. 긴 툴팁의 전체 높이·화면별 가독성은 플레이 확인 대상으로 남긴다.

플레이·검증용 입력·캡처는 실행하지 않았다. 실제 해상도별 화면과 시장/술집/휴식 전환 확인은 사용자 확인 대상이다.
