# 게임 UI 배치

`feature/improve_layout`에서 구현 중인 목표 배치. 구현·확인이 끝난 항목은 표시한다. (지금은 아무것도 구현되지 않았다.)

UI 배치 원본은 프리팹이며 Game 씬 UI는 패널별 프리팹(`Assets/Art/UI/`) 인스턴스다. 배치는 프리팹에서 수정하며 런타임에 UI 오브젝트와 Layout Group을 동적 생성하지 않는다. CanvasScaler는 1920×1080 기준 Expand 모드를 유지한다.

---

## 1. 설계 원칙

- **세 축**: 화면은 **왼쪽 백팩**(선택한 화물칸의 짐), **아래 기차**(화물칸 바), **오른쪽 도착지**(지금 역에서 할 일과 다음에 갈 곳)의 세 축으로 나눈다.
- **고정 UI**: 상태 안내, 화물칸 바, 정보 바, 화물칸 바 양옆 버튼(상성표 보기, 지도)과 다음 정산 게이지는 고정 UI로, 일시정지 외 어떤 화면(지도·이동 확인·이동 연출·수첩·상성표)에도 가려지지 않는다.
- **지도는 도착지 축만 교체**: 지도는 다음 목적지를 고르는 도구이므로 도착지 축(우측 패널) 전체를 바꾼다. 지도를 열어 둔 상태에서도 백팩과 기차가 상시 노출되며, 기차 보드 입력과 툴팁이 동작한다.
- **소문·의뢰**: 도착지 축 상단 요약 띠(2칸)에 상시 노출되며, 전체 기록은 우측 접이식 수첩(소문/의뢰 탭)에서 확인한다.
- **상성·정산**: 화물칸 바 왼쪽 버튼(상성표 보기)과 다음 정산 게이지에 배치한다.

## 4. 보드 규격 및 드래그 거리

- **셀 크기 통일**: 기차·시장·도축·개조의 4개 보드 셀 크기를 **97.6px**로 일치시킨다.
  - 기차 보드: 5×5 (488×488px, left 64, top 270)
  - 시장 보드: 7×6 (683.2×585.6px, left 624, top 221)
  - 도축 보드: 3×3 (292.8×292.8px, left 624, top 368)
  - 개조 보드: 3×3 (292.8×292.8px, left 624, top 368)
- **보드 중심 높이 맞춤**: 모든 보드의 수직 중심 좌표를 **Y = 514px**로 일치시켜 수평 드래그 동선을 최적화한다.
  - 기차 보드 중심: (308, 514)
  - 시장 보드 중심: (965.5, 514)
  - 도축·개조 보드 중심: (770.5, 514)
- **드래그 거리 단축**:
  - 시장 ↔ 기차 보드: 약 **658px** (기존 약 933px 대비 약 275px 단축)
  - 도축·개조 ↔ 기차 보드: 약 **462px** (기존 약 933px 대비 약 471px 단축)
  - 화차 상점 카드 1(789, 716) ↔ 다음 빈 슬롯(874, 936): 약 **236px** (기존 약 1,000px 대비 대폭 단축)

## 5. 겹침 순서 (Z-order)

화면 계층은 아래 순서로 배치된다 (오른쪽이 위):

```
도착지 본문 < 지도 (도착지 축 교체) < 이동 확인·연출 < 접이식 수첩 < 상성표 크게 보기 < 고정 UI < 일시정지
```

- **고정 UI**: 상태 안내, 화물칸 바, 정보 바, 양옆 버튼(상성표 보기, 지도) 및 정산 게이지는 지도·수첩·상성표보다 위에 그려져 상시 노출된다. 유일하게 일시정지(전체 화면 모달)에 의해서만 덮인다.
- **툴팁**: 인벤토리 카드 밖 Canvas 좌표를 사용하며, 본문 위뿐만 아니라 지도 위에서도 표시된다. 입력을 가로채지 않으며 드래그 중에는 숨긴다.

## 6. Esc 키 입력 우선순위

Esc 입력 시 다음 순서로 최상위 상태부터 순차 취소·닫기를 수행한다:

1. **이동 확인 취소**: 이동 확인 창을 닫고 지도 화면으로 복귀
2. **드래그 취소**: 잡고 있던 화물을 원래 위치로 반환
3. **상성표 크게 보기 닫기**: 열려 있는 상성표 모달 닫기
4. **지도 닫기**: 지도를 닫고 직전 역 본문 화면으로 복귀
5. **수첩 닫기**: 펼쳐진 수첩 패널을 접음
6. **역 하위 화면 복귀**: 시장·화차 상점·술집·휴식·도축·개조·정제에서 행동 목록으로 복귀 (단, 도축·개조·정제 작업대 보드에 화물이 남아있으면 안내를 띄우고 퇴장을 거부)
7. **일시정지 메뉴**: 열려 있는 화면이 없으면 일시정지 모달 호출

## 7. 새 표시 요소 목록

모든 항목은 이번 `feature/improve_layout` 작업의 목표 사양이다:

- **요약 띠 [목표]**: 도착지 축 상단에 소문 요약(최대 2줄)과 진행 중 의뢰 요약(최대 3건)을 상시 표시하고 '전체 보기' 클릭 시 수첩을 연다.
- **다음 정산 게이지 [목표]**: 화물칸 바 좌측 상단에 6시간 단위 주기 진행 막대와 다음 정산 시 예상 가치 변동(±n)을 표시한다.
- **잠긴 화물칸 [목표]**: 화물칸 바의 미보유 슬롯(4~8번)을 잠김 상태로 사전 배치하고, 화차 상점에서 드래그 타깃으로 유도한다.
- **화차 상세·증감치 [목표]**: 화차 상점에서 상품 선택 시 우측 영역에 상세 스펙 및 현재 편성 대비 증감치(보유 칸 +1, 적재 칸 +25 등)를 표시한다.
- **의뢰 상세·화물 모양 [목표]**: 술집 의뢰 게시판에서 선택한 의뢰의 목적지·기한·보상 및 의뢰 화물의 5×5 미니 격자 모양을 우측 영역에 미리보기로 제공한다.
- **지도 노드 태그·배지·이동 미리보기·경로 색칠 [목표]**: 지도 노드에 특산품 태그 칩, 소문 '?' 배지, 의뢰 목적지 깃발을 달고, 노드 호버 시 이동 미리보기 카드를 띄우며 이동 경로 선로를 강조 색칠한다.
- **드래그 보조 표시 [목표]**: 화물 드래그 시 회전 전 원래 자리 점선 표시, 놓을 자리 슬롯 하이라이트, 인접 상성 변화 칩(±n%)을 표시한다.
- **툴팁 미니 격자 [목표]**: 화물 툴팁 상단에 화물 외형을 나타내는 5×5 미니 격자와 분류 태그 칩을 표시한다.

## 8. 기존 유효 기술 규칙 유지

기존 UI_LAYOUT에서 유효한 기술 및 렌더링 계약은 그대로 계승한다:

- **버튼 Tint**: 버튼은 배경색을 직접 저장하고 ColorTint 전환을 명시한다. 상태별 tint는 기초데이터의 절대 색을 배경색으로 나눈 배율을 적용해 일관된 테마를 유지한다.
- **화물 아이콘 종횡비**: 원본 종횡비를 유지하며 테이블 표시 크기 안에 맞춘다. 표시 오프셋도 물품과 함께 회전하여 실제 배치와 드래그 미리보기가 동일한 계산을 공유한다.
- **지도 지명-역 대응 안내선**: 노드별 `LabelConnector`로 지명과 역을 연결한다. 안내선은 프리팹에 사전 배치한 Image를 사용하고 입력을 가로채지 않으며, 공간 부족 시 강제 표시하지 않는다.
- **지도 줌 단계별 라벨 노출**: 지역 `mapLabelPriority` + 역 `mapLabelImportance` + 상태 가산점을 합산하여 핵심 역을 우선 노출한다. 줌/폰트 기준은 지도 프리팹(`Assets/Art/PuzzleWorldMap.prefab`)의 `PuzzleMapView`가 소유한다.
- **툴팁 슬롯 풀 및 표기 규칙**: 현재 적용 효과(실제 적용 중인 시너지·보존 효과), 일반 효과(동물 고유 효과 및 하단 구분선), 가능 인접 효과(주는 효과 우선 → 받는 효과, 그룹 내 이점 우선 정렬) 영역에 각각 프리팹 TMP 슬롯 6개를 사전 배치하고, 초과 설명은 마지막 슬롯에 줄바꿈으로 처리한다. 지칭은 '물품' 구분을 적용하며, 미방문 마을의 전 품목 배율은 지도에서 숨긴다.
- **역 행동 뒤로 가기**: 상환 가능 여부와 독립적으로 항상 활성화한다.

## 9. 미확인 사항 (플레이 확인 대상)

- **해상도별 화면 검증**: 1920×1080 외 해상도/비율에서 Expand 모드 적용 시 레이아웃 요소 간 간격 및 앵커 동작 실기 확인 필요.
- **지도 뷰포트 축소 체감**: 지도 뷰포트가 기존 1824×624에서 1232×580으로 줄어듦에 따른 노선 탐색성 및 한 화면 가시 역 수 감소 체감 확인 필요.
- **하단 정보 바 간섭 여부**: 정보 바가 화면 하단(top 1004)에 배치됨에 따라 창 모드 OS 작업 표시줄 및 스팀 오버레이 알림(우하단 기본값)과의 겹침/간섭 체감 확인 필요.
