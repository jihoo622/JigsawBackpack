# 게임 UI 배치

feature/improve_layout에 구현됨. 플레이 확인 전

UI 배치 원본은 프리팹이며 Game 씬 UI는 패널별 프리팹(`Assets/Art/UI/`) 인스턴스다. 배치는 프리팹에서 수정하며 런타임에 UI 오브젝트와 Layout Group을 동적 생성하지 않는다. CanvasScaler는 1920×1080 기준 Expand 모드를 유지한다.

## 0. 프리팹 구성과 동시 편집 규칙

feature/ui-prefabs에서 단일 `GameplayLayout.prefab`(12.8MB)을 화면·부품 단위 중첩 프리팹으로 나눴다. 플레이 확인 전.

| 구분 | 프리팹 | 내용 |
|---|---|---|
| 씬 UI 묶음 | `UI/Scene/GameUI` → `GameCanvas` · `PuzzleWorldMap` · `PauseCanvas` · `UIEventSystem` | Game 씬의 UI 루트. 씬에는 카메라·조명·볼륨(씬 오브젝트)과 `GameUI` 인스턴스만 있다. 캔버스 사이 참조(일시정지 ↔ 입력, UI 입력 모듈)는 `GameUI`가 보관한다 |
| 본문 캔버스 | `UI/Scene/GameCanvas` | `Inventory Canvas`(Presenter·입력)와 그 아래 패널 인스턴스(`GameplayLayout`·`City Navigation`·툴팁·수첩·상성표 등). `City Navigation` → 술집·휴식 참조를 보관한다 |
| 껍데기 | `UI/GameplayLayout.prefab` | 좌측 기차 열(`Train Inventory`)·역 제목/뒤로 가기/구분선과 아래 화면 인스턴스를 배치만 한다 |
| 역 화면 | `UI/Station/StationActions` · `WagonShop` · `Rest` · `Tavern` · `RumorSummary` · `QuestSummary` | 행동 목록, 화차 상점, 휴식, 술집(의뢰 게시판·상세 포함), 소문/의뢰 요약 띠 |
| 작업대 | `UI/Workbench/Workbench`(원본) → `Butchery` · `Modification` · `Refining`(변형) | 3×3 보드·확인 버튼·정보 열 공통 구조. 개조는 개조 모드 버튼과 신선도 글자를 변형에 추가 |
| 하단 | `UI/Bottom/FixedBottomBar` | 화물칸 바·수첩/지도 버튼 |
| 부품 | `UI/Components/UIButton` · `HeaderButton`(UIButton 변형: 닫기·뒤로·접기 136×36, 라벨 16pt) · `ActionCard` · `WagonProductCard` · `QuestOfferSlot` · `WagonSlot` | 라벨 1개 버튼, 행동 카드 9장, 화차 상품 카드 2장, 의뢰 슬롯 2개, 화물칸 슬롯 8개 |

- 한 사람이 한 프리팹을 맡는다. 화면을 고칠 때는 해당 화면 프리팹을 Prefab Mode로 열어 수정하고, 상위(`GameplayLayout`·씬)에서 인스턴스를 고쳐 오버라이드를 만들지 않는다. 상위에 남는 오버라이드는 인스턴스 루트 위치와 인스턴스별 문구·아이콘·색뿐이다.
- 공통 모양(버튼 라벨 크기·패딩·전환 색 배율, 카드 내부 배치)은 부품 원본에서 고치면 모든 인스턴스에 전파된다. 인스턴스에서 같은 값을 고치면 전파가 끊긴다.
- 씬(`Game.unity`)에는 UI 오브젝트와 오버라이드를 두지 않는다. UI 추가·수정은 `GameUI`/`GameCanvas` 이하 프리팹에서 하고, 화면 간 참조는 둘 다 담는 가장 가까운 상위 프리팹(`GameCanvas`·`GameUI`)에 저장한다.
- 병합 충돌 완화: `.gitattributes`는 `*.prefab`·`*.unity`를 `unityyamlmerge`로 지정한다. 각자 로컬 git에 드라이버를 등록해야 동작한다.
  - `git config merge.unityyamlmerge.name "Unity SmartMerge"`
  - `git config merge.unityyamlmerge.driver "'C:/Program Files/Unity/Hub/Editor/6000.3.22f1/Editor/Data/Tools/UnityYAMLMerge.exe' merge -p %O %B %A %A"`
  - `git config merge.unityyamlmerge.recursive binary`
- `Tools/MyJG/Item Editor` 저장은 `PuzzleInventoryView`가 든 프리팹(작업대 원본·변형, `GameplayLayout` 포함)의 아이콘 참조를 다시 저장한다. 다른 사람이 같은 프리팹을 편집 중이면 저장을 미룬다.

## 0-1. 글자·간격 규격

UI 글자는 모두 TextMeshPro(`NotoSansKR-Medium SDF`)를 쓴다(구형 `UnityEngine.UI.Text` 금지). 외곽선이 필요하면 uGUI `Outline` 효과 대신 TMP 외곽선 머티리얼을 쓴다. 글자 크기는 6단계만 쓴다. 줄임표·자르기 모드 글자는 상자 높이가 한 줄 높이(14pt 20.3, 16pt 23.2, 20pt 29)보다 작으면 통째로 숨겨지므로 줄 상자는 그 이상으로 둔다. 자동 크기(autosize)를 켠 글자는 최대 = 단계값, 최소 = 한 단계 아래로 둔다.

| 단계 | 크기 | 쓰임 |
|---|---|---|
| Display | 32 | 모달 제목(이동 확인·이동 연출·일시정지) |
| Title | 24 | 화면 제목(역 이름·수첩·지도·기차 카드), 정보 바 본문, 큰 버튼(높이 56 이상, 한 줄) 라벨, 툴팁 품목명 |
| Subtitle | 20 | 패널·섹션 제목(정보 열·술집·안내), 행동 카드 제목, 중간 버튼(높이 40~55)·두 줄 버튼 라벨, 화물칸 번호, 수치 강조 |
| Body | 16 | 본문·설명·행 글자, 작은 버튼(40 미만) 라벨, 지도 범례, 툴팁 본문 |
| Caption | 14 | 보조 안내·칩·요약 띠 머리표·진행 수치 |
| Micro | 12 | 배지 숫자 |

- 화면 세로 띠(정보 바·상태 안내·두 열·하단 고정 UI) 사이와 위아래 끝은 16으로 통일한다. 자금·시간·상태 같은 HUD는 위, 화물칸 바·정산·지도 버튼은 아래에 둔다.
- 간격은 8pt 그리드(4·8·16·24·32)를 쓴다. 화면 바깥 여백 40·카드 안쪽 패딩 24·섹션 사이 16·같은 묶음 항목 사이 8·글자와 아이콘 사이 4~16.
- 정보 열(525×644)은 패딩 24, 제목 줄 32(top 24), 제목-본문 8, 줄 32 + 간격 8. 같은 열의 글자는 왼쪽 시작선을 공유하고 수치는 오른쪽 정렬, 버튼 라벨은 가운데 정렬이다.
- 보드 셀(97.6)과 보드 기준 열 폭(683·525)은 보드 정렬 계약(§4)이라 그리드 예외다. 지도 내부(역명·시간 라벨)는 줌 역배율 보정 대상이라 지도 프리팹의 `PuzzleMapView` 값이 원본이다.
- 테이블 리치 텍스트의 절대 크기(`<size=n>`)도 같은 단계를 쓴다. 비율 크기(`<size=75%>` 등)는 기준 글자에 따라 달라지므로 유지한다.

## 0-2. 고유명사 하이퍼링크 (FM식)

플레이 확인 전.

- **대상**: 도시·지역·품목·태그·의뢰. 링크 ID는 `<종류>:<테이블 ID>`(예 `city:city.erna`, `item:piece.apple`, `tag:Metal`, `quest:12`, `region:region.mine`)이며 만들기·읽기는 `Presentation.EntityLink`/`TryParseEntityLink` 한 곳이다. 링크 글자색은 도시·지역은 그 지역 노선 색, 품목·태그·의뢰는 `presentation.link.color`(`Presentation.EntityLinkTextColor`). 마우스를 올리면 도시·지역은 지역 색을 `presentation.link.regionHoverLighten`만큼 밝게, 나머지는 `presentation.link.hover`로 바뀐다.
- **링크가 들어가는 문구**: 소문 문구(술집·소문 기록·소문 요약 띠), 소문 기록의 들은 마을, 의뢰 화물·목적지·지역 불이익(게시판·의뢰 기록·의뢰 요약 띠·상태 안내·지도 정보), 지도 도시 정보의 지역, 정보 바 현재 마을·지역, 상태 안내의 거래 품목·숙련 레벨 상승 태그. 툴팁은 입력을 받지 않으므로 링크를 넣지 않는다.
- **입력**: 링크가 들어가는 TMP에는 `TextLinkHandler`를 붙이고 `raycastTarget`을 켠다(수첩 소문/의뢰 본문, 술집 소식, 의뢰 슬롯 설명, 요약 띠 줄, 지도 도시 정보, 정보 바 현재 마을, 상태 안내 줄 — 상태 안내 캔버스에 GraphicRaycaster 추가). 링크가 아닌 곳의 누름·클릭은 부모 버튼으로 넘긴다. 화물을 끄는 중에는 반응하지 않는다.
- **클릭(대표 화면)**: 도시 → 지도 열고 그 역을 가운데·선택, 지역 → 지도 전체 보기 후 그 지역 중심, 품목 → 수첩 상성표 탭에서 품목 줄과 태그 행·열 강조, 태그 → 상성표 탭에서 그 태그 행·열 강조, 의뢰 → 수첩 의뢰 탭. 이동 규칙은 `EntityLinkNavigation`, 클릭 수신·이동 기록은 `GameCanvas`의 `EntityLinkRouter`(기록은 씬 로컬 `EntityLinkHistory`).
- **마우스 오버 미리보기**: `UI/Components/EntityPreviewCard`(별도 Canvas 272, 입력 없음, 폭 320, 제목 20pt + 줄 4개 16pt, 커서 오른쪽 아래에 두고 화면 밖이면 반대쪽). 내용: 도시(지역·이동 시간과 운임·방문 여부), 태그(받는 시너지 최대 4), 의뢰(남은 기한·보수), 지역(역 수·특산). 도시·지역 카드 제목은 지역 색. 판매 배율·판매 우대 같은 시세 정보는 미리 보여 주지 않는다.
- **아이템 정보 팝업**: 품목 링크에 마우스를 올리면 미리보기 카드 대신 `UI/Components/ItemInfoPopup`(Canvas 272, 입력 없음, 폭 360, 안쪽 16·간격 8)을 띄운다. 이름 20pt 굵게 → 태그 칩 최대 3(14pt, 태그 색) → 설명 16pt(테이블 `description`) → 구분선 → 수치 줄 최대 3(이름 14pt·값 16pt 굵게: 기본 가치·크기·보관 기한) → '옆에 두면' 14pt + 상성 줄 4(기차 상성표에서 이 품목이 받는 인접 배율 합, 넘치면 '외 N개'). 화물 종류의 고정 정보만 보이고, 칸에 놓인 화물의 현재 가치·신선도는 화물 툴팁이 맡는다.
- **우클릭**은 화물을 잡았으면 회전하고 그 외에는 닫기·행동 목록 복귀를 한 단계 처리한다. 고유명사 링크 위에서도 같은 규칙을 적용한다.
- **분석 로그**: `entity_link_clicked`(kind·id·action=click/context, `PLAY_LOG.md`).

## 1. 설계 원칙

- **세 축**: 화면은 **왼쪽 백팩**(선택한 화물칸의 짐), **아래 기차**(화물칸 바), **오른쪽 도착지**(지금 역에서 할 일과 다음에 갈 곳)의 세 축으로 나눈다.
- **고정 UI**: 정보 바(시간·정산 표시 포함)·상태 안내(화면 위), 화물칸 바, 화물칸 바 양옆 버튼(수첩, 지도)은 고정 UI로, 일시정지 외 어떤 화면(지도·이동 확인·이동 연출·수첩·상성표)에도 가려지지 않는다.
- **지도는 도착지 축만 교체**: 지도는 다음 목적지를 고르는 도구이므로 도착지 축(우측 패널) 전체를 바꾼다. 지도를 열어 둔 상태에서도 백팩과 기차가 상시 노출되며, 기차 보드 입력과 툴팁이 동작한다.
- **지도 표기**: 역 이름은 보통·주요 16pt(주요는 굵게), 축소 시 14pt, 현재 위치·상환 목표 20pt, 상태 배지 14pt(지도 프리팹 `PuzzleMapView` 값이 원본). 현재 위치는 금색(`presentation.map.current`), 상환 목표는 산호색(`presentation.map.targetMarker`)으로 고리·후광·이름·배지를 구분한다. 지도 머리: 제목 24pt(폭 184) 오른쪽에 안내 문구 `Guide` 14pt 최대 두 줄(224~768, 폭 544, 줄 간격 −4), 그 오른쪽에 검색 칸 `MapSearch`(784, 14, 320×36, 입력 16pt, 최대 24자). 결과 목록 `SearchResults`는 칸 바로 아래(+40)로 펼치는 폭 320 카드(안쪽 4·간격 2): 결과 슬롯 6개(높이 36, 이름 16pt·종류 14pt·'경로' 버튼 64×28) + '외 N개'/'결과 없음' 14pt. 지도 패널의 마지막 자식이라 계획 창·범례 위에 그린다. 경로 계획 창 `RoutePlan/Card`는 지도 화면 오른쪽 위(920, 128, 폭 320, 높이는 내용에 맞춤, 안쪽 16·간격 8)에 겹친다: 제목 20pt 굵게, 요약·경고 14pt, 거치는 역 슬롯 8개(높이 28: 정차 토글 20 + 역 이름 16pt(지역 색) + 정차/통과 14pt), '외 N개 역' 14pt, 버튼 줄 36(자동 이동·중지·계획 취소, 공용 `UIButton` 16pt). 계획 경로는 노선도에서 금색으로 칠한다(`HighlightPath`). , 그 아래 범례 줄 `MapLegend`(40)은 전체 폭에 항목 `Legend_<지역>`(색 막대 20×6 + 8 + 이름 16pt 한 줄)을 간격 24로 왼쪽부터 나란히 둔다(가로 레이아웃 그룹이 글자 폭에 맞춤). 줌이 `regionLabelMaxZoom`(0.85, 지도 프리팹 `PuzzleMapView`)보다 작으면 역 이름 대신 지역명(`RegionLabel_<지역>` 20pt 굵게, 지역 색, 뒤에 어두운 판 `RegionPlate_<지역>`, 사전 배치 7개, 외곽선 없는 기본 머티리얼)을 띄우고, 역 이름은 현재 위치·상환 목표·의뢰 목적지·선택 역만 남긴다. 지역명은 남은 역 이름을 먼저 놓은 뒤, 그 지역 역들의 가운데에서 8방향으로 16px씩 최대 240px까지 넓혀 가며 역 표식·이름·연결선과 겹치지 않는 첫 자리에 두고, 자리가 없으면 숨긴다. 역에는 이름만 쓰고(판매·수요 칩 없음), 이름 뒤에 이름 상자와 같은 크기의 어두운 판 `LabelPlate`(`presentation.map.labelPlate`, 검정 72%)을 깐다. 노선 이동 시간 라벨은 14pt·높이 20이며 넘침 처리는 Overflow다(Truncate면 한 줄 높이 20.3보다 작아 글자가 통째로 숨는다).
- **소문·의뢰**: 도착지 축 상단 요약 띠(2칸)에 상시 노출되며, 전체 기록은 우측 접이식 수첩(소문/의뢰/숙련 탭)에서 확인한다. 수첩은 하단 지도 버튼 아래 '수첩' 버튼과 화면 오른쪽 가장자리 손잡이(위아래로 옮길 수 있음)로 열고 닫는다.
- **숙련·평판**: 평판은 정보 바에, 태그별 숙련 레벨은 기차 카드 칩에 상시 노출하고, 세부(경험치·이득·다음 평판 단계)는 수첩 숙련 탭에서 본다. 칩·평판 칸을 누르면 수첩 숙련 탭이 열린다.
- **상성·정산**: 상성표는 수첩의 '상성표' 탭(넓게 펼침)에서 보고, 다음 정산은 정보 바 시간 칸의 하루 막대에서 함께 본다.

## 5. 겹침 순서 (Z-order)

화면 계층은 아래 순서로 배치된다 (오른쪽이 위):

```
도착지 본문 < 지도 (도착지 축 교체) < 이동 확인·연출 < 접이식 수첩 < 상성표(수첩 상성표 탭 내용) < 지도 이동 미리보기
  < 고정 UI < 드래그 고스트 < 화차 드래그 미리보기 < 화물 툴팁 < 일시정지
```

| 순서 | Canvas (경로) | 원본 프리팹 | sortingOrder | GraphicRaycaster |
|---|---|---|---|---|
| 본문 | `Game UI/Inventory Canvas` | `GameCanvas` | 0 | 있음 |
| 지도 | `PuzzleWorldMap` (루트) | `PuzzleWorldMap` | 100 | 있음 |
| 이동 확인·연출 | `PuzzleWorldMap/MapPanel/MapTravelPanel` | `PuzzleWorldMap` | 200 | 있음 |
| 수첩 | `Inventory Canvas/RumorLogPanel` | `PuzzleTradeNotebook` | 210 | 있음 |
| 상성표(수첩 탭 내용) | `Inventory Canvas/PuzzleSynergyChart` | `PuzzleSynergyChart` | 220 | 있음 |
| 지도 이동 미리보기 | `.../MapViewport/TravelPreviewCard` | `PuzzleWorldMap` | 230 | 없음 (표시 전용) |
| 고정 UI | `FixedBottomBar`, `City Navigation`, `JourneyFooter` | `GameplayLayout` 등 | 250 | 있음 (`JourneyFooter`는 없음) |
| 드래그 고스트 | `.../Train Inventory/Drag Ghosts`, `.../Market Inventory/Drag Ghosts` | `PuzzleInventoryUI` | 260 | 없음 |
| 화차 드래그 미리보기 | `FixedBottomBar/WagonProductDragPreview` | `GameplayLayout` | 265 | 없음 |
| 화물 툴팁 | `Inventory Canvas/PuzzleItemTooltip` | `PuzzleItemTooltip` | 270 | 없음 |
| 링크 미리보기·아이템 정보 | `Inventory Canvas/EntityPreviewCard`, `ItemInfoPopup` | `EntityPreviewCard`, `ItemInfoPopup` | 272 | 없음 |
| 링크 우클릭 메뉴 | `Inventory Canvas/EntityContextMenu` | `EntityContextMenu` | 280 | 있음 |
| 일시정지 | `Game UI/Pause Menu Canvas` | `PauseCanvas` | 300 | 있음 |

- 값은 모두 프리팹 원본이며 씬 오버라이드를 두지 않는다. 중첩 Canvas는 `overrideSorting`을 켠다.
- 캔버스 분리는 유지한다(통합하지 않는다). 지도 이동·확대, 수첩 스크롤, 툴팁·드래그 고스트처럼 자주 바뀌는 요소가 수천 개 보드 슬롯이 있는 본문 캔버스의 재배치를 일으키지 않게 하고, 겹침 순서를 계층 위치와 무관하게 각 프리팹의 `sortingOrder`로 고정하기 위해서다.
- **고정 UI**: 정보 바(시간·정산 표시 포함)·상태 안내(화면 위), 화물칸 바, 양옆 버튼(수첩, 지도)은 지도·수첩·상성표보다 위에 그려져 상시 노출된다. 덮는 것은 드래그 중 표시(고스트·화차 미리보기)와 툴팁, 일시정지뿐이다.
- **표시 전용 Canvas**: 지도 이동 미리보기·드래그 고스트·화차 드래그 미리보기·툴팁 Canvas에는 `GraphicRaycaster`를 두지 않아 클릭과 호버를 가로채지 않는다.
- **지도 이동 미리보기**: 카드 앵커는 뷰포트 좌상단이며 카드는 뷰포트 안으로 고정된다. 펼친 수첩·상성표보다 위, 고정 UI보다 아래다.
- **툴팁**: 인벤토리 카드 밖 Canvas 좌표를 사용하며, 본문 위뿐만 아니라 지도·수첩·고정 UI 위에서도 표시된다. 입력을 가로채지 않으며 드래그 중에는 숨긴다.

## 6. Esc 키 입력 우선순위

Esc 입력 시 다음 순서로 최상위 상태부터 순차 취소·닫기를 수행한다:

-1. **지도 검색 칸**: 입력 중이거나 결과가 열려 있으면 비우고 닫고 포커스 해제
0. **고유명사 우클릭 메뉴 닫기**: 열려 있으면 먼저 닫기
1. **이동 확인 취소·자동 이동 중지**: 이동 확인 창을 닫고 지도 화면으로 복귀. 자동 이동 중이면 달리는 구간을 마친 뒤 그 역에 정차
2. **드래그 취소**: 잡고 있던 화물을 원래 위치로 반환
3. **상성표 탭 닫기**: 수첩 상성표 탭이 열려 있으면 상성표와 수첩을 함께 접기
4. **지도 닫기**: 지도를 닫고 직전 역 본문 화면으로 복귀
5. **수첩 닫기**: 펼쳐진 수첩 패널을 접음
6. **역 하위 화면 복귀**: 시장·화차 상점·술집·휴식·도축·개조·정제에서 행동 목록으로 복귀 (단, 도축·개조·정제 작업대 보드에 화물이 남아있으면 안내를 띄우고 퇴장을 거부)
7. **일시정지 메뉴**: 열려 있는 화면이 없으면 일시정지 모달 호출

마우스 뒤로가기 버튼(`UI/Back`)과 일반 우클릭(`UI/RightClick`)은 닫을 화면이 있을 때 같은 순서로 한 단계씩 처리한다. 화물을 잡고 있을 때의 우클릭은 회전에 사용한다. 우클릭은 누름에만 반응하고 같은 프레임의 뒤로가기 입력은 한 단계로 합친다.

## 7. 새 표시 요소 목록

모든 항목은 이번 `feature/improve_layout` 작업에서 구현 완료되었다 (플레이 확인 전):

- **요약 띠 [구현됨]**: 도착지 축 상단에 소문 요약(최대 2줄)과 진행 중 의뢰 요약(최대 3건)을 상시 표시하고, 띠를 누르면 수첩의 해당 탭(소문/의뢰)을 연다. 별도 '전체 보기' 버튼은 없으며 호버 시 띠가 밝아진다.
- **다음 정산 표시 [구현됨]**: 정보 바 시간 칸의 하루 막대에 정산 시각 눈금·이번 주기 진행 띠를, 옆 글자에 남은 시간과 예상 가치 변동(±n)을 표시한다.
- **잠긴 화물칸 [구현됨]**: 보유하지 않은 칸은 표시하지 않음. 화차 카드를 드래그하는 동안에만 다음 빈 칸에 테두리 힌트를 띄운다. 힌트와 보유 칸 선택 표시는 같은 `HighlightBorder`(속이 빈 9-slice 테두리)를 쓴다.
- **화차 상세·증감치 [구현됨]**: 화차 상점에서 상품 선택 시 우측 영역에 상세 스펙 및 현재 편성 대비 증감치(보유 칸 +1, 적재 칸 +25 등)를 표시한다. 상점은 선택 없음으로 시작하고(상세는 고르기 안내만 표시), 카드를 누르거나 끌기 시작하면 선택, 같은 카드를 다시 누르거나 쪽 넘김·상점 퇴장 시 해제한다. 선택 표시는 의뢰 게시판과 같은 속이 빈 테두리다.
- **화차 드래그 미리보기 [구현됨]**: 카드를 끄는 동안 화물칸 바 슬롯과 같은 방향(90도)·크기(상자 124×56에 종횡비 유지로 맞춤, 약 84×56)의 화차 그림을 커서 오른쪽 아래(중심 +56, +40)에 띄운다. 상자·위치는 카드의 `PuzzleWagonProductRow` 직렬화 값(프리팹)이 원본이며 드롭 판정은 커서 위치 기준 그대로다.
- **의뢰 상세·화물 모양 [구현됨]**: 술집 의뢰 게시판에서 선택한 의뢰의 목적지·기한·보상 및 의뢰 화물의 5×5 미니 격자 모양을 우측 영역에 미리보기로 제공한다. 게시판은 선택 없음으로 시작하고(상세는 고르기 안내만 표시), 슬롯을 누르면 선택, 다시 누르거나 수락·술집 퇴장 시 해제한다. 선택 표시는 슬롯 안쪽의 속이 빈 테두리(화물칸 선택 테두리색)이며 배경을 칠하지 않는다.

## 8. 기존 유효 기술 규칙 유지

기존 UI_LAYOUT에서 유효한 기술 및 렌더링 계약은 그대로 계승한다:

- **버튼 Tint**: 버튼은 배경색을 직접 저장하고 ColorTint 전환을 명시한다. 상태별 tint는 기초데이터의 절대 색을 배경색으로 나눈 배율을 적용해 일관된 테마를 유지한다.
- **화물 아이콘 종횡비**: 원본 종횡비를 유지하며 테이블 표시 크기 안에 맞춘다. 표시 오프셋도 물품과 함께 회전하여 실제 배치와 드래그 미리보기가 동일한 계산을 공유한다.
- **지도 지명-역 대응 안내선**: 노드별 `LabelConnector`로 지명과 역을 연결한다. 안내선은 프리팹에 사전 배치한 Image를 사용하고 입력을 가로채지 않으며, 공간 부족 시 강제 표시하지 않는다.
- **지도 줌 단계별 라벨 노출**: 지역 `mapLabelPriority` + 역 `mapLabelImportance` + 상태 가산점을 합산하여 핵심 역을 우선 노출한다. 줌/폰트 기준은 지도 프리팹(`Assets/Art/PuzzleWorldMap.prefab`)의 `PuzzleMapView`가 소유한다.
- **툴팁 슬롯 풀 및 표기 규칙**: 현재 적용 효과(실제 적용 중인 시너지·보존 효과), 일반 효과(동물 고유 효과 및 하단 구분선), 가능 인접 효과(주는 효과 우선 → 받는 효과, 그룹 내 이점 우선 정렬) 영역에 각각 프리팹 TMP 슬롯 6개를 사전 배치하고, 초과 설명은 마지막 슬롯에 줄바꿈으로 처리한다. 지칭은 '물품' 구분을 적용하며, 미방문 마을의 전 품목 배율은 지도에서 숨긴다.
- **역 행동 뒤로 가기**: 상환 가능 여부와 독립적으로 항상 활성화한다.

## 9. 미확인 사항 (플레이 확인 대상)

- **해상도별 화면 검증**: 1920×1080 외 해상도/비율에서 Expand 모드 적용 시 레이아웃 요소 간 간격 및 앵커 동작 실기 확인 필요.
- **지도 뷰포트 축소 체감**: 지도 뷰포트가 기존 1824×624에서 1232×580으로 줄어듦에 따른 노선 탐색성 및 한 화면 가시 역 수 감소 체감 확인 필요.
- **지도 마을 정보 줄 잘림**: `CityInformation`(64px)에 들어오는 문구가 최대 5줄이라 셋째 줄 이후(방문 안내·의뢰 줄)가 잘린다. 문구 구성 또는 영역 재배치 결정 필요.
- **시장 정보 줄바꿈 누락**: 시장 정보 `BoardValue`에서 '귀한 자원' 줄과 '희귀 자원' 줄 사이 줄바꿈이 없어 '목재희귀 자원'처럼 붙는다. 기초데이터 `cityTagPreferencesText2`·`map.informationText10` 끝에 `\n`이 없다(기초데이터 수정 필요).
- **지도 범례 지역명**: 범례 칸(약 48px)에는 지역 라벨 첫 단어만 보이고 특산 표기('· 금속 + 광물' 등)는 잘린다.
- **하단 정보 바 간섭 여부**: 정보 바가 화면 하단(top 1004)에 배치됨에 따라 창 모드 OS 작업 표시줄 및 스팀 오버레이 알림(우하단 기본값)과의 겹침/간섭 체감 확인 필요.
