# 외부 에셋 라이브러리

## POC_06

- 원본은 [npced16/POC_06](https://github.com/npced16/POC_06), 기준 커밋은 `a9c3fb9db61ac7484494887984dc3bd23fff5ec2`다. 저장소의 MIT 라이선스와 저작권 표기를 함께 보관했으며 사용자는 저작자에게 직접 사용 허가를 받았다고 확인했다.
- 가져온 위치: `Assets/Art/External/POC_06`. PNG 90개(약 5.1MiB)·팔레트·열차 UI 프리팹 3개·라이선스·출처 목록을 포함한다. PNG는 원본 Git blob과 일치하며 기존 GUID와 임포터 설정을 보존했다. 프로젝트 기존 에셋과 GUID 충돌은 없었다.
- 기관차 탑뷰 724×2172, 화물칸 탑뷰 1024×1536, 측면 열차 2172×724는 알파가 있는 고해상도 이미지다. 작은 픽셀 열차 1개도 포함한다. 나머지는 같은 황동·증기 테마의 선로 6개, 거점 정상/폐허 8개, 환경 4개, 소품 19개, 타일 14개, 연기 6개, UI 12개, 아이콘 11개, 초상 6개다.
- 우선 사용 후보는 이동/기차 화면의 열차 삽화, 화물/돈/출발/책 아이콘, 술집/NPC 초상, 역 주변 소품이다. 상품 아이콘은 석탄·철·황동·유리·부품·음식 중심이므로 현재 11개 상품 테마를 모두 대체하지 않는다. UI는 기존 9-slice 설정을 사용한다.
- `Prefabs/LocomotiveTopUI.prefab`, `CargoWagonTopUI.prefab`, `TrainSideUI.prefab`는 Canvas에 배치하는 시각 전용 프리팹이다. 원본 게임 컴포넌트·커스텀 머티리얼 없이 기본 UGUI만 참조한다. 측면 열차는 원본 다중 스프라이트를 유지하고 RawImage로 전체 그림을 표시한다.
- 화물칸 그림은 이미 자재가 실린 삽화다. 실제 플레이 보드 배경에 바로 적용하면 화물과 혼동될 수 있다. 고해상도 열차와 64px 픽셀 이미지의 스타일도 화면별로 나눠 사용한다.
- 원본 Train/Smoke 프리팹의 게임 전용 스크립트·머티리얼 의존성을 확인해 그대로 복사하지 않았다. 원본 씬·실행 코드·폰트·전투 콘텐츠도 제외했다. 연기는 6프레임 이미지이며 아직 재생 컴포넌트에 연결하지 않았다.
- `feature/아트리소스` 적용 범위: Game 씬의 화물칸 선택 바 8개에 탑뷰 화물칸, 기차 카드 우측 상단에 기관차 장식, 시장/술집/휴식/이동 버튼에 화물/사람/벤치/출발 아이콘을 연결했다. 지도 프리팹의 이동 연출은 기존 도형 부품을 숨기고 측면 열차를 표시하며 이동 방향에 맞춰 UV만 좌우 반전한다. 이미지 원본은 수정하지 않는다.
- 화물칸 선택 바는 세로 원본을 90도 돌려 표시하며 슬롯 수/화면 폭에 맞춰 그림 크기를 계산한다. 번호·선택 테두리·드래그 호버와 클릭 영역은 기존 것을 사용한다. 퍼즐 보드·상품 아이콘·기차 이동 규칙은 유지한다.
- `Tools/MyJG/Apply POC Art Resources`로 다시 적용할 수 있고 UI 배치·기차 바·지도 이동 UI 제작 도구도 같은 적용 함수를 호출한다. 모든 시각 요소는 씬/프리팹에 사전 저장하며 런타임에는 만들지 않는다. 적용 결과의 플레이·해상도별 확인은 수행하지 않았다.
- 파일별 출처·해시·GUID·해상도와 파생 프리팹 관계는 `SourceManifest.json`, 사용 안내와 라이선스는 같은 폴더의 `README.md`·`LICENSE.txt`가 원본이다.
