# 기초데이터 추가 이관 후보

아래 항목은 **아직 이관하지 않은 후보**다. 런타임·에디터 제작 코드와 Game 씬·인벤토리/지도 프리팹의 직렬화 설정을 점검했다. 지도 이름/노선 우선순위와 UI 배치는 프리팹 직렬화 필드로 이관 완료했다. 태그 표시 순위·내구도 표시 태그는 기초데이터로 이관했다. 이미 기초데이터나 프리팹에 있는 수치·문구·색상은 중복 후보로 세지 않는다.

## 우선 이관 후보

| 항목 | 남아 있는 값·위치 | 제안 | 고려 사항 |
|---|---|---|---|
| 버튼 테마 잔여분 | 화물칸 선택/증차 버튼의 원본 ColorBlock, 비활성 구형 마을 화면과 제작 도구의 복제 원본 | 프리팹 테마 적용 | 현재 HUD·역 메뉴·지도·모달은 프리팹 테마 적용. 화물칸은 런타임 선택/드래그 강조와 함께 통합할 필요가 있음 |
| 인벤토리 원본 프리팹 스타일 | `PuzzleInventoryUI.prefab`의 TMP 글자 크기 32/19/21/26과 `m_fontColor` | 프리팹 기본 스타일 정리 | Game 씬의 제목·안내·금액은 이미 프리팹 값으로 제어한다. 원본 프리팹 기본 스타일 중복 정리가 잔여 후보 |


## 레코드 형태를 정한 뒤 이관할 후보

| 항목 | 남아 있는 데이터·위치 | 권장 소유권·이유 |
|---|---|---|
| 태그별 표시 매핑 | `Presentation`의 `PUZZLE_TAG_LABELS`, `PuzzleTagBackgroundColor`, `GetTagSortWeight`가 태그 ID와 문구/색/순위 키를 연결 | 기초데이터에 태그 표시 레코드 추가. 실제 문구·색·대부분 순위는 이미 표에 있으나 새 태그 등록 시 코드 switch도 수정해야 함 |
| 지역 색 매핑·범례 순서 | `Presentation.PuzzleMapRegionColor`의 지역 ID switch, 지도 프리팹의 7개 지역 배열 | 기초데이터의 지역 표시 레코드에 색 키·범례 순위 저장. 지역 ID는 도메인 표와 참조 검증 |
| 라벨 배치 방향·시도 순서 | `PuzzleMapView.LABEL_DIRECTIONS`: 상/우/하/좌/대각선 8방향 | 배치 튜닝이 필요하면 기초데이터에 순서 필드가 있는 좌표 레코드 추가. 단위 방향 자체보다 시도 우선순위가 조정 대상 |
| 술집 소식 선택 정책 | `PuzzleInventoryPresenter.GetTavernRumor` 및 `PuzzleCityView.HearRumor`: 전체 미방문 도시·판매 허용·고가 수요 필터, 마을·품목 조합 무작위 한 항목, 방문당 한 번·대화 로그 기록 | 술집 도메인 표 권장. 소식 개수·선택 순서·재방문 갱신 기준을 먼저 확정. 문구는 이미 기초데이터 사용 |

## 표 구조의 추가 간소화 후보

- 화물 셀의 네 방향 `Flat` 정보는 현재 모두 같지만 향후 연결 규칙 확장 의도를 확인한 뒤 생략 규약을 정한다.
- 노선의 왕복 중복 좌표는 공통 레일과 방향별 요금으로 나눌 수 있다. 단방향·비대칭 요금 계약과 지도 제작 도구가 함께 바뀌므로 별도 작업으로 남긴다.
- 태그별 가격 프로필은 중복을 줄일 수 있으나 도시별 수요 조정이 잦으므로 재고 프로필과 분리해 편집 형태를 먼저 정한다.

## 이관 대상에서 제외한 값

- 60분/시간·24시간/일·백분율 100, 네 방향·90도 회전, 인덱스·비트 연산·중심 좌표와 판별용 -1은 단위·알고리즘 정의다.
- 경로·Input Action·직렬화 필드·씬 오브젝트·이벤트/분석 스키마 이름은 코드/자산 계약이다. 서버 주소·키는 환경변수/LogKit 계약을 유지한다.
- 스프라이트·폰트·도시 ID·사전 배치 슬롯의 오브젝트 참조는 씬/프리팹에 남긴다. 슬롯 용량 확장은 도메인 보드 크기와 제작 도구에서 산출하는 편이 우선이며 임의의 공통 숫자를 추가하지 않는다.
- 분석 운영 값은 기존 `Resources/LogData.json`에서 관리한다. 기초데이터와 중복하지 않는다.

이관 완료 항목과 편집 방법은 [기초데이터 계약](BASIC_DATA.md), 실행 상태는 [CURRENT_STATE](CURRENT_STATE.md)를 본다.
