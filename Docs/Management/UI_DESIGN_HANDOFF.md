# UI 디자인 아웃소싱용 정리 — 씬 플로우 및 화면 구성

> 작성 목적: UI 디자인을 외부에 맡길 때 전달하는 문서. 게임의 씬 흐름, 한 판 플레이 흐름, 화면·패널 구성과 기능, 이동(전환) 구조, 제작 규약을 한 곳에 모은다.
> 규칙·수치의 원본은 [게임 기획서](../게임 기획서.md), 배치의 원본은 [UI 배치](UI_LAYOUT.md)와 프리팹이다. 이 문서는 그 요약본이며 수치가 어긋나면 원본을 따른다.

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 명 | Trainventory (저장소명 JigsawBackpack) |
| 장르 | 기차 화물 인벤토리 관리 + 지역 거래 게임 |
| 핵심 플레이 | 격자 화물칸에 화물을 배치·회전하고, 지역별 시세 차익과 이동 시간·비용을 비교해 자금을 모은다 |
| 목표 | 공업 지역에서 출발해 14일(336시간) 안에 수도권 금융마을에서 채무 1,500 전액 상환 |
| 시작 조건 | 시작 자금 200, 고정 출발지 에른아 공업역 |
| 플랫폼 입력 | 마우스·키보드 (드래그&드롭 중심) |
| 기준 해상도 | 1920×1080, CanvasScaler Expand(16:9) 기준. 그 외 해상도는 확대 적용 |

지도는 지하철 노선도 스타일: 생산 5개 지역 25개 마을 + 수도권 5개 + 일반 마을 1개, 양방향 노선 51개. 지역별 노선 색, 원형 역 표식, 현재 위치 금색 강조.

## 2. 씬 플로우

빌드 씬 순서는 `Preload → Title → Game` (원본: `FlowTableData.scenes`, 씬 이름이 키).

```
[Preload]  테이블·에셋 준비 → 자동 진행
    ↓
[Title]    타이틀/시작 화면 → 시작 입력 시 Game으로
    ↓
[Game]     본플레이. 종료·재시작은 Game 씬을 다시 로드 (restartScene = Game)
```

**현재 구현 상태(중요):**
- 실제로는 **Game 씬 바로 시작**이며, Title 진입 흐름과 영구 저장·이어하기는 아직 연결되지 않았다. 디자인 범위에서 Title 화면은 후순위.
- 패배·승리 모두 결과 패널(모달)로 이어지고, 재시작은 같은 판을 초기화한다.
- 일시정지 메뉴는 Game 씬 내 모달이며 씬 전환이 아니다.

## 3. 한 판 플레이 흐름 (게임 루프)

1. 현재 역에서 **행동 선택**: 시장 / 화차 상점 / 술집 / 휴식 / (시설 있으면) 도축·개조·정제 / 이동(지도)
2. **시장**: 7×6 시장 보드에서 화물을 드래그해 구매·판매. 화물은 기차 5×5 보드로 이동
3. **배치 관리**: 화물칸(객차) 사이 배치·회전. 인접 화물 간 시너지(가치 증감), 6시간 주기 정산으로 실제 가치 변동
4. **지도**: 연결된 역을 골라 이동. 목적지·소요 시간·요금 확인 → 확인창 → 이동 연출 → 도착
5. **조력 시설**: 술집에서 소문(타 지역 시세 정보)과 운송 의뢰, 휴식에서 시간 보내기, 상점에서 화차 증차(최대 8칸)
6. **승패**: 기한 내 금융마을 도착 후 상환 버튼 = 승리 / 336시간 경과 = 패배

시간 구조: 시작 06:00, 낮 18시간 + 밤 6시간. **야간에는 시장 거래 불가**(이동·기차 내 정리만 가능).

## 4. 게임 화면 레이아웃 (1920×1080)

화면은 **세 축**으로 나뉜다. 상세 좌표표는 [UI_LAYOUT §2](UI_LAYOUT.md) 원본.

```
┌──────────────────── 고정 UI: 정보 바 (현재 마을·기한·시간·평판·자금·상환) ────────────────────┐
├──────────────────── 고정 UI: 상태 안내 띠 (거래·이동·미리보기 안내) ──────────────────────────┤
│  ┌── 백팩 축 (왼쪽) ──┐   ┌────────── 도착지 축 (오른쪽) ──────────┐                          │
│  │ 기차 카드           │   │ 역 제목 / [뒤로 가기]                   │                          │
│  │ · 화물 가치·효과     │   │ [소문 요약 띠]   [의뢰 요약 띠]          │                          │
│  │ · 숙련 칩 12개       │   │ ┌ 도착지 본문 ────────────────────┐    │  ┌ (수첩 펼침 시 ┐      │
│  │ · 5×5 기차 보드      │   │ │ 행동 목록 / 시장 / 화차 상점 /     │    │  │  우측 덮음     │      │
│  │ · 조작 안내          │   │ │ 술집 / 휴식 / 작업대 / 지도       │    │  └───────────────┘      │
│  └─────────────────────┘   └───────────────────────────────────┘    │                          │
├──────────────────────────────┬───────────────────────┬────────────────────────────────────────┤
│ [수첩 버튼]                   │  고정 UI: 화물칸 바    │ [지도 버튼]                             │
└──────────────────────────────┴───────────────────────┴────────────────────────────────────────┘
```

- **고정 UI**(정보 바·상태 안내·화물칸 바·수첩/지도 버튼)는 일시정지를 제외한 어떤 화면·모달에서도 항상 보인다.
- **지도는 도착지 축만 교체**해 연다. 백팩·기차는 계속 노출되고 기차 보드 조작도 가능하다.
- 보드 셀 크기는 전부 97.6px로 통일(기차 5×5 / 시장 7×6 / 작업대 3×3), 모든 보드 세로 중심 Y=612로 드래그 동선 최적화.
- Z-order 요약: 본문 < 지도 < 이동 확인·연출 < 수첩 < 상성표 < 고정 UI < 드래그 표시·툴팁 < 일시정지(최상위).

## 5. 화면·패널 전환 (UI 상태 머신)

```
(게임 진행 중)
 ├─ 행동 목록 ←→ 하위 화면: 시장 · 화차 상점 · 술집 · 휴식 · 도축 · 개조 · 정제   [뒤로 가기/Esc]
 ├─ 지도 열기 (지도 버튼 또는 '이동' 카드)
 │     ├─ 역 클릭 → [이동 확인 모달] --확인--> [이동 연출(진행률)] → 도착 → 지도 닫힘
 │     │                        └--취소/Esc--> 지도 복귀
 │     ├─ 미연결 역 클릭 → [경로 계획 창] (경유 정차 토글·자동 이동)
 │     └─ 닫기/Esc → 직전 역 화면 복귀
 ├─ 수첩 열기 (하단 버튼 또는 우측 손잡이) → 탭: 소문 / 의뢰 / 숙련 / 상성표
 │     └─ 상성표 탭: 수첩이 화면 폭으로 넓게 펼쳐짐. Esc는 상성표+수첩 함께 접음
 ├─ 결과 패널 (승리·패배): 시간 정지, 입력 차단, [재시작] [종료]
 └─ 일시정지 (Esc, 닫을 화면 없을 때): [계속] [재시작]
```

**Esc 우선순위**(위부터): 지도 검색 칸 → 고유명사 행동 메뉴 → 이동 확인 취소/자동 이동 중지 → 드래그 취소 → 상성표 접기 → 지도 닫기 → 수첩 접기 → 하위 화면 복귀 → 일시정지 열기. 마우스 뒤로가기 버튼과 일반 우클릭은 닫을 화면이 있을 때 같은 순서로 한 단계씩 처리한다. 화물을 잡았을 때의 우클릭은 회전이다.

## 6. 화면별 기능 명세

### 6.1 고정 HUD

| 요소 | 내용 |
|---|---|
| 정보 바 | 현재 마을(지역색 링크)·남은 기한 D-n(3일 이하 경고색)·게임 시간(Day n · HH:mm · 낮/밤 · 휴업) + 하루 24시 낮/밤 막대(현재 시각선, 정산 시각 눈금, 이번 주기 진행 띠, "정산 남은 시간 · 예상 ±")·평판·자금·상환 버튼(금융마을에서만 활성) |
| 상태 안내 띠 | 마지막 행동 결과·거래 미리보기·이동 실패 사유 등 한 줄 안내. 거래 품목·숙련 상승 태그에 링크 |
| 화물칸 바 | 객차 슬롯 최대 8개 버튼. 선택 칸 강조, 드래그 호버 배율·색 보정. 미보유 칸은 표시 않고 화차 카드 드래그 시에만 빈칸 테두리 힌트 |
| 수첩 버튼 / 지도 버튼 | 화면 좌·우 하단 고정보다 큰 버튼. 지도는 열리면 '지도 닫기'로 문구 전환 + 활성 테두리. 수첩 버튼과 우측 손잡이에 새 소식 개수 배지 |

### 6.2 기차 카드 (백팩 축, 좌측)

- 선택한 화물칸의 5×5 보드. 보드 제목(칸 번호)·현재 가치(굵게)와 기본 가치(보조)·화차 특수 효과(냉장 프레임 등) 표시.
- 숙련 칩 12칸(태그별 Lv + 진행 막대), 클릭 시 수첩 숙련 탭.
- 화물 툴팁(호버): 기차뿐 아니라 시장·작업대 보드 호버 시에도 공용 툴팁(`PuzzleItemTooltip`, 상세 구조는 §6.6)을 띄운다. 기본/실제 가치, 적용 시너지, 거래 배율·예상 금액, 미래 가치, 신선도·유통기한, 효과 설명을 표시.
- 드래그: 칸 간·칸 간 이동, 회전. 드래그 중 원자리 표시·놓을 자리 하이라이트·상성 변화 칩(±n%)·고스트 그림.
- Ctrl+좌클릭 = 시장↔기차 즉시 거래(빈자리 자동 탐색). 같은 보드 내 이동은 무료.

### 6.3 역 화면 (도착지 축, 중앙 우측)

- **행동 목록**: 카드 2열 그리드(시장·화차 상점·술집·휴식·이동·특화 시설). 없는 자리는 점선 '시설 없음' 카드.
- **시장**: 7×6 보드 + 우측 정보 열(재고 구분, 태그별 구매·판매 배율, 도시 전 품목 배율). 밤에는 보드·거래 잠금.
- **화차 상점**: 좌측 안내+상품 카드 목록(6슬롯), 우측 선택 화차 상세(그림·가격·칸 수·편성 증감치). 카드를 화물칸 바로 드래그해 구매.
- **술집**: 소문 대화(1회) + 의뢰 게시판(슬롯 2개) + 선택 의뢰 상세(목적지·기한·보수·보증금·의뢰 화물 5×5 미니 격자).
- **휴식**: 1시간 휴식 / 아침까지 대기 버튼 + 정산·야간 안내.
- **작업대(도축·개조·정제)**: 3×3 보드 + 확정 버튼 + 우측 안내. 도시별 시설 다름(다르폴 도축, 에른아 개조 등).

### 6.4 지도 (도착지 축 전체 교체)

- 노선도: 지역색 노선 51개, 역 31개, 현재 위치 금색 강조, 상환 목표 산호색. 줌 35~250% + 드래그, 전체/현재 위치 버튼.
- 줌 구간별 라벨: 축소(85% 미만)하면 역 이름 대신 지역명, 확대하면 역 이름 추가. 글자·마커는 줌 역배율 보정. 노드 안내선(이름-역 연결) 사전 배치.
- 역 호버: 공용 툴팁(`PuzzleItemTooltip`, §6.6)으로 이동 미리보기(지역·소요 시간·운임·도착 예정·남은 기한·방문 여부) 표시. 미방문 역은 이름·지역 중심, 소문 들은 역은 `?` 배지, 의뢰 목적지는 의뢰색 링 + 남은 시간.
- 경로 계획: 미연결 역 클릭 시 최단 시간 경로 + 경유역 정차 토글 + 자동 이동/중지. 경로는 금색 칠.
- 지도 머리: 검색 칸(역·지역 부분/초성 일치, 결과 6개 + '경로' 버튼), 지역 범례.
- **이동 확인 카드**: 목적지·소요 시간·요금·이동 후 자금, 확인/취소(취소 기본). **이동 연출 카드**: 사전 배치 기차 그림 + 진행률. 완료 시 도착 표시 후 자동 닫힘.

### 6.5 수첩 (우측 접이식, 4탭)

| 탭 | 내용 |
|---|---|
| 소문 | 들은 게임 날짜·시각 – 들은 마을 – 내용 순 기록. 새 기록으로 자동 스크롤 |
| 의뢰 | 진행 중(남은 기한·목적지·보수) + 완료/실패 기록 |
| 숙련 | 평판·동시 의뢰 수·다음 단계 요약 + 태그별 Lv·경험치 행(사전 배치 12행) |
| 상성표 | 태그×태그 시너지 표(칸당 효과 %) + 제외 규칙 각주 + 화물별 태그 배지. 선택 시 수첩이 화면 폭으로 펼쳐짐 |

- 여는 방법: 하단 '수첩' 버튼 / 화면 우측 가장자리 세로 손잡이(드래그로 상하 이동).
- 요약 띠(소문 2줄·의뢰 3건)는 도착지 축 상단에 항상 보이고, 클릭 시 해당 탭 열림.

### 6.6 공통 위젯

- **고유명사 하이퍼링크**: 소문·의뢰·안내·지도 정보의 도시/지역/품목/태그/의뢰 이름이 링크. 클릭=관련 화면 이동, 호버=공용 툴팁(`PuzzleItemTooltip`)으로 미리보기 표시, 우클릭=공통 뒤로가기.
- **공용 툴팁 (`PuzzleItemTooltip`)**:
  - **레이아웃·동작**: 폭 300px, 내용량에 따른 가변 높이. 표시 전용(`blocksRaycasts=false`)이며 마우스를 따라다니되 화면 우측 경계 초과 시 좌측으로 자동 전환되고 `22×20` 화살표 포인터(`Pointer`)가 함께 좌우 플립된다(하단 고정 UI 여백 228px 회피).
  - **내부 구조**:
    - **헤더**: 제목 + 태그 배지 묶음(`TagBadgeGroup`, 품목·태그 호버 시 표시).
    - **수치 행** (2열 라벨/값 + 행별 1px 구분선): 기본 가치 · 현재 가치 · 판매/구매 배율 및 금액 · 미래 정산 가치(시너지 정산 횟수) · 신선도(`•`) · 신선도 하락까지(`nD nH` / 정지).

## 7. 디자인 제작 규약 (외주 계약 시 전달)

1. **배치 원본은 프리팹**(`Assets/Art/UI/` 이하 화면별 중첩 프리팹). 런타임 UI 생성 금지 — 개수 변하는 목록은 사전 배치 슬롯 풀(on/off, 초과 시 "외 N개").
2. **글자**: TextMeshPro만. 6단계 고정 — Display 32(모달 제목) / Title 24(화면 제목) / Subtitle 20(섹션 제목) / Body 16(본문) / Caption 14(보조) / Micro 12(배지).
3. **간격**: 8pt 그리드(4·8·16·24·32). 띠 사이 16, 화면 여백 40, 카드 패딩 24.
4. **색·문구 단일 출처**: 테마 색과 공통 문구는 내부 시스템(Presentation/기초데이터)에서 공급. 화면마다 고유 색을 하드코딩하지 않고, 색 팔레트/텍스트 시트를 산출물로 준다.
5. **캔버스 구조 유지**: 본문/지도/수첩/툴팁/고정UI/일시정지 등 캔버스가 분리되어 있고 sortingOrder로 Z 순서를 고정한다. 통합하지 않는다.
6. **기존 아트**: 외부 도입 이미지 90장과 열차 시각 UGUI 프리팹 3종(화물칸 바·기관차 장식·역 아이콘)이 이미 적용되어 있다(`Assets/Art/External/POC_06`). 새 디자인은 이 톤과 호환해야 한다.
7. **금지**: 씬에 UI 오버라이드 저장, 코드에서 View 오브젝트 생성, LayoutGroup 런타임 생성, 구 Text 컴포넌트, 폰트 autosize 남용(최대=단계값/최소=한 단계 아래).
