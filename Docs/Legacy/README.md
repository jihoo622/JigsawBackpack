# 과거 자료(Legacy)

**현재 작업 기준으로 사용하지 않는다.** 조사·설계·구현 판단의 근거로 인용하지 말고, 필요한 내용은 현재 문서로 옮겨 다시 확인한 뒤 쓴다.

## UI/ — 2026-11-19 화면 배치 개편 확정 전 자료

확정 레이아웃: [시안 3b](../Research/relayout/concept-3b.html)와 [전체 화면 배치 개편 계획](../Research/UI_RELAYOUT_PLAN.md).
아래 자료는 3b 확정 이전의 다른 레이아웃 안과 그 근거 조사라 확정안과 충돌한다.

| 자료 | 내용 | 격리 이유 |
|---|---|---|
| `GRID_INVENTORY_*.md`, `BACKPACK_DECKBUILDER_UI_RESEARCH.md`, `TRADE_GAME_UI_RESEARCH.md`, `TRAIN_GAME_UI_RESEARCH.md` | 유사 게임 UI 조사와 레이아웃 후보 | `turnBase-전환` 브랜치 기준 수치(3시간 턴·5×5 보드 등)이고, 결론이 확정안과 다르다 |
| `CURRENT_UI_LAYOUT_AUDIT.md`, `DIRECT_GRID_LAYOUT_EVIDENCE.md`, `TRADE_DESTINATION_LAYOUT_EVIDENCE.md` | 옛 화면 점검과 배치 근거 | 옛 브랜치 화면 기준 |
| `UI_REDESIGN_PROPOSAL.html` | A/B/C/D/L안 비교 | L안(보드 아래 렌즈 패널) 채택 기록. 3b로 대체 |

| `relayout/concept-1~3.html` | 개편 시안 1(나란히 거래대)·2(위아래 열차 편성)·3(지도 중심 허브) | 비교 후 3을 수정한 3b로 확정. 그림은 `Research/relayout/assets/`를 참조 |
