## 그룹 1 — 서바이벌 호러(RE류) 인디의 그리드 재해석

### 1. SIGNALIS (2022, rose-engine / Humble Games·Playism)
- 장르·플랫폼: 2D 픽셀 서바이벌 호러(3인칭 고정 각도). PC·PS4·PS5·XB1·XSX|S·Switch.
- 그리드 방식: 인벤토리는 칸 격자 UI. 품목은 1~2칸 점유(권총·탄약·열쇠 등), 회전 지원 여부는 이번 조사에서 확인 못 함 `(추정: 지원)`. **칸 수와 무게가 아니라 "소지 가능 개수 6개"라는 개수 상한**이 핵심 제약 — 위키·리뷰에서 공통 확인. 무게 개념 없음.
- UI 레이아웃 특징: 소지창(6칸)과 별개로 세이브룸의 **아이템 보관 상자**가 있어 데드백/필수품 비축 용도. 픽업 시 어느 칸에 들어갈지 자동 배정되며 빈칸이 없으면 습득 불가 → 버리기/넣기 판단이 퍼즐의 일부.비판적으로 "인벤토리가 답답하다"는 리뷰가 많았고, 개발진이 **제약을 완화하는 옵션(난이도/인벤토리 관련 패치)**을 추가하겠다고 밝힘(1.2 업데이트 계열). 전용 툴팁·정렬 버튼·필터는 없음.
- 참고 포인트: ① "칸수·무게 대신 개수 상한"이라는 극단적 단순화 — 화물칸 크기 확장이 곧 캐리 파워가 되는 JigsawBackpack에서 초반 압박감을 주는 조임 장치. ② 세이브룸 보관함 = 역(hub) 보관소 아이디어. 출처: Wikipedia(SIGNALIS), Rock Paper Shotgun 리뷰. 확신도: 높음(개수 상한·보관함) / 낮음(회전·격자 치수).

### 2. Crow Country (2024, SFB Games)
- 장르·플랫폼: 90년대풍 고정 카메라 서바이벌 호러. PC·PS4·PS5·XB1·XSX|S·Switch.
- 그리드 방식: RE류 아이템박스식 격자 — 대형 품목이 여러 칸을 점유하는 구조로 보이나 회전 지원은 확인 못 함 `(추정: 회전 없음·자동 정렬)`. 무게 개념 없음.
- UI 레이아웃 특징: 조합(crafting)이 인벤토리 안에서 수행 — 여러 아이템을 조합해 퍼즐 해체·무기/장비 업그레이드품 획득. 회복탄·탄약은 자판기/컨테이너에서 조달. 필드 노트·일지류가 별도로 정리(독서용 리스트). 품목 다수는 "특정 장소에서만 쓰는 열쇠형"이라 인벤토리 점유 압박이 시나리오 진행도에 따라 변함.
- 참고 포인트: ① 인벤토리 = 조합 작업대(선택 → 조합) UI. 화물칸에서 두 물품 인접 시 효과(연계 보너스)를 설명하는 인터페이스로 응용 가능. ②_upgrade(시크릿 보상)을 "칸 추가"가 아니라 "칸 효율(압축·보관함)"로 주는 설계. 출처: Wikipedia(Crow Country), itch/스팀 페이지. 확신도: 중간(그리드 세부=낮음).

### 3. Tormented Souls (2021, Dual Effect / PQube)
- 장르·플랫폼: 고정 카메라 RE류 호러 어드벤처. PC·PS4·PS5·XB1·XSX|S·Switch.
- 그리드 방식: 브리프케이스형 3D/2D 혼합 격자 — 품목이 도미노형 모양으로 여러 칸 점유, **회전(축 회전)으로 맞추는 RE4식** 구조 `(추정: 축 회전 지원)`. 무게 개념 없음.
- UI 레이아웃 특징: 세이브포인트에 **아이템 박스(창고)** 운영, 소지一格=한 손 규칙이 강해 총기/양손 장비의 슬롯 배치가 별도. 아이템 조합은 없고 "열쇠·손잡이·퓨즈"류 키아이템 위주라 슬롯 정리 = 퍼즐 자체.
- 참고 포인트: ① "물건 모양이 곧 퍼즐"이라는 호러식 연출 — 칸이 남는데 못 넣는 답답함이 긴장의 원천(JigsawBackpack에서는 압박강도가 큰 화물칸에서 동일 효과). ② 소지칸과 장비슬롯(입는/드는)을 완전히 분리한 화면. 출처: Dual Effect/PQube 스팀 페이지, Wikipedia. 확신도: 중간.

### 4. 참조 원조 — Resident Evil 4 (2005 / 2023 리메이크, Capcom)
- 장르·플랫폼: 서바이벌 호러(AAA). 본 카테고리 C 후보는 아니나 "가방 칸 + 회전 + 케이스 업그레이드"의 원형이라 비교군으로 유지.
- 그리드 방식: 아타셰케이스(briefcase) 격자, 도미노형 품목 + 회전, 케이스 용량 업그레이드. 무게 없음.
- UI 레이아웃 특징: 인벤토리 화면에서 즉시 조합(화약+허브)·무기 장착, 케이스 확장(4×5 → 6×8 등)이 진행 보상. "칸이 남으면 못 넣는다"는 규칙의 대명사.
- 참고 포인트: ① 화물칸 업그레이드를 "칸 수"로만 주지 않고 "칸 모양(긴 화물용 1×N 열 추가)"로 주면 퍼즐 깊이가 커짐. ② 정렬/회전 버튼의 조작감(회전 단축키 상시 노출)은 이 계열 표준. 출처: SteamPeek/스팀 태그·리뷰·일반 지식. 확신도: 높음(개념) — 세부 수치는 확인 못 함.

## 그룹 2 — 생존·크래프트 (볼륨·무게·컨테이너)

### 5. Project Zomboid (2013, The Indie Stone)
- 장르·플랫폼: 오픈월드 좀비 생존 시뮬(isometric(등거리)). PC(Steam/GOG)·macOS·Linux — Xbox Game Pass 이식.
- 그리드 방식: **기본은 격자 아님** — 품목당 개별 슬롯 + 리터 단위 "수용량(capacity)" + kg 무게의 이중 제약. 컨테이너는 `수용량`과 `무게 경감률`을 가져 예: Normal Hiking Bag = 수용량 20, 무게 경감 70%(위키 확인). 의류의 화주머니(cargo pants/조끼)가 슬롯을 늘리는 구조.
- UI 레이아웃 특징: 인벤토리는 좌측 페이퍼돌(장착 슬롯) + 우측 아이템 리스트/컨테이너 트리, 아이템 우클릭 컨텍스트(들기/입기/분할/버리기) 중심. 컨테이너를 열면 별도 창이 뜨고 드래그&드롭 이동. 무게 게이지·피로/스태미나 연동. 정렬 버튼은 없고 "Item Pooling/stack"과 검색형 드롭다운 지원. **워크숍 모드 "Inventory Tetris"가 기본 리스트 인벤토리를 회전 가능한 공간 격자로 교체** — 서든 생존 커뮤니티에도 격자 수요가 있다는 방증.
- 참고 포인트: ① 컨테이너별 "무게 경감 %" — 화물을 어떤 차량/대차에 실느냐로 실효 용량이 달라지는 규칙(기차 화물칸 업그레이드의 수치화 모델). ② 수용량(부피)과 무게를 따로 표시해 "가득 찬 이유"를 두 게이지로 설명하는 UI. 출처: projectzomboid.fandom.com(Normal Hiking Bag·Game Interface), Steam Workshop(Inventory Tetris). 확신도: 높음(수치·UI) / 중간(모드 세부).

### 6. Cataclysm: Dark Days Ahead (2016~ 정기 릴리스, Cascade 팀 / 무료 오픈소스)
- 장르·플랫폼: 턴제 로그라이크 생존(텍스트+타일). PC·Android — 무료.
- 그리드 방식: 공간 격자 아님 — **부피(volume)와 무게(weight)의 이중 제약**이 핵심. 품목은 1칸=1개체가 아니라 리터/kg 속성, 컨테이너는 `수용 부피` + **포켓(pocket) 타입**(min/max 부피, 모양 요구 = rigid storage, 물막이, 즉시 접근 여부)으로 실제 수납 가능 여부가 결정. 겹쳐 쌓는 스택도 부피를 소모.
- UI 레이아웃 특징: 인벤토리는 "착용 중 → 컨테이너 → 포켓" 계층 트리 + 포켓별 탭/단축키. 정렬 방식전환(이름/부피/무게/카테고리/접근성), 즐겨찾기(자동 줍기 프로필 = what to pick up), `autopack`(적당한 포켓에 자동 배정), 한 번에 많은 개수를 옮기는 슬라이더. 무게/부피 초과 이유는 텍스트 메시지(예: "too large for the pocket")로 명시.
- 참고 포인트: ① **포켓 단위 제약**(크기·모양·물막이)은 "이 칸엔 이 종류만" 규칙(냉장 칸, 유독물 칸)으로 직결. ② "저장 소견서(pickup profile)" = 자동 정리/적재 규칙 프리셋 — JigsawBackpack의 열차별 적재 프리셋 기능과 대응. ③ 초과 사유를 게이지+문구로 병기. 출처: CDDA 위키 접근 실패 — 스팀 미등재·오픈소스 문서 및 일반 지식 기반. 확신도: 중간(메커닉=높음 / UI 세부 항목명=낮음).

### 7. NEO Scavenger (2014, Blue Bottle Games)
- 장르·플랫폼: 턴제 샌드박스 생존(텍스트+아이콘). PC·Mac·Linux·Android·iOS.
- 그리드 방식: **격자 기반 — 부피(칸)와 무게를 동시 계산**(위키 명시). 품목을 **마우스 휠·화살표 버튼으로 회전**시켜 맞춤. 가방·배낭·쇼핑카트 등으로 "두 손으로 들 수 있는 이상"의 수납 공간 확장.
- UI 레이아웃 특징: 신체 부위별 슬롯(투구/안면/어깨/손) + 메인 격자 창, 컨테이너는 별도 창. 무게 초과·부피 초과를 별도 표시. 아이콘 중심의 저해상도 UI지만 "무엇이 몇 칸×몇 칸"인지 실루엣으로 즉시 판별.
- 참고 포인트: ① 회전 UI(휠 + ±버튼) — 컨트롤러/터치에서도 동일한 ±버튼 방식. ② 신체 슬롯이 곧 컨테이너(어깨에 메는 가방 = 별도 격자)라는 중첩 모델 → 객차마다 다른 칸 모양을 주는 설계와 유사. 출처: neoscavenger.fandom.com(Inventory). 확신도: 높음.

### 8. Barotrauma (2019, FakeFish / Liminant LC)
- 장르·플랫폼: 협동 우주(해양) 생존·시뮬, 2D 사이드뷰. PC·macOS·Linux(게임패스 포함).
- 그리드 방식: 아이템은 크기 등급(아주 작음/작음/중형/대형)을 갖고, 컨테이너는 **칸 슬롯 수(Item Slots)**로 용량을 표현 — 예: Large Steel Cabinet 30칸, Medium Steel Cabinet 15칸, 배낭형 12칸 + "중형 아이템 수납 불가"(위키 확인). 일부 컨테이너는 수납 가능 종류 제한. 회전은 없음.
- UI 레이아웃 특징: 컨테이너를 열면 **칸 테이블 GUI**가 뜨고 드래그&드롭 + 더블클릭 즉시 넣기/빼기. **방수(watertight)** 속성으로 침수 구역에서 내용물 보호 — "칸의 성질"이 수납 규칙이 되는 대표 사례. 도구벨트(toolbelt)는 슬롯 4~5개의 즉시 접근 바.
- 참고 포인트: ① 컨테이너 속성 태그(방수/전원/냉장/위험물)를 칸에 부여 → JigsawBackpack의 "특수 화물칸" 규칙 UI. ② 더블클릭 즉시 이동 + 도구벨트(핫바) 조합은 정돈 속도를 크게 높임. 출처: barotrauma.fandom.com(Containers). 확신도: 높음.

### 9. This War of Mine (2014, 11 bit studios)
- 장르·플랫폼: 내전 생존(2D 사이드뷰, 주간 기지/야간 약탈). PC·Mac·Linux·모바일·콘솔.
- 그리드 방식: **캐릭터별 슬롯 수**가 다른 칸 인벤토리 — 확인된 수치: Boris 17칸, Adam 15칸, Marko 15칸, Pavle 12칸, Zoran 7칸(위키). 품목은 크기별로 슬롯을 차등 점유(무게는 이동속도/조용함에 영향 `(추정)`).
- UI 레이아웃 특징: 약탈 지점의 컨테이너(가방·선반·캐비닛)와 캐릭터 배낭을 좌우로 벌려 놓고 드래그&드롭 — **"시간 제한 안에서 몇 칸을 채울까"**가 코어 루프. 귀환 후 기지 창고는 별개의 항목 리스트(수요 아이콘 표시). 배낭 확장은 아이템(대형 배낭)으로.
- 참고 포인트: ① "캐릭터마다 칸 수가 다름" → 기관사/짐꾼 등 승무원을 칸 수·특수칸으로 차별화하는 아이디어. ② 약탈(제한 시간 파밍) 화면과 기지 창고 화면을 완전히 분리한 2-탭 레이아웃. 출처: thiswarofmine.fandom.com(Playable Characters). 확신도: 높음(칸 수) / 중간(무게 연동).

### 10. The Long Dark (2017, Hinterland)
- 장르·플랫폼: 탐험 생존(1인칭). PC·Mac·Linux·콘솔·Switch.
- 그리드 방식: 배낭 화면은 슬롯 격자 + **kg 무게 상한** — 기본 30kg, 착용·장비로 증가(위키 Encumbrance). 무게는 이동속도·스태미너에 직결. 품목은 1×1/2×1급 점유 `(추정)`, 회전 없음.

- 참고 포인트: 캐릭터(기관사·차장)의 능력이 화물칸 크기를 늘리는 성장축 — 승무원 배치와 적재 용량의 연동. 출처: tvtropes.org. 확신도: 높음(기록) / 중간(메커닉 디테일).

### 27. Arcanum: Of Steamworks & Magick Obscura (1999, Troika)
- 그리드 방식: 무게와 격자 공간을 병행. **defrag(자동 정리) 버튼** 내장.
- UI 특이점: 하단 10칸 핫키 슬롯은 아이템 크기를 무시 → 격자 공간을 우회하는 "즉시 슬롯" 존재.
- 참고 포인트: 무게+격자 병행 UI의 초기 사례, 그리고 "핫바가 격자 압력의 탈출구"라는 패턴(화물칸의 즉시 하차 칸). 출처: tvtropes.org. 확신도: 높음(기록).

### 28. Arx Fatalis (2002, Arkane) / Dungeon Siege (2002, Gas Station)
- Arx Fatalis: 격자 크기를 **주변에서 찾은 배낭으로 확장** + 정렬 버튼.
- Dungeon Siege: **"가장 빈틈없이 채우는" 자동 정리 버튼** + 도시마다 노새(mule) 추가 용량.
- 참고 포인트: "정렬 버튼"과 "역/역간 수송수단(노새)형 보조 용량" — 정차역 허브 확장UI와 직결. 출처: tvtropes.org. 확신도: 높음(기록).

### 29. Kingdom Hearts 358/2 Days (2009, h.a.n.d. / Square Enix)
- 그리드 방식: 무기·마법·스킬·가방까지 전부 **패널을 확장되는 격자에 배치**, **배수(multiplier) 패널**이 특정 종류 패널의 효과를 인접 범위에서 배가.
- 참고 포인트: "특정 칸/특정 종류 옆에 놓으면 배율" = 인접 보너스의 최고 완성형. 인접 보너스 시각화를 "범위 하이라이트"로 보여주는 모델. 출처: tvtropes.org. 확신도: 높음(기록).

### 30. Infinite Space (2009, Idea Factory·Graphic Research)
- 그리드 방식: 함선마다저마다 다른 모양의 모듈 격자, 엔진/교량은 지정 칸 고정, **격납고를 캐터펄트 옆에 인접**시켜야 작동.
- 참고 포인트: 고정 칸(필수 장비) + 인접 조건 조합. 객차의 "기관실·제동칸 고정" 규칙 설계 시 참고. 출처: tvtropes.org. 확신도: 중간.

### 31. Level-5 계열 — Dark Cloud (2000) / Dark Chronicle (2002) / Rogue Galaxy (2005)
- 그리드 방식: 도미노형+중첩 불가(같은 종류도 스택 안 됨 → 칸 압박 극심), "Pocket" 아이템으로 최대 소지량 증가, Rogue Galaxy는 **7페이지×40칸 페이징 + 전용 진귀품 페이지 + 창고도 격자**.
- 참고 포인트: 대량 아이템의 **페이징 UI**(칸이 넘칠 때 탭/페이지 분할)와 "창고도 같은 격자"라는 일관성 — 창고/객차/화물창을 동일 격자 문법으로 통일할 근거. 출처: tvtropes.org. 확신도: 높음(기록).

### 32. 비교 참조(다른 카테고리 소관 · 짧게)
- Escape from Tarkov 계열 루타슈: 컨테이너마다 **내부 격자 모양이 다르고**(도미노형 내부칸) 회전 지원, 겹쳐 메는 nested container. 확인: GitHub/스팀 사례 문서에서의 간접 언급. 확신도: 높음(개념) — 본 문서는 상세 생략.
- Path of Exile: 12×5 격자 + 스태시 탭, 회전 없음. 확신도: 높음(일반 지식).
- Madison(2022)·Agony류 호러: RE식 격자를 차용하나 회전/칸 규격 미확인. 확신도: 낮음.

## 카테고리 C UI 트렌드 요약 (5줄)

- 제약의 축이 세 가지로 정리된다: **칸(공간) / 무게·부피 / 개수** — 호러·로그라이크는 칸+개수, 생존류는 무게·부피, CDDA·PZ는 둘의 이중 제약. JigsawBackpack이 "칸+무게"를 택하면 설명 UI는 생존류(게이지 2개)를 따른다.
- 회전 지원은 사실상 표준(NEO Scavenger·RE류·Undungeon·잼작들). 회전 없는 작품(Fate·Diablo II)은 "칸이 남는데 못 넣는다"는 불만이 리뷰·문서에 고착된다.
- 컨테이너는 단순 용량이 아니라 **속성 태그**(Barotrauma 방수 / PZ 무게경감% / CDDA 포켓 모양·부피)로 발전 — "칸 종류" 규칙은 이 계보에서 그대로 가져올 수 있다.
- 자동화는 정렬 버튼(Arx·Dungeon Siege) → 규칙 프리셋(CDDA pickup profile·autopack)으로 진화했다. "자동 정렬"보다 "자동 규칙"이 고급 사용자에게 통용된다.
- 인접성은 보너스의 주 언어가 되었다(KH358/2 배율 패널 → Starsector 인접 조건 → Undungeon·Packmates 시너지) — 표현은 항상 **배치 즉시 발광/연결선**으로, 텍스트 설명 없이 읽히게 만든다.
