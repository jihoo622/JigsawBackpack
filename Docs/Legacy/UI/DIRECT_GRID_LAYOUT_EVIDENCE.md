# 직접 유사 그리드 레이아웃 증거 — R2

> 확인일: 2026-11-18 · 범위: A/B/C 8개 · 변경: 이 문서만 신규 작성  
> 상태: **정지 화면 관찰 완료 / 연속 조작·현행 빌드 검증 미완료**. 조사 완료 게이트 통과 문서가 아니다.

## 1. 방법, 선정, 증거 계약

[조사 계획](GRID_INVENTORY_LAYOUT_RESEARCH_PLAN.md) §5와 [후보 레지스터](GRID_INVENTORY_CANDIDATE_REGISTER.md)를 기준으로 기존 백팩·ARPG·서바이벌·인디 문서를 대조했다. 기존 문서의 조작·시너지·출시 버전 주장을 화면 사실로 승계하지 않았다.

- A: Backpack Battles, Backpack Hero, NEODUEL, God Of Weapons(4).
- B: DREDGE, ZERO Sievert, NEO Scavenger(3).
- C: Save Room - Organization Puzzle(1).
- NEO Scavenger는 레지스터 G20의 예비 규칙에 따라 선택했다. RE4 리메이크도 Steam 첫 8장을 열었으나 탐색·전투·시네마틱뿐이라 직접 격자 증거 표본으로 채택하지 않았다. Tarkov/SCUM/DayZ의 기존 미검증 서술로 수량을 채우지 않았다.
- **이 8개는 A/B/C 비교 표본이지, 계획 전체의 A≥4/B≥4/C≥1/D≥3 충족이 아니다. B가 한 개 부족하다.**

### 실제 접근한 자료

`https://store.steampowered.com/api/appdetails?appids=<ID>&l=english`의 JSON과 `screenshots[].path_full` 이미지를 내려받아 직접 열었다. A4·DREDGE·NEO 각 첫 8장, ZERO 7장, Save Room 6장, 총 **61장**을 축소판으로 훑었고 핵심 8장은 원본으로 재확인했다. RE4의 제외 검토 8장은 이 61장에 포함하지 않는다. 이미지와 JSON은 작업용 임시 디렉터리에만 저장했으며 저장소에는 이 문서와 원본 URL을 남긴다. 아래 `#n`은 **확인 당시 API 배열의 0부터 시작하는 순번**이며, 배열이 바뀌어도 하단 해시 URL로 식별한다.

증거 표기:

- **V**: 이번에 실제 본 정지 화면. 화면 안 텍스트·배치·외곽선만 입증한다.
- **U**: 확인 불가. 지원하지 않는 기능이라는 뜻이 아니다.
- **N**: 비교 범위상 해당 없음. 예: 경제가 없는 순수 패킹 퍼즐의 거래 직후.
- **제안**: Trainventory용 해석·설계 가설. 원작의 검증된 UX 효과가 아니다.

**중요한 한계:** 게임을 실행하거나 조작 영상을 연속 재생하지 않았다. 정지 화면에 커서·강조가 있어도 호버/클릭 구분, 드래그 여부, 유효/무효 드롭, 구매 후 갱신·되돌리기를 추론하지 않는다. 각 게임에 평상시·선택·드래그·확정 전·확정 후의 **5상태 점검 행은 작성했지만, 8×5=40개 상태를 실제 관찰한 것은 아니다.** 서로 다른 스크린샷을 전후 시퀀스로 조합하지 않는다.

Steam 상품의 PC 지원은 확인했으나 각 홍보 이미지의 촬영 OS·입력 장치·빌드·촬영일은 대체로 U다. 정식 출시일은 촬영 버전이 아니다. 특히 Backpack Battles 일부 자료에는 0.7.6 표기가 보여 현행 정식판 UI라고 부르지 않는다. URL의 `1920x1080`도 실제 픽셀 치수를 보증하지 않는다.

## 3. 게임별 5상태 점검과 해석

### 3.1 Backpack Battles — 가격표는 물건 옆, 가방은 별도 영역

| 점검 상태 | 관찰 / 미확인 |
|---|---|
| 평상시 | **V BB0/BB3**: 왼쪽 가방, 오른쪽 상품 선반, 아래 STORAGE, 상단 전투 시작. 상점은 가방과 같은 격자가 아니다. |
| 아이템 선택 | **V BB4**: 도감/레시피 화면의 큰 설명 카드와 조합 재료 도식. 상점 선택 화면은 U; 이 카드를 구매 툴팁이라고 전용하지 않음. |
| 드래그 중 | **U**: BB3 중앙 손 커서는 보이지만 물건을 잡았다는 증거가 아님. 원자리·회전·무효칸 U. |
| 확정 전 | **V BB3의 가격 표시만**: 상품별 가격, SALE/원가 취소선, Gold 5와 붉은 8/10 가격. 가격색과 잔액의 인과·드롭 전 가격 미리보기는 U. |
| 확정 후 | **U**: 같은 거래 전후 자금/재고/복구 상태 없음. BB3의 Gold 옆 -1도 원인을 특정하지 않음. |

- **레이아웃:** BB3 가방은 대략 좌상단 10–41% 폭, 3–60% 높이, 선반은 우측 약 62–97% 폭. 셀 수·셀 크기 일치 비교는 불가(상점이 격자가 아님). 가격은 물건 바로 옆, 자금은 좌하단으로 떨어져 있다.
- **가격·시너지:** 가격표는 상시 V. 가방 일부 보라색 발광은 V지만 발광이 어느 조건·어느 대상의 시너지인지는 해당 정지 화면만으로 U. BB4는 결과물+재료를 공간적으로 묶는다.
- **접근·복구:** 가격 열람에 별도 패널을 열 필요가 없는 상태임은 V; 실제 진입 클릭 수, 회전 키, 빠른 이동, 취소·되돌리기 U.
- **장점 / 위험:** 물건과 가격의 결합이 강하다. 반면 물건마다 가격표를 두면 조밀한 시장 격자에서는 모양을 가릴 수 있고, 원거리 자금 확인이 필요하다(사용성 가설).
- **Trainventory 적용:** 선택 화물 옆 현재 가격 + 고정 자금 표시를 시험한다. 선반의 넓은 빈 공간과 구버전 가방 모양을 우리 시장 7×6에 그대로 복제하지 않는다.

### 3.2 Backpack Hero — 규칙과 현재 기여량을 함께 설명

| 점검 상태 | 관찰 / 미확인 |
|---|---|
| 평상시 | **V BH0/BH7**: 상부 가방, 하부 캐릭터/적. BH7은 두 개의 포켓 표현. 두 거래 그리드가 아님. |
| 아이템 선택 | **V BH2**: FEATHER ARMOR 카드, 두 방어구의 노란 점선 테두리, `FOR EACH ARMOR IN ANOTHER POCKET`, `ADDS 3 DODGE TO SELF`, `BASE:1`, `2X FEATHER ARMOR +2` 표시. |
| 드래그 중 | **U**: 선택 테두리가 드래그/배치 미리보기인지 확정 불가. |
| 확정 전 | **U**: 전투 선택 카드의 현재 효과를 구매 전후 차분으로 간주하지 않음. |
| 확정 후 | **U**: 거래/재배치 전후 상태의 연속 근거 없음. |

- **레이아웃:** BH2 상부 가방 영역은 대략 폭 13–87%, 높이 3–58%; 설명 카드가 중앙 하단으로 돌출해 가방 일부와 전투 공간을 가린다. 두 시장/내부 보드의 거리·동일 셀 여부 N. BH6의 마을 STORE는 별도 좌우 목록·전송 화살표·Sell Items/Done 버튼이지 던전 가방과 동시 노출된 상점이 아니다.
- **가격·시너지:** BH2는 규칙과 현재 기여량을 같은 카드에서 읽을 수 있다. 엄밀히 이 예는 단순 상하좌우 인접이 아닌 **다른 포켓의 방어구** 조건이다. BH6의 판매 자원 보상과 BH2 전투 수치를 한 화면 정보처럼 합치지 않는다.
- **접근·복구:** 선택/호버 어느 입력으로 카드가 열렸는지 U. 드래그 고스트·실패 이유·빠른 이동·되돌리기 U. 보이는 Reorganize를 자동 정렬 기능으로 단정하지 않는다.
- **장점 / 위험:** 현재 결과의 산식을 설명한다. 큰 카드가 배치 작업 공간을 가리는 위험이 있다.
- **Trainventory 적용:** `기본 가치 + 현재 이웃 기여` 분해를 고정 정보 열에 시험한다. 전투 턴 조작이나 다중 포켓 조건을 새 경제 규칙으로 들이지 않는다.

### 3.3 NEODUEL — 연결 규칙 카드와 가격이 같은 정비 화면에 존재

| 점검 상태 | 관찰 / 미확인 |
|---|---|
| 평상시 | **V ND5**: 좌측 내 가방, 우측 원형 상품 영역·가격표, 아래 임시 보관처럼 보이는 빈 영역, 위 Start Duel. 빈 영역의 실제 기능은 U. |
| 아이템 선택 | **V ND1**: Hyper 카드 + Cooldown/Energize 보조 설명; 가방에 청록 연결선, 우측 선택 상품에 가격 6, 보유액 17. |
| 드래그 중 | **U**: 상품 위 커서는 보이나 드래그·원자리·회전·배치 가능 셀은 확인 못 함. |

- **가격·시너지:** `On Start`, `Trigger`, `Link`를 분리한 카드와 별도의 용어 도움말이 V. 연결선 존재만으로 모든 몬스터가 인접 시너지를 가진다고 판정하지 않는다. 우측 일부 상품/가격이 도움말에 가려진다.
- **접근·복구:** 기본 선택 카드 외에 보조 설명을 펼치는 입력 횟수 U. 빠른 이동·취소·실패 복구 U.
- **장점 / 위험:** 규칙을 수치와 용어별로 쪼갠다. 다중 툴팁이 공간과 물건 비교를 방해할 수 있다.
- **Trainventory 적용:** `조건 / 현재 효과 / 배치 후 변화`를 분리하되 드래그 때 보조 용어 카드는 접고, 영향 대상과 변화량을 우선한다. 이는 제안이지 ND의 검증된 드래그 동작이 아니다.

### 드래그·실패·되돌리기에 대한 결론

이 자료로 **좋은 드래그 고스트, 유효/무효 표시, 회전 키, 빠른 이동, undo가 원작에 존재한다고 권고할 수 없다.** 아래는 조사 계획이 요구하는 현 제품의 검증 과제이지 외부 사례에서 검증된 사실이 아니다.

1. 출발 좌표 고스트와 도착 예상 모양을 동시에 보존한다.
2. 무효 드롭은 공간 겹침/경계 밖/잔액 부족/거래 불가를 텍스트+모양으로 구분한다.
3. 회전 시 잡은 기준 칸·원래 위치가 안정적으로 유지되는지 확인한다.
4. 가격·시너지 예상치는 같은 거래·배치 스냅샷을 쓰고 `예상`과 `확정`을 구분한다.
5. 빠른 이동은 새 위치의 시너지를 예측 불가능하게 바꾸지 않는지, 실패 시 돈과 좌표가 모두 복구되는지 확인한다.
6. 판매 취소와 거래 후 undo는 별도 기능으로 정의한다. 위 증거는 후자를 입증하지 않는다.

## 5. 권고에 쓸 수 있는 결론 / 남은 조사 게이트

### 현재 권고 가능한 방향(최종안 아님)

- **기차·시장 두 격자는 유지하되 거래 중 서로 가까이 둔 비교 작업 공간을 우선 시안화한다.** 외부 근거는 DR3/ZS5/NS2의 동시 컨테이너와 큰 중앙 간격이다. 현 제품 제약은 5×5 기차·7×6 시장·PC 드래그이며, 근접 배치의 성능 우위는 아직 실험하지 않았다.
- **선택 정보는 고정 열 또는 보드 밖 카드에 둔다.** BH2/ND1/GW6의 실제 카드 중첩이 근거다. 선택 규칙과 현재값을 보되 드래그 때 보드가 가려지지 않아야 한다. 정보 열의 픽셀 폭은 현재 UI 감사 및 3안 설계에서 정한다.
- **가격과 공간 결과를 분리해서 동시에 표현한다.** BB3/ND1/GW6의 물건 근처 가격·판매액, BH2의 산식, GW6의 인접 문장을 조합한다. 어느 한 게임이 `구매/판매 + 두 격자 + 위치 가치 + 타 도시 기회 + 운임`을 모두 해결했다는 증거는 없다.
- **정확한 미래 가격을 이 사례들로 정당화하지 않는다.** 목적지/정보 신선도는 별도 [가격·목적지 조사](TRADE_DESTINATION_LAYOUT_EVIDENCE.md) 범위다. 여기서는 미확인 도시 가격을 노출할 근거가 없다.
