# Trainventory 세계관 기획서

게임의 세계·세력·인물·이야기 전달 방식을 정의한다. 게임 규칙은 [게임 기획서](<게임 기획서.md>), 지금 시스템에서 세계관이 닿을 수 있는 지점과 데이터 위치는 [세계관 작업 안내](Management/WORLD_BRIEF.md)를 본다.

각 항목은 **확정**(사용자가 정한 방향)과 **초안**(제안, 확정 전)을 구분한다. 초안은 확정 전까지 이름·관계·사건을 바꿀 수 있다.

## 1. 확정 방향

| 항목 | 결정 |
|---|---|
| 장르 | 스팀펑크 |
| 시대 | 벨 에포크(근대 산업의 낙관기) |
| 중심 갈등 | 공업 지대의 신흥 세력과 수도권 구세력의 미묘한 신경전 |
| 분위기 | 배경은 밝게 유지한다 |
| 이야기 형식 | 군상극. 이야기의 주인공은 세계의 여러 인물이다 |
| 플레이어 | 그냥 무역을 할 뿐이다. 세력 다툼과는 거래·의뢰를 통해 직간접적으로만 상호작용한다 |

## 2. 톤 원칙 (초안)

- **경쟁이지 전쟁이 아니다.** 다툼은 박람회·특허·신문 1면·유행·노선·살롱 초대장처럼 체면과 자존심을 건 일이다. 폭력·전투·몰락·비극적 결말은 쓰지 않는다. 최악의 결과는 망신·손해·체면 구김이다.
- **진보는 즐겁다.** 전기등·비행선·카페·신문·만국박람회의 시대다. 새것에 대한 설렘을 기본 정서로 둔다.
- **어느 쪽도 악당이 아니다.** 신흥 세력은 시끄럽고 서두르며, 구세력은 거만하고 느리다. 양쪽 모두 매력과 약점이 있고 플레이어가 편을 고르지 않아도 된다.
- **유머는 가볍게.** 기존 품목 설명(똥은 "불쾌한 화물")과 술집의 전해 들은 말투("~대요")를 유지한다.
- **조각으로 읽힌다.** 플레이어는 모든 마을을 들르지 않고 순서도 매번 다르다. 어느 조각부터 봐도 이해되게 쓰고, 다 보지 못해도 결말이 성립해야 한다.

## 3. 시대와 기술의 결 (초안)

| 구분 | 신흥(공업) 쪽 | 구(수도권) 쪽 |
|---|---|---|
| 재료·색 | 구리·황동·주철·리벳, 증기와 그을음, 붉은 벽돌 | 대리석·금박·유리 천장, 크림색·연녹색, 가스등 |
| 상징 기술 | 증기 기관·태엽 자동인형·압력계·기계 팔 | 전신·은행 금고·시계탑·온실 |
| 생활 | 공장 사이렌, 노동자 식당, 발명 경연 | 살롱·오페라·카페 테라스·경마 |
| 말투 | 직설적이고 숫자로 말함 | 정중하고 돌려 말함 |

공통 배경: 철도가 세계를 하나로 묶기 시작한 시기다. 비행선은 하늘의 사치품이고 화물은 아직 기차가 나른다.

## 4. 세력 (초안)

### 신흥 세력: 증기 기관공 연합(가칭)

- 공업 지대의 공장주·발명가·기관사 연합. 자수성가했고 젊다.
- 원하는 것: 수도 만국박람회 본관 전시, 노선 확장, 관세와 면허 규제 완화, 특허 인정.
- 수단: 값싼 기계, 새 기술, 노동자 신문의 여론.
- 약점: 돈과 인맥이 부족하고, 서두르다 사고를 낸다.
- 거점: 에른아 공업역(본산·플레이어 출발지), 노르노바(신도시), 카르포트(수도와 가장 가까운 최전선).

### 구세력: 왕립 상공 협회(가칭)

- 수도권의 은행가·귀족 살롱·전통 길드. 오래된 돈과 품격.
- 원하는 것: 박람회 심사권 유지, 표준과 면허로 질서 유지, 신흥 세력을 "길들여" 자기 질서 안에 넣기.
- 수단: 대출, 인허가, 사교계 평판.
- 약점: 변화를 두려워하고, 실은 새 기계에 끌린다.
- 거점: 금융마을(은행·플레이어의 채권자), 아이포트 중앙(박람회장), 트렌포드(전통 길드).

### 중간 지대

생산 지역은 두 세력이 서로 끌어들이려는 상대다. 지역별 '귀하게 사는 물건'(게임 기획서 5장)을 관계의 근거로 쓴다.

| 지역 | 기울기 | 근거와 정서 |
|---|---|---|
| 광산 | 신흥 쪽 | 공업에 금속을 팔아 벼락 호황. 대신 기계를 비싸게 사야 해 불만도 있다 |
| 목축 | 양다리 | 공업 지대가 먹는 고기를 대고, 수도의 미식 수요도 크다. 금속·곡물이 귀하다 |
| 농업 | 양다리 | 공업 식량 수요로 호황. 기계·금속이 귀해 근대화를 원하지만 수도와의 오랜 거래도 있다. 거름을 사는 유일한 지역 |
| 해안 | 구세력 쪽 | 수도에 생선·소금을 대는 오래된 무역항. 철도가 항로를 대신할까 경계하지만 기계도 귀하게 산다 |
| 일반 마을 | 중립 | 간선 위 경유지. 역 카페에 양쪽 소문이 모인다 |

## 5. 지리와 무대 (초안)

마을 이름은 지금 지도의 역 이름을 그대로 쓴다. 이름은 유럽풍이라 벨 에포크와 잘 맞는다. 실제 노선과 소요 시간은 [세계관 작업 안내](Management/WORLD_BRIEF.md) 3장을 본다.

- **공업 지대**는 지도 한쪽에 모인 굴뚝의 땅이다. 카르포트가 수도 쪽으로 가장 가까운 공업 마을이다.
- **헤일하임**(목축)은 공업 지대에서 수도로 가는 길 대부분이 지나는 교차로다. 양쪽 사람이 가장 많이 스치는 곳이다.
- **메르트**(일반 마을)는 농업 지대를 지나 금융마을로 들어가는 수도의 관문이다.
- **수도권**은 아이포트 중앙을 중심으로 금융마을·디아안·트렌포드·세르그라드가 둘러싼다.
- **해안**은 디아안을 통해 수도와 이어지는 오래된 무역 항로의 땅이다.
- **농업은 저지대, 목축은 고지대**라는 기존 배치 콘셉트를 유지한다.

## 6. 플레이어 (초안)

- 이름 없는 독립 화물 열차 상인이다. 어느 세력에도 속하지 않는다.
- **빚 자체가 두 세력 사이에 끼어 있다.** 에른아 공장에서 만든 중고 화물 열차를 금융마을 은행 대출로 샀다. 신흥 세력의 기차를 구세력의 돈으로 산 셈이다.
- 양쪽 모두 플레이어를 "쓸 만한 운반책"으로 대한다. 플레이어의 거래와 배달이 쌓여 세계의 저울을 조금씩 움직이지만, 플레이어 자신은 장사를 할 뿐이다.
- 대화 선택지나 직접 개입은 두지 않는다. 플레이어의 선택은 **무엇을 어디에 팔았나, 어느 의뢰를 맡았나**다.

## 7. 중심 사건: 수도 만국박람회 (초안)

- 14일째 수도에서 만국박람회가 개막한다. 이날이 플레이어의 상환 기한과 같다.
- 신흥 세력은 본관 전시를 노리고, 구세력은 심사권으로 막거나 길들이려 한다. 신경전은 박람회를 향해 커진다.
- 흐름 예시

| 기간 | 국면 |
|---|---|
| 1~4일 | 인물 소개와 박람회 소식. 각자의 사정이 드러난다 |
| 5~9일 | 신경전 고조. 초대장·관세·특허 시비. 세력 의뢰가 늘어난다 |
| 10~13일 | 출품을 둘러싼 의뢰가 몰린다 |
| 14일 | 개막과 상환. 플레이어의 교역 흔적에 따라 신문 1면과 후일담이 달라진다 |

## 8. 군상극 배역 (초안)

마을마다 술집 단골 한 명을 둔다. 다시 들를 때마다 그 인물의 이야기가 한 걸음씩 나아가는 방식을 기본으로 검토한다.

| 마을 | 인물 | 세력 | 이야기 줄기 |
|---|---|---|---|
| 에른아 공업역 | 젊은 수석 기관사 겸 발명가 | 신흥 | 박람회 출품작인 증기 자동인형을 완성하려 한다. 부품 의뢰를 낸다 |
| 카르포트 | 상공회의소장 | 신흥 | 수도와 가장 가까운 최전선의 협상가. 늘 초조하다 |
| 노르노바 | 노동자 신문 발행인 | 신흥 | 수도를 풍자하는 기사를 쓴다. 소문의 출처가 되기도 한다 |
| 금융마을 | 은행가(플레이어의 채권자) | 구 | 정중하고 우아하다. 실은 신흥 세력의 가능성에 몰래 투자하고 싶다 |
| 아이포트 중앙 | 박람회 심사위원장인 귀부인 | 구 | 전통을 지키려 하지만 새것에 끌린다 |
| 트렌포드 | 시계 장인 길드장 | 구 | 기계에 일을 뺏길까 걱정한다. 구세력의 진짜 이해관계를 보여 준다 |
| 리오브루크 | 정제소장 | 광산 | 금속 붐으로 벼락부자가 되어 양쪽에서 구애를 받는다 |
| 피오아 항 | 원로 선주 | 해안 | 수도의 오랜 납품처. 철도를 경계한다 |
| 이브트 | 농업 조합장 | 농업 | 호황 속에서 양쪽 사이를 줄타기한다 |
| 헤일하임 | 교차로 여관 주인 | 목축 | 양쪽 사람이 모두 묵는 곳. 엇갈리는 인물들을 목격한다 |
| 세르아·메르트 | 역 카페 주인 | 중립 | 양쪽 소문을 모두 듣는 중립 화자. 이야기를 정리해 준다 |

인물끼리 얽힌다. 예: 발명가의 자동인형을 심사위원장이 몰래 보고 싶어 하고, 은행가는 회의소장과 비밀 협상을 한다. 플레이어는 그 사이 화물과 편지를 나르며 모르는 새 다리를 놓는다.

## 9. 이야기 전달 방식 (초안)

플레이어가 무역만으로 세력과 상호작용하도록 기존 장치에 이야기를 싣는다.

| 장치 | 관여 | 방식 |
|---|---|---|
| 술집 의뢰 | 직접 | 의뢰인과 세력을 붙인다. 이어지는 의뢰로 인물 이야기를 진행한다. 가끔 두 세력의 상충하는 의뢰가 같은 시기에 걸려, 어느 쪽을 맡느냐가 선택이 된다 |
| 술집 소문 | 간접 | 가격 소식에 세력 소식(신문 가십)을 섞는다 |
| 거래 흐름 | 간접 | 무엇을 어디에 팔았는지가 세력의 기운을 조금씩 움직인다. 예: 수도권에 기계를 팔면 근대화 바람, 공업에 식량·금속을 대면 신흥 성장. 기운이 소문·의뢰·결말을 바꾼다 |
| 거래 숙련과 평판 | 간접 | 기계·금속 숙련이 높으면 공업, 생선·과일·소금 숙련이 높으면 수도가 플레이어를 알아본다 |
| 마을 작업대 | 무대 | 개조(에른아)는 연합의 기술, 정제(리오브루크)는 광산 호황, 도축(다르폴)은 수도 미식 수요 |
| 이동 중 사건(검토안) | 직접 | 비행선 추월 경주, 신문 기자 합승, 검표원 같은 가벼운 사건 |
| 검문소(검토안) | 직접 | 수도권 관세 검문과 무면허 기계 같은 금지 품목 |
| 철도 투자·기관차 업그레이드(검토안) | 직접 | 연합의 노선 확장 사업과 기술 |
| 결말 | 결과 | 승리 조건(상환)은 그대로다. 박람회 개막일 신문 1면과 인물 후일담이 세력 기운에 따라 달라진다 |

## 10. 미정 사항

| 항목 | 결정할 내용 |
|---|---|
| 고유 명칭 | 세계 이름, 두 세력의 정식 명칭, 박람회 이름 |
| 화폐 | 이름과 단위. 지금 화면은 `$`, 게임 기획서는 "원"으로 섞여 있다 |
| 세력 기운 | 수치로 둘지, 의뢰 문구만으로 진행할지. 수치라면 어떤 거래가 얼마나 움직이고 무엇에 영향을 주는지 |
| 진행 기준 | 날짜에 따라 사건이 열리는 방식, 마을 재방문에 따라 인물 이야기가 나아가는 방식, 또는 둘의 혼합 |
| 박람회와 기한 | 개막일을 상환 기한(14일)과 묶을지 |
| 결말 | 결말 종류의 수, 패배(기한 초과) 시의 이야기 |
| 출발 마을 | 공업 마을 중 출발지를 고르거나 무작위로 정하면 도입부를 어떻게 바꿀지 |
| 판 사이 연속성 | 이야기 진행·숙련을 다음 판으로 이어갈지 |
| 인물 표시 | 초상화·이름 표시·대사 창을 둘지, 지금처럼 문장만 둘지 |
| 배역 확정 | 8장 인물의 이름·성별·관계. 배역이 없는 마을을 둘지 |

미정 항목은 결정 전까지 확정 설정으로 취급하지 않는다.
