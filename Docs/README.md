# 문서 안내

- [게임 기획서](<게임 기획서.md>): 게임 목표·플레이 규칙·지역·경제·화면과 설계 미정 사항.
- [세계관 기획서](<세계관 기획서.md>): 세계·세력·인물·이야기 전달 방식. 작업자용 시스템 안내는 [세계관 작업 안내](Management/WORLD_BRIEF.md).
- [관리 문서](Management/README.md): 현재 구현 상태·기획 대비 차이·개발 과제·기술 및 운영 계약.
- [전체 화면 배치 개편 계획](Research/UI_RELAYOUT_PLAN.md): 확정 레이아웃 [시안 3b](Research/relayout/concept-3b.html)(플랫폼·선로·다이제틱 마을 배경 + 크기 조정·자유 배치 창)와 결정 기록. 현재 화면 목록은 [UI_SCREEN_INVENTORY](Research/UI_SCREEN_INVENTORY.md).
- [과거 자료(Legacy)](Legacy/README.md): 3b 확정 전의 다른 레이아웃 안·조사·목업. 현재 작업 기준으로 사용하지 않는다.
- [행선지 렌즈 구현 계획](Research/ROUTE_LENS_IMPLEMENTATION_PLAN.md): develop 규칙 비교표, 정보 공개 규칙, 렌즈 계산 계층. 화면 배치 부분은 개편 계획으로 대체됐다.

게임 기획서의 원본은 [게임 기획서](<게임 기획서.md>)다. 노션 동기화는 중단했다.

기획서에는 구현 여부·코드 구조·검증 결과·작업 이력을 적지 않는다. 기획이 바뀌면 해당 규칙을 수정하고 실제 반영 여부는 관리 문서에 따로 갱신한다. 미정 설계와 미구현 작업을 구분한다.

루트 [README](../README.md)는 짧은 인수인계 메모, [AGENTS](../AGENTS.md)는 작업 규약이다.
