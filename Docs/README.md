# 문서 안내

- [게임 기획서](<게임 기획서.md>): 게임 목표·플레이 규칙·지역·경제·화면과 설계 미정 사항.
- [관리 문서](Management/README.md): 현재 구현 상태·기획 대비 차이·개발 과제·기술 및 운영 계약.

게임 기획서는 [노션 페이지](https://app.notion.com/p/41400f902d2281849db4c5e61b7f5ac3)를 주 관리 화면으로 사용한다. 로컬 기획서와 양방향으로 반영하며, 프로젝트 작업 시작 시 노션 변경을 가져오고 로컬에서 기획을 바꾸면 같은 작업에서 노션에도 반영한다. 충돌 처리·문서 대응·공통 기준은 [동기화 규칙](Management/NOTION_SYNC.md)을 따른다.

기획서에는 구현 여부·코드 구조·검증 결과·작업 이력을 적지 않는다. 기획이 바뀌면 해당 규칙을 수정하고 실제 반영 여부는 관리 문서에 따로 갱신한다. 미정 설계와 미구현 작업을 구분한다.

루트 [README](../README.md)는 짧은 인수인계 메모, [AGENTS](../AGENTS.md)는 작업 규약이다.
