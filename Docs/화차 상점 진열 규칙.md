# 화차 상점 진열 규칙

## 데이터 원본

- `Assets/Resources/Tables/PuzzleTradeTableData.json`: 화차 상품, 가격, 기능, 무작위 판매 설정.
- `Assets/Resources/Tables/PuzzleTableData.json`: 마을의 지역과 기본 화차 목록(`cities[].wagonProductIds`).
- 판매처 추첨 결과는 게임 세션에 보관한다. 원본 JSON의 마을 목록을 덮어쓰지 않는다.

## 기본 진열

게임 시작 직후부터 모든 마을에 `defaultWagonProductId`로 지정한 일반 화차(`standard`)를 기본 진열한다. 초심자용 화차를 먼저 구매해야 하는 조건은 없다.

기존 마을 목록의 일반 상품과 대형 유개 화차는 그대로 유지하며, 기본 일반 화차는 중복 없이 추가한다. 특수 화차의 기존 고정 배정은 무작위 배정으로 대체한다. 일반 특수 화차와 지역 특색 화차는 기본 진열에 추가로 등장한다. 초심자용 상품 데이터는 남아 있지만 별도 기본 진열 대상으로 지정하지 않는다.

## 지역 특색 화차

상품의 `saleRegionId`에 판매 지역을 지정한다. 게임 시작 시 해당 지역의 마을 중 한 곳을 균등 추첨한다. 상품마다 정확히 한 곳에서 판매하고, 방문·구매·시간 경과로 판매처를 다시 추첨하지 않는다. 새 회차에서는 다시 추첨하므로 이전 회차와 같은 마을이 뽑힐 수도 있다.

| 지역 | 지역 ID | 화차 | 상품 ID | 기능 |
|---|---|---|---|---|
| 농업 | `region.farm` | 텃밭 화차 | `garden` | 곡물과 똥으로 곡물 증식 |
| 목축 | `region.ranch` | 가축 화차 | `livestock` | 배설물을 우선 수납하는 똥 전용칸 |
| 공업 | `region.industry` | 제련 화차 | `smelter` | 나무와 광석 조각으로 금속 주괴 생산 |
| 광산 | `region.mine` | 분쇄 화차 | `crusher` | 큰 광석을 1칸 광석 조각으로 분해 |
| 해안 | `region.coast` | 냉장 화차 | `refrigerated` | 신선 화물 유통기한 소모 완화 |

수도권과 일반 마을권에는 현재 지역 전용 화차를 배정하지 않는다.

## 일반 특수 화차

상품에 `randomSale: true`를 지정하고 `saleRegionId`를 비워 둔다. 모든 지역의 모든 마을에서 후보 중 같은 확률로 추첨한다.

| 화차 | 상품 ID | 기능 |
|---|---|---|
| 광석 호퍼 | `hopper` | 광석·금속 전용 대형 적재 공간 |
| 장물 평판 화차 | `flatbed` | 목재·기계의 운임 적재 칸 면제 |
| 짐칸 화차 | `granary` | Cargo 태그 전용 대형 적재 공간 |
| 소형 냉장 화차 | `coldbox` | 작은 적재 공간과 신선 화물 보존 |

`generalSpecialWagonsPerCity`는 마을당 일반 특수 화차 진열 수이며 현재 **1**이다. 후보 수보다 크면 후보 전체를 중복 없이 진열하고, 0이면 일반 특수 화차를 진열하지 않는다. 같은 상품이 여러 마을에서 판매될 수 있으며, 모든 후보가 회차에 반드시 등장하는 것은 아니다.

이 목록 역시 회차 시작에 정하고 재방문해도 유지한다. 기본 일반 화차(`defaultWagonProductId`)는 항상 첫 번째로 표시하고, 나머지는 가격 오름차순, 동일 가격이면 상품 ID 순으로 표시한다. 구매 가능 판정도 이 목록을 사용한다. 최저 구매 비용은 표시 순서와 별개로 실제 최저 가격을 사용한다.

특수 화차(`randomSale` 또는 `saleRegionId` 지정)는 상점 카드의 이름만 동일한 하늘색으로 표시한다. 크기와 가격은 기존 색상을 유지한다. 색상은 `BasicDataTableData.json`의 `presentation.station.specialWagonName`에서 변경할 수 있다.

## 이번 구현 범위

### 의뢰 보상용 화차 데이터

`PuzzleTradeTableData.json`의 `wagonProducts`에 아래 4종을 준비했다. 모두 막힌 칸과 특수 효과가 없는 직사각형이며, `price`는 칸당 10원 기준 보상 가치다. 상점 판매 목록이나 무작위 판매 후보에는 포함하지 않는다.

| 상품 ID | 이름 | 크기 | 사용 가능 칸 | 보상 가치 |
|---|---|---|---|---|
| `questReward.4` | 4칸 보상 화차 | 2×2 | 4 | 40원 |
| `questReward.6` | 6칸 보상 화차 | 3×2 | 6 | 60원 |
| `questReward.8` | 8칸 보상 화차 | 4×2 | 8 | 80원 |
| `questReward.10` | 10칸 보상 화차 | 5×2 | 10 | 100원 |

JSON의 판매 분류에 따른 회차별 상점 진열, 의뢰 보상 화차 지급, 지역 특수 화차 판매처 소문을 구현한다. 신규 특수 화차 추가는 후속 작업이다.

### 지역 특수 화차 소문

술집 소문 후보는 원본 마을별 화차 목록이 아니라 현재 회차에서 추첨한 실제 판매 목록을 참조한다. `saleRegionId`가 지정된 지역 특수 화차 5종만 대상으로 하며, 일반 특수 화차와 의뢰 보상 화차는 제외한다.

예시: **노르노바에서 특별한 화차를 판다던데… 제련 화차 말이야.** 마을 이름은 지도 링크, 화차 이름은 기존 화차 정보 툴팁 링크다. 소문은 기존 수첩 기록과 미방문 마을의 지도 배지에 반영된다. 소문을 듣기 전에도 판매 마을에서 구매할 수 있다.

시작 마을의 첫 선호 소문은 유지한다. 이후 희귀 수요와 화차 소문 중 후보가 있는 종류를 같은 확률로 추첨하고, 해당 종류 안에서 소문 하나를 무작위로 고른다. 둘 다 없으면 기존 특산·시설 소문으로 넘어간다.

현재 마을, 방문한 마을, 최근 소문을 들은 마을은 기존 후보 제외 규칙을 따른다. 소문 중복 제한은 마을 단위이며 `PuzzleRumorTableData.refreshHours` 이후 다시 후보가 된다(방문한 마을은 계속 제외). 화차 판매처를 재추첨하지 않으며, 기록과 분석 로그에는 화차 상품 ID도 남긴다. 소문 문구는 `BasicDataTableData`의 `presentation.station.wagonRumor`로 관리한다.

### 의뢰 보상 연결 및 지급

`TrainventoryQuestTableData.json`의 의뢰별 `rewardWagonProductId`로 보상 화차를 지정한다. 기존 현금 의뢰 2종은 유지하고 아래 화차 의뢰 4종을 추가했다.

| 의뢰 ID | 화차 보상 | 산정 가치 | 보증금 |
|---|---|---|---|
| `courier.wagon4` | `questReward.4` | 40원 | 20원 |
| `courier.wagon6` | `questReward.6` | 60원 | 30원 |
| `courier.wagon8` | `questReward.8` | 80원 | 40원 |
| `courier.wagon10` | `questReward.10` | 100원 | 50원 |

초기 설정은 각 가중치 1, 거리 2~12, 소포·공구 상자 중 하나 운송, 기한 150% + 12시간이다. 기존 현금 의뢰와 함께 무작위 추첨되므로 한 방문에 모든 화차 의뢰가 보장되지는 않는다.

화차 의뢰의 별도 현금 보수는 0이며, 완료 시 화차를 무료 연결한다. 화물 실제 가치와 보증금은 기존과 같이 현금 지급한다. 숙련 경험치와 보증금 산정에는 현금 보수와 화차 가치의 합을 사용한다. 실패하면 화차를 지급하지 않는다.

연결 한도가 꽉 차면 완료 의뢰에 미수령 상태로 보관한다. 화차를 판매하거나 숙련 상승으로 연결 한도가 늘어나면 오래된 보상부터 자동 연결하며, 같은 보상은 한 번만 지급한다. 기본 연결 한도와 최대 연결 한도를 넘기지 않는다. 수첩의 완료 의뢰에 지급 완료·수령 대기를 표시한다.

의뢰 목록·상세·수첩에서 화차 이름 링크를 제공한다. 마우스를 올리면 기존 `PuzzleItemTooltipView`의 정보 툴팁에 크기, 사용 가능한 칸 수, 보상 가치, 설명이 표시된다. 클릭하면 수첩 의뢰 탭을 연다.

화차 키워드 툴팁은 기존 능력치 행의 좌우 정렬을 사용한다. `크기 / a x b`, `사용가능칸 / n칸`, `가치 / m$`의 세 행을 표시하고, 아래 일반 효과 영역의 제목을 `특수 기능`으로 표시한다. 기능 설명은 `• 설명` 형식으로 표시하며, 기능이 없는 보상·일반 화차는 효과 없음으로 표시한다. 의뢰 보상과 술집 소문의 화차 링크에 동일하게 적용한다.

## 판매처 디버그 도구

Unity 메뉴 `Tools > MyJG > Wagon Shop Debug`를 열고 게임을 실행한다. 현재 회차의 지역 특수 화차별 지역, 판매 마을 이름과 ID를 확인할 수 있다. 게임 시작 직후부터 배정 결과가 보이며, 창을 열거나 새로 그릴 때 재추첨하지 않는다.

`지역 특수 화차 배정표 복사`로 배정표를 클립보드에 복사할 수 있다. `일반 특수 화차 판매처도 보기`를 펼치면 일반 특수 화차의 판매 마을도 표시한다. 플레이 모드 밖이거나 세션 초기화 전이면 안내를 표시한다.
