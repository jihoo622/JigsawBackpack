3. 공통 패키지 — 3안 모두에 선행 적용

거래 요약 패널자동 정렬(방향 선택형)시장 검색·필터Junk 마킹·일괄 매도실패 사유 문구 보강
  • 자동 정렬: 기차 카드 헤더에 버튼. 방향(위→아래 / 왼→오른) 선택형 — Titan Quest AE·Sacred 2 계보. 서비스의 빈자리 탐색(현재 Ctrl 경로)을 재사용, 미리보기 없이 즉시 적용은 유지하되 Ctrl 이동과 동일한 상태 줄 사유를 표시.
  • 시장 검색·필터: 시장 보드 상단 1줄 — 품목명 검색(IME 포커스 시 Esc 우선순위 주의) + 태그·등급 칩 필터. 결과 없음 상태 표시. Diablo IV 스태시 검색·Sacred 품목 탭 계보.
  • Junk 마킹·일괄 매도: 기차 화물 우클릭 메뉴에 "폐기 예정 표시"(Junk) → 시장 열려 있으면 일괄 매도 버튼. D3/D4 Junk 체계. 표시는 프리팹 사전 배치 뱃지로 처리(런타임 생성 금지 유지).
  • 실패 사유 문구 보강: 같은 화차 재배치 등 Direction=None에서도 사유 문장을 반환하도록 Presentation.PuzzleTradeStatus 확장 — "공간 무효/경제 무효가 같은 색" 문제를 텍스트로 중복 전달.
  • 소문 연동 힌트: 시장 보드에서 알고 있는(소문으로 확인된) 태그 등급 배지를 정보 열에 상시 표시 — 정보 수준 4단계(정확/범위/등급/미확인) 중 현재 수준을 라벨로 구분.

4. 레이아웃 3안 예상 와이어프레임

각 안은 같은 시나리오(시장의 2×3 화물을 기차로 구매·배치)의 평상시 / 드래그 중 두 상태를 그린다. 아래 탭으로 안을 전환하고, 각 안 안의 버튼으로 상태를 전환한다.

A안 · 보수안좌우 구조 유지 + 정보 계층·드래그 피드백만 개선

C안 · 재구성안구매·배치·가격·목적지 판단을 하나의 거래 작업 공간으로
기차 보드 5×5 시장 보드 7×6 컨텍스트 패널(신설) 드래그 고스트 주석 ①②③…

7. G1 결정 게이트 — 사용자 확인 항목

  • 선택 안 확정: B안(기본 제안) / A안 / C안 / 보류
  • 거래 컨텍스트 패널의 우선 정보: 도시 규칙 vs 선택 화물(감사서 질문 1) — B안은 "드래그 중에만 화물 우선"으로 절충
  • 드롭 전 비교 기준 수치: 즉시 판매액 / 다음 정산 가치 / 선택 목적지 순익 중 무엇을 보여줄 것인가(질문 2) — B안은 현재 견적만 표시하고 목적지 순익은 목적지 선택 상태로 한정
  • 알려진 도시 정보 수준·유효 기간(질문 3): 소문의 refreshTurns와 동일 수명으로 갈지
  • Ctrl 빠른 이동의 즉시 거래 유지 여부(질문 4) — B안은 유지 + 상태 줄 사유 강화만
  • 다른 화차 동시 노출은 이번 범위에서 제외(질문 5) — 하단 화차 바 드롭 유지

본 문서는 R4 산출물이다. G1에서 안이 확정되면 I1(프로토타입/구현) → V1(시나리오 검증) → V2(독립 리뷰)로 진행한다(조사 계획 §9). 와이어프레임의 좌표·크기는 UI_LAYOUT 계약의 50% 축소값이며 실제 렌더링 측정이 아니다.
