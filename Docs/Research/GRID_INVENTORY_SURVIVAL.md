# 서바이벌 호러·하드코어 서바이벌의 그리드 인벤토리 — UI 레이아웃 조사 (카테고리 B)

조사일: 2026-11-18. 웹 검색(공식 매뉴얼·위키·커뮤니티·패치노트) 기반 2차 요약이며, 실제 플레이·스크린샷 대조는 하지 않음. 불확실 항목은 "(추정)" 표기.
검증 메모: RE4 리메이크 어태케이 케이스 칸수는 자료 간 상이(RE Wiki는 S 6×10 계열, Game8 등 일부는 7×10 계열 표기) — 본 문서는 RE Wiki 기준으로 기록. RE4(2005)는 아이템 박스가 없는 것이 확인됨(초기 검색 요약의 "타자기 아이템 박스" 기술은 오류로 판단해 배제).

---

## 1. Resident Evil 4 (2005, Capcom)
- 장르·플랫폼: 서드퍼슨 서바이벌 호러. GC → PS2·PC·Wii·HD 리마스터 등 전 콘솔.
- 그리드 방식: 어태케이 케이스 테트리스의 원조. 시작 케이스 S 6×10(60칸), 상인에서 M·L로 확장(순차 구매 불필요). 품목별 칸 점유(권총 2×3 등), 90° 회전 가능. 무게 개념 없음 — 순수 공간 퍼즐.
- UI 레이아웃 특징: 케이스를 열면 인벤토리 화면 단독 표시. 드래그&드롭 배치 + 회전 버튼. 인벤토리 열어도 게임이 일시정지되지 않아 "정리하는 동안에도 위험"이라는 긴장 유지. 시리즈 최초로 아이템 박스 폐지 — 케이스가 유일한 저장소, 가득 차면 줍기 자체가 불가하고 바닥에 두거나 상인에게 판매. 탄약 등 소모품은 자동 스택.
- 참고 포인트: ① 케이스 확장을 상점 재화로 파는 구조 — 기차 화물칸 확장을 "역에서 화물칸 구매"로 이식 가능. ② 비일시정지 인벤토리 — 정지 없이 화물 정리를 허용해 시간 압박을 부여하는 옵션.

## 2. Resident Evil 0 (2002, Capcom)
- 장르·플랫폼: 서바이벌 호러. GC, 2016 HD 리마스터(콘솔/PC).
- 그리드 방식: 그리드 테트리스 아님 — 캐릭터별 고정 슬롯형(레베카·빌리 각 8칸 추정). 칸 크기·회전 개념 없음, 무게 없음.
- UI 레이아웃 특징: 시리즈 전통의 아이템 박스를 폐지하고 "맵 자체가 창고" 방식 채택 — 내려놓은 아이템은 맵에 영구 유지되어 나중에 회수 가능. 파트너 2인제: 레베카↔빌리가 서로의 이동식 보관함이며, 아이템 교환은 두 캐릭터가 가까이 있을 때만 가능(교환 제약). 캐릭터 전환과 아이템 인계가 핵심 퍼즐.
- 참고 포인트: ① "세계가 보관함" — 기차 정차지·역사 바닥을 영구 창고로 쓰는 규칙의 원형. ② 교환 제약(만나야만 넘겨줌) — 화물 2곳(기차/마을) 간 직접 이동 불가, 중간 운송 수단 필요 같은 제약 설계에 참고.

## 3. Resident Evil Village (2021, Capcom)
- 장르·플랫폼: 1인칭 서바이벌 호러. PS4/5·Xbox·PC.
- 그리드 방식: 브리프케이스 그리드. 품목별 칸 점유 + 90° 회전 가능(공식 매뉴얼 확인). 무게 없음. 듀크(상인)에서 확장 브리프케이스 구매(10,000 Lei).
- UI 레이아웃 특징: 공식 매뉴얼 기준 — 줍기 시 임시 슬롯이 화면 우측에 먼저 뜨고, 케이스에 넣을지 판단 후 확정(즉시 배치 강제가 아닌 2단계). 자동 정렬 버튼 없음(수동 배치). 클래식 아이템 박스 없음(RE4 방식 계승). PC 모드로 1×1 고정 등 우회 존재.
- 참고 포인트: ① "임시 슬롯 → 케이스 배치" 2단계 줍기 — 화물 칸이 가득해도 일단 받아 두고 역에서 분배하는 UI 흐름 참고. ② 확장 케이스가 상점 최고가 재화 — 화물칸 확장의 가격 설계 벤치마크.

## 4. Resident Evil 4 Remake (2023, Capcom)
- 장르·플랫폼: 3인칭(오버숄더) 서바이벌 호러. PS4/5·Xbox·PC.
- 그리드 방식: 어태케이 케이스 그리드(RE Wiki 기준 S 6×10=60칸 → M 8×10=80 → L 8×12=96). 품목별 다양한 폴리오미노 점유, 90° 회전. 무게 없음.
- UI 레이아웃 특징: 자동 정렬(Auto-Sort) 버튼 신설 — RE 계열 최초의 원클릭 정리. 아이템 툴팁에 스탯·장착 파츠·조합 정보 상세 표시. 케이스 자체가 5종 이상(상점 3종 + 도전과제·에디션 해금 특수 케이스)이며 특수 케이스는 "탄약 드랍률 증가, 회복량 절약 등" 패시브 보너스 제공 — 인벤토리 컨테이너가 장비 카테고리로 승격.
- 참고 포인트: ① 컨테이너 선택이 로드아웃 선택 — "용량만 큰 칸 vs 작지만 패시브 있는 칸"의 트레이드오프를 화차 칸(냉동·특수 화물칸)에 응용 가능. ② 자동 정렬 + 수동 회전의 공존 — 자동 정렬이 있어도 배치 최적화는 유저 몫.

## 5. Signalis (2022, rose-engine)
- 장르·플랫폼: 탑다운 레트로 서바이벌 호러. PC·콘솔.
- 그리드 방식: 그리드 아님 — 고정 6슬롯. 세계관 설정 "Rule of Six(여섯 개 이상 소지 금지)"로 제한을 서사화.
- UI 레이아웃 특징: 클래식 RE식 세이프룸 보관함 왕복 강제. 탄약·회복·도구 중 무엇을 6칸에 넣을지가 매 구간의 전략. 6슬롯 제한은 유저 호불호가 큰 최대 논쟁점(커뮤니티 다수 스레드).
- 참고 포인트: ① 제한을 세계관 텍스트로 정당화 — "화물칸 규격은 철도 규정" 같은 세계관 문서로 제약의 몰입 설명 가능. ② 극단적 슬롯 제한이 난이도가 되는 반면교사 — JigsawBackpack 화물칸 수 기본값 설계 시 벤치마크.

## 6. Dead Rising 시리즈 (2006~2024, Capcom)
- 장르·플랫폼: 좀비 액션 어드벤처(오픈월드 쇼핑몰). 콘솔/PC.
- 그리드 방식: 그리드 아님 — 화면 상단 수평 슬롯 바. 시작 4칸 → 레벨업으로 최대 12칸. 대형 오브젝트(전기톱 사용 중, 잔디깎기)는 슬롯 보유 불가 — "들고 있는 것"과 "가지고 있는 것" 분리.
- UI 레이아웃 특징: DR2~ 무기 결합, DR4는 카테고리 탭 정리 + 잡지 수집으로 근접/사격/투척/음식 슬롯 추가 확장. 슬롯 수 자체가 성장 보상.
- 참고 포인트: ① 슬롯 수를 레벨 보상으로 — 기차 업그레이드(차량 트리)로 화물칸 수 늘리는 구조와 동형. ② 대형 아이템은 "손에 들면 슬롯 밖" 규칙 — 팔레트·기관 부품처럼 장착형 대형 화물의 참고.

## 7. Escape from Tarkov (2017 베타~, Battlestate Games)
- 장르·플랫폼: 1인칭 익스트랙션 슈터(하드코어 서바이벌). PC.
- 그리드 방식: 칸 그리드 + 무게(kg) 병행. 품목별 N×M 칸 점유, 드래그 중 R로 90° 회전. 총중량이 스태미나·이동 속도에 영향(컨테이너 안 물건도 무게에 포함 — Strength 스킬 훈련에 활용됨).
- UI 레이아웃 특징: 우클릭 컨텍스트 메뉴, Ctrl+클릭 퀵이동 등 핫키 세트. 미검사 아이템은 검사(Examine)해야 정보 공개, 팔 골절 시 검사 속도 67% 감소(건강 시스템 연동). 컨테이너 계층 — 리그(조끼)·가방·보관용 케이스가 각자 내부 그리드 보유, 중첩 깊이 제한(가방 안 가방 등 무한 "마트료시카" 방지). 시큐어 컨테이너는 사망해도 내용물 보존(감마 3×3=9칸, 에디션/퀘스트 획득). 자동 정렬 없음 — 의도된 마찰이며 커뮤니티 불만 단골.
- 참고 포인트: ① 미확인 화물 검사(Examine) — 기차에 실리기 전 "정체 불명 화물 검사" 미니 인터랙션으로 이식 가능. ② 중첩 깊이 제한 — "상자 안 상자" 규칙을 명시적 깊이 제한으로 구현한 선례.

## 8. DayZ (2018 1.0, Bohemia Interactive)
- 장르·플랫폼: 1인칭/3인칭 오픈월드 서바이벌. PC·콘솔.
- 그리드 방식: 의복·가방 등 컨테이너별 슬롯 그리드(예: 전투가방 56칸). 품목별 칸 점유, 드래그 중 Space로 90° 회전(일부 슬롯은 방향 고정). 무게 표시 + 수용량(load) 병행, 과적 시 스태미나·이동 페널티.
- UI 레이아웃 특징: 좌측 인벤토리 / 우측 Vicinity(주변 물건) 2분할 패널. 하단 핫바(1~0, 조끼 착용으로 확장). 컨테이너 중첩 — 조끼 안 파우치, 파우치 안 소형 컨테이너 계층. 더블클릭·우클릭 메뉴·끼워넣기(combine). 1.26 패치로 조끼·가방 수용량 대폭 너프 — 슬롯 밸런스를 패치로 조정한 사례.
- 참고 포인트: ① Vicinity 패널 — "지금 화물차 옆 바닥에 있는 화물"을 별도 리스트로 보여주는 레이아웃. ② 의복(옷→조끼→가방) 계층 컨테이너 — 기차 "기관차→화물칸→내부 선반" 중첩 구조 참고.

## 9. SCUM (2020 EA, Gamepires)
- 장르·플랫폼: 오픈월드 하드코어 서바이벌. PC.
- 그리드 방식: 컨테이너별 그리드 + 컨테이너별 kg 무게 한계의 이중 제한 — 칸이 남아도 무게 초과 시 적재 불가. Ctrl+휠로 회전. 임시 가방 4×6 등 컨테이너마다 그리드 규격 상이.
- UI 레이아웃 특징: 가방·조끼·홀스터·옷 주머니까지 의복 레이어별 독립 컨테이너. 신진대사/체중 시스템과 연동되어 캐릭터 자체가 컨테이너. 공식 위키에 컨테이너별 그리드×무게 한계×최대 용량 표(Storages Tables) 존재 — 데이터가 표로 정리될 만큼 규격이 명확.
- 참고 포인트: ① "칸 수 × 무게" 이중 한계 — 기차 화물칸에 "칸 + 톤수" 두 게이지를 두는 설계의 직접 레퍼런스. ② 컨테이너 규격표 UI — 도감 형식으로 화물칸별 규격을 문서화하는 방식 참고.

## 10. Dark and Darker (2024 EA, Ironmace)
- 장르·플랫폼: 던전 익스트랙션 PvPvE. PC.
- 그리드 방식: 기본 16칸 그리드 + 착용 가방 최대 4개. 품목별 직사각 점유, 회전 없음(커뮤니티 요구가 가장 많은 부재 기능). 무게 없음 — 순수 공간 퍼즐. 가방은 가방 안에 못 넣고 "접기" 규칙 필요(중첩 제한).
- UI 레이아웃 특징: 가방을 열면 가방 내부 그리드가 추가 렌더링. 금화·보석도 칸을 차지 — 화폐가 곧 공간 압박. 퀵슬롯은 3칸 세트 단위로 2세트 전환(3/4키). 스태시(계정 창고)는 세션 간 보존.
- 참고 포인트: ① 회전 없는 그리드도 성립함 — 회전을 빼고 슬롯을 줄이면 배치 난이도가 아니라 선택 압박이 난이도가 됨. ② 화폐가 칸 차지 — 기차에서 "현금 상자도 화물칸 점유" 규칙의 선례.

## 11. The Cycle: Frontier (2022, Yager — 2023 서비스 종료)
- 장르·플랫폼: F2P 익스트랙션 PvPvE. PC.
- 그리드 방식: 그리드 + 무게 병행. 무기 2슬롯·방어구·헬멧 등 전용 슬롯 + 가방 티어별 그리드 칸 수·무게 한계 동시 확장.
- UI 레이아웃 특징: 세이프 포켓(사망 시 보존되는 소형 그리드) — 최소 전리품 보장 장치. 가방 업그레이드를 맵 파밍/상점으로 획득.
- 참고 포인트: 세이프 포켓 — "사고 시 손실 화물 중 보호되는 소형 금고칸"을 기차 룰에 도입할 수 있는 사례.

## 12. Gray Zone Warfare (2024 EA, MadFinger Games)
- 장르·플랫폼: 오픈월드 익스트랙션 FPS. PC.
- 그리드 방식: 테트리스 그리드 없음 — 컨테이너(리그·파우치·가방)별 고정 슬롯 + 무게 중심. 무게는 은닉 스탯으로 20kg 미만/20~32kg/33kg+ 임계 구간이 기동성·스태미나·조준 안정성을 지배(커뮤니티 검증 가이드 기준).
- UI 레이아웃 특징: 컨테이너 열람형 UI, 무게가 화면 직접 노출이 약해 "알아야 하는데 안 보인다"는 평. 방탄복 중량 차이(약 4kg vs 14kg급)가 로드아웃 설계의 핵심.
- 참고 포인트: ① 무게 임계 구간(초과 시 급격한 페널티) — 기차 중량 게이지에 구간식 페널티 적용 참고. ② 무게를 숨기면 유저가 불편해함 — 중량은 상시 가시화가 정답이라는 부정적 선례.

## 13. The Forever Winter (2024 EA, Fun Dog Studios)
- 장르·플랫폼: PvE 익스트랙션 서바이벌 TPS. PC.
- 그리드 방식: 자유 그리드 아님 — 리그(운반 장비)별 전용 슬롯 조합(건랙·대형/중형 아이템 슬롯·소/중/대 컨테이너). 무게 시스템 병행. 캐릭터 클래스별 리그 제한.
- UI 레이아웃 특징: 추출 성공 시 "Move to Stash"로 리그 내 물품을 일괄 이송. 허브(The Innards)에서 저장 유닛 구매(예: 저장 무게 26.4)로 스태시 확장. 무게/운반 시스템은 커뮤니티가 "가장 불투명한 시스템"으로 꼽는 수준 — 가이드 영상이 별도로 존재.
- 참고 포인트: ① 리그=슬롯 프리셋 — "화물칸 종류(냉동·벌크·특수)별 슬롯 배치 프리셋" 설계에 직결. ② 추출 후 일괄 이송 버튼 — 정산 화면의 원클릭 정리 UX.

## 14. Zero Sievert (2022 EA, CABO Studio)
- 장르·플랫폼: 탑다운 익스트랙션 서바이벌. PC.
- 그리드 방식: 타르코프식 칸 그리드 + 무게. 가방·리그 내부 그리드, 품목별 점유.
- UI 레이아웃 특징: 자동 정렬 버튼이 존재하나 "정렬 옵션을 골라도 쓸모없다"는 평가 — 정렬 품질이 낮으면 무용. 스태시는 작업대 업그레이드+퀘스트로 최대 14탭 확장. 후반부엔 스태시 관리가 플레이 시간 대부분이라는 커뮤니티 불만, 모드(ZS Stash Manager — 가격/무게/유형/수량 정렬·검색)로 보완.
- 참고 포인트: ① "자동 정렬은 있으면 무조건 좋다가 아님" — 정렬 알고리즘 품질이 UX를 결정한다는 반증 사례. ② 스태시 탭(카테고리 페이지) 확장 — 역 창고를 탭 구조로 정리하는 방안 참고.

## 15. Project Zomboid (2013 EA → B42, The Indie Stone)
- 장르·플랫폼: 아이소메트릭 좀비 서바이벌. PC.
- 그리드 방식: 바닐라는 그리드 아님 — 리스트형 2분할 창(좌: 내 인벤토리, 우: 열린 컨테이너). 무게(kg) 중심이며 상한이 근력 스탯·착용 의복에 따라 변동. 그리드는 모드(B42 GridInventory 등)로 제공 — 타르코프식 공간 점유·스택·무게 표시를 얹는 형태.
- UI 레이아웃 특징: Ctrl+클릭 다중 선택 일괄 이동, 창별 핀/고정(접기) 상태 저장. 컨테이너 열람 시 좌우 비교형 — "내 것 vs 창고" 나란히 보기가 표준.
- 참고 포인트: ① 적재 한계가 캐릭터 성장(근력)에 연동 — 기차 적재 한계를 업그레이드(기관부·차륜)로 늘리는 구조와 동형. ② 좌우 나란히 비교 2분할 — 기차칸↔역 창고 이동 UI의 기본형.

## 16. Sons of the Forest (2023 EA, Endnight Games)
- 장르·플랫폼: 1인칭 오픈월드 서바이벌 호러. PC.
- 그리드 방식: 그리드/칸 개념 없음 — 노란 공예 매트 위에 아이템을 실물처럼 펼쳐 배치하는 공간형 인벤토리.
- UI 레이아웃 특징: 백팩을 매트 중앙으로 드래그하면 퀵셀렉트 슬롯 지정 — 슬롯 배정 행위 자체가 매트 위 조립. 가방↔가방 물건 이동도 매트 위에서 처리. 다이어제틱(세계물) 인벤토리의 대표작.
- 참고 포인트: 화물칸 UI를 "창문 너머 실제 화물" 뷰로 보여주는 다이어제틱 접근 — 그리드 추상화와 실물 뷰의 혼용 참고.

## 17. Starfield (2023, Bethesda Game Studios) — 비그리드 대조
- 장르·플랫폼: SF 오픈월드 RPG. PC·Xbox.
- 그리드 방식: 그리드 없음 — 카테고리 탭 리스트. 무게(mass) 중심, 초과 시 이동 불가. 선박 카고홀드로 저장을 외장(Ship Builder로 무게 한계 대폭 확장).
- UI 레이아웃 특징: 즐겨찾기(Favorites)→Q/십자키 퀵슬롯. 개인 한계 초과분은 선박·거점 컨테이너로 외부 위임이 표준 운용.
- 참고 포인트: "개인 인벤토리 + 외장 화물(선박)" 2계층 — 기차=외장 화물 컨테이너 자체인 JigsawBackpack과 대비되는 구조로, 개인 소지분/화물칸 분리 UI 참고.

## 18. Stalcraft (2022, EXBO) — 무게제 대조
- 장르·플랫폼: F2P 오픈월드 슈팅(S.T.A.L.K.E.R.류). PC.
- 그리드 방식: 그리드 없음 — 무게제(현재/과부하/최대 무게 표시). 타르코프류임에도 칸 퍼즐을 채택하지 않은 사례.
- UI 레이아웃 특징: 스태시 리워크 패치로 창고 구성 대개편. 무게 3단 게이지 표시.
- 참고 포인트: 같은 장르에서 그리드 대신 무게제 선택 시 UI가 단순해지는 대신 공간 전략이 사라짐 — 그리드 채택 근거로 인용 가능.

## 카테고리 B UI 트렌드 요약
- 양대 문법: 칸 퍼즐(RE 계열·DaD — 공간 자체가 자원) vs 무게제(DayZ·SCUM·GZW — 중량이 기동성 페널티). 익스트랙션류는 칸+무게 병행(Tarkov·TFC·ZS)이 표준.
- 확장은 상점/장비 티어로 판매: 케이스 S→M→L(RE4R·Village), 가방 티어(DayZ·TFC), 리그 교체(TFW) — 컨테이너 확장 자체가 진행 보상이며 RE4R처럼 패시브 있는 특수 컨테이너로 선택 폭 확대.
- 회전 여부가 난이도 설계: RE·Tarkov·DayZ·SCUM은 허용, DaD는 부재 — 회전 없는 게임은 기본 칸수를 줄여 선택 압박으로 대체.
- 공통 조작 세트: 드래그&드롭 + 퀵이동(Ctrl+클릭), 우클릭 컨텍스트 메뉴, 호버 툴팁(칸·무게·스탯), 컨테이너 중첩은 깊이 제한으로 무한창고 방지, 미확인 아이템 검사(Examine).
- 패배 비용 완화 장치가 UI에 명시: 시큐어 컨테이너·세이프 포켓(사망 보존), 추출 후 "Move to Stash" 일괄 이송. 자동 정렬은 존재해도 품질이 나쁘면 평가 감점(Zero Sievert) — 품질 기준이 높음.
