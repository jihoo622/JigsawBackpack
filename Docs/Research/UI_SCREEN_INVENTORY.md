## 21. 교차 화면 분석 — 거래 중 필요한 정보의 현재 위치

플레이어가 **시장 거래(구매·적재·판매·다음 행선지 결정)**를 수행할 때 반드시 확인해야 하는 6가지 핵심 정보가 현재 UI에서 어디에 흩어져 있는지 정리한다.

| 필요 정보 | 현재 표시 위치 | 문제점 및 개선 여지 |
|---|---|---|
| **가격** (구매가 / 판매가 / 예상 금액) | • **화물 드래그 중**: 좌측 하단 `RouteLens/Trade` (`구매 13$`)<br>• **호버 시**: `PuzzleItemTooltip/Body/BuyRateRow` (`판매 금액 31$`)<br>• **시장 보드 기본 상태**: **미표시** | 시장 보드 위 아이템 자체에 가격 라벨이 없어, 집어 들거나 툴팁을 띄우기 전까지 가격 비교가 불가능하다. |
| **등급 / 시세** (물가 · 선호 · 풍부 · 희귀) | • **현재 도시**: 시장 패널 상단 `MarketInfoPanel` (`물가 125%`, `선호 130%` 등)<br>• **방문/소문 도시**: 지도 호버/하단 정보, 수첩 `소문` 탭, `RouteLens` `방문 도시`/`소문 도시` 탭 | 현재 도시 시세와 타 도시 시세가 시장·지도·수첩·렌즈 4곳에 흩어져 있어, 한 화면에서 "여기서 사서 저기에 팔면 이득인가"를 바로 보기 어렵다. |
| **시너지** (인접 보너스 / 상성 규칙 / 다음 정산 예상) | • **기차 보드 상단**: `BoardValue` (`화물 현재 가치`)<br>• **상단 HUD 시계**: `Settlement` (`정산 1턴 · 예상 +N$`)<br>• **호버 시**: `PuzzleItemTooltip` (`현재 적용 효과`)<br>• **드래그 시**: `RouteLens` + 보드 위 `① ② ③` 후보<br>• **전체 규칙**: 수첩 `상성표` 탭(전체 화면 덮음) | 전체 상성표를 열면 기차 보드와 시장이 가려지고, 드래그 중 예상 정산 수치와 상단 HUD 정산 수치가 멀리 떨어져 있다. |
| **목적지** (다음 역 · 경로 · 이동 비용/시간) | • **우측 패널**: `지도` (`PuzzleWorldMap`, `RoutePlan/Card`)<br>• **진입 버튼**: 행동 목록 `다른 역으로 이동` + 하단 `지도` 버튼 | 지도를 열면 시장이 닫히고 시장을 열면 지도가 닫혀, 화물을 보면서 다음 목적지 시세·운임을 대조할 때 화면 전환이 잦다. |
| **자금** (보유 자금 · 거래 후 잔액 · 목표 자금) | • **최상단 HUD 우측**: `City Navigation/Funds` (`보유 자금 200$`), `Game Clear Button` (`결산 · 목표 1,500$`)<br>• **드래그 중**: 좌측 하단 `RouteLens/Trade` (`잔액 200 → 187$`) | 거래 액션이 일어나는 중앙·우측 시장 보드와 보유 자금 표시(최상단) 사이의 시선 이동 거리가 크다. |
| **기한** (남은 일수/턴 · 현재 시각 · 낮/밤) | • **최상단 HUD 중앙-좌측**: `DeadlineCard` (`D-14 · 56턴`), `Game Time` (`1일 오전 · 낮 · 1턴` + `DayNightBar`)<br>• **의뢰 기한**: 수첩 `의뢰` 탭, `ActiveQuestSummary` 요약 띠, 술집 게시판 | 남은 전체 런 기한(상단)과 개별 의뢰 기한(우측 요약 띠/수첩), 이동 소요 턴(지도)이 분리되어 있어 한눈에 일정 계산을 하기 어렵다. |
