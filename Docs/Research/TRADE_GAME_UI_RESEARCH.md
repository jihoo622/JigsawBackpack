# 무역·시장 게임 10선 — 화면/UI 레이아웃 및 시장·거래 UI 구조 조사

조사일: 2026-11-14. 웹 검색(Steam 커뮤니티/공식 블로그/위키/리뷰) 기반 2차 요약이며, 실제 스크린샷 대조는 하지 않음. 불확실 항목은 "확인 안 됨".

---

## 1. Anno 1800 (Ubisoft, 2019)
- **반응**: 압도적 긍정적으로 평가받는 상업적 성공작. 다만 거래 화면 세밀함은 유저 불만 단골(스레드 다수).
- **거래 화면**: 섬별 창고/시장 패널에서 항목별 요청·제안량을 톤 단위로 표시. 무역 루트 편집기는 루트 단위 Import/Export 토글 + 자동 매매 설정. NPC 상대는 톤당 고정 오퍼 리스트.
- **시세 표현**: 플레이어 간 자유 시세판은 없고, 고정가 + 톤 단위 수량/가격표 위주. 상승/하락 화살표 같은 시세 디자인은 거의 미사용(확인 안 됨).
- **경로/운송 UI**: 지역(리전) 지도에 섬 노드 + 무역 루트 항로 선. 루트 선택 시 경유지와 적재 화물이 리스트로 열거. 하역/적재 방향을 색으로 구분해 달라는 요구가 많았음.
- **HUD**: 상단 바에 현금·인구· 자재(icon) 좌→우 배열. 루트/선박 정보는 지도 오버레이로 통합.
- **특이점**: "도시 건설이 주력, 거래는 보조" 구조. UI는 장식 최소화(공식 UI devblog)하고 톤 단위 정량 표시로 정보 설계 집중.

## 2. Anno 1404 / Venice (Ubisoft, 2009/2010)
- **반응**: 시리즈 명작으로 꾸준히 긍정. 다만 무역 화면은 "버전 따라 직관성 편차" 평.
- **거래 화면**: "함선·무역 루트" 메뉴에서 루트 생성 → 경유지 4개 이상 추가, 정박지별 상단(매수)/하단(매도) 슬롯 방식. 루트 상세를 보려면 화면 전환이 필요해 당시 "엉망"이라는 비판이 있었다.
- **시세 표현**: 가격 그래프 없음. 항목별 재고 부족/과잉을 아이콘·색으로 표시. 구체적 시세 위젯은 확인 안 됨.
- **경로/운송 UI**: 필드 지도 위에 무역선과 항로가 실제 항해로 그려지고, 도시 리스트보다 지도 중심.
- **HUD**: 상단 현금·인구 바. 창고 패널에서 재고 확인.
- **특이점**: 후속작(1800) 무역 UI의 원형. "루트=경유지 시퀀스 + 각 역의 살/팔 항목"이라는 문법을 확립.

## 3. Patrician IV (Gaming Minds/Kalypso, 2010) — Steam Special Edition
- **반응**: 대체로 긍정("장르 내 기본 거래가 가장 좋다"는 평). 낡은 UI는 감점 요인.
- **거래 화면**: 도시 화면의 거래 탭에서 ** convoy↔마을 슬라이더**로 매수/매도량을 즉시 조절. 항목별 **4-dot(다이아) 지표**로 도시 공급 수준·거래가 도시 경제에 미치는 영향 표시. 1-diamond 가격대가 매도 기준가로 쓰임.
- **시세 표현**: 상품 목록 화면에 전 도시 생산·매수/매도 가능 여부 표형 표시. 가격대(75%/100%/125%) 개념이 UI에 반영.
- **경로/운송 UI**: 무역 루트 편집기가 강력 — 도시별 적재/양하 항목·수량·**가격 상한 조건**(예: "곡물 300개, 최대가 41")까지 지정. 거점 간 항로는 지도에 실선.
- **HUD**: 상단 현금·명성·일자. 함선 화면에 선적 화물 칸 표시.
- **특이점**: "조건부 자동 거래 규칙" UI의 교과서. 공급 영향 4-dot 지표가 buy-low-sell-high 판단을 보조.

## 4. Rise of Venice (Gaming Minds/Kalypso, 2013)
- **반응**: 평범~혼재. "저가매수-고가매도 코어는 즐거우나 UI 성급" 이 공통 평.
- **거래 화면**: 도시(시장 광장) 클릭/중클릭 → 시장 메뉴에서 항목별 사기/팔기. 암시장 탭 별도. 사용된 함선·창고와 재고 리스트 연동. 스투어드(대리인) 자동매매 기능은 부실하다는 혹평.
- **시세 표현**: 항목별 재고·수요 표시는 있으나 그래프·추세선 부족. 가격 변동은 도시 만족도/수요 아이콘 위주.
- **경로/운송 UI**: 동지중해 15개 도시 지도, 도시 노드 클릭형. 호송선단 이동 경로는 지도 실선. 도시 간 가격 비교 리스트 화면 있음(세부 확인 안 됨).
- **HUD**: 좌상단 현금·시간, 함선 화물칸은 인벤토리 패널.
- **특이점**: Venice DLC 확장성(노선 편집·블랙마켓)은 있으나 UI 완성도가 발목 — "기능은 있는데 배치·흐름이 거칠다"의 사례.

## 5. Port Royale 4 (Gaming Minds/Kalypso, 2020)
- **반응**: 혼재(긍정 50%대). 거래 시스템은 단단하나 반복적이라는 평.
- **거래 화면**: 도시 인터페이스의 거래 탭. **Standard(자동) 버튼** 하나로 "이 도시에서 생산하는 건 사고, 아닌 건 팔기" 자동 설정. 커스텀 모드는 항목별 매수/매도 잔량·조건.
- **시세 표현**: **4-pip(막대 4칸) 희소성 지표**로 상품 수급을 즉시 표시(리뷰에서 정보디자인의 하이라이트으로 언급). 커뮤니티가 수요 계산 스프레드시트를 만들 만큼 내장 비교 기능은 부족.
- **경로/운송 UI**: 카리브 지도에 도시 노드·항로, 교역로(route) 편집 창에서 경유 도시 순서와 매매 규칙 정의.
- **HUD**: 상단 현금·영향력·일자, 함대 화물은 함선 카드형.
- **특이점**: "생산 구조 기반 원터치 자동 무역"과 희소성 pip 인디케이터. 가격 그래프보다 재고 게이지로 의사결정 유도.

## 6. The Guild 3 (Tricore/THQ Nordic, 2017, EA→정식)
- **반응**: 혼재. 생활·경제 시뮬 매력 대비 UI 불편 불만 다수.
- **거래 화면**: 도시의 시장(Marketplace) 건물로 이동 → "Open market" 창에서 품목별 매수/매도 목록과 가격. **장바구니 아이콘 상/하 방향이 사는 건지 파는 건지** 헷갈린다는 Steam 불만이 대표적.
- **시세 표현**: 품목별 현재가 숫자 + 수급에 따른 변동. 가격 그래프 없음(확인 안 됨). 생산 원가 대비 마진은 건물/생산 체인 화면에서 관리.
- **경로/운송 UI**: 도시 간 이동은 3D 필드(마차/행렬)이고, 시장 데이터는 도시 단위 창. 다중 도시 시세를 한눈에 보는 비교 시세판은 빈약.
- **HUD**: 우측/상단 캐러밴 패널에 현금·식량·인구. 계절·시간 표시.
- **특이점**: "시장=물리적 장소(건물)"라는 공간 배치형 설계. 아이콘 의미 불명확 사례로 자주 인용됨.

## 7. Merchant of the Skies (Coldwild, 2019)
- **반응**: Very Positive(약 87%, 1.4천+건). cozy한 비행선 무역 시뮬로 호평.
- **거래 화면**: 부유 섬 도시에 도착하면 **전 품목 가격이 한 화면 리스트에** 노출 — 행 단위 좌(매수가)/우(매도가) + 수량 슬라이더/Max 버튼. 재고는 비행선 화물칸(스택 슬롯)에 아이콘 그리드.
- **시세 표현**: 수요·공급 기반 실시간 가격 변동 + 가격 편차(spread) 모드. 도시 간 가격 차이를 리스트 비교로 파악(그래프 없음).
- **경로/운송 UI**: 월드 지도에 섬/도시 노드와 항로, 미탐사 영역은 페그(Fog). 자동 항해 경로 표시.
- **HUD**: 상단 현금·식량·체력/시간 게이지. 화물 공간은 비행선 교체 시 전략 자원이 됨.
- **특이점**: 인디 미니멀 시장의 표본 — "가격 리스트 한 장 + 지도"로 완결. 멀티선단 운영·섬 구매 등 확장 요소.

## 8. X4: Foundations (Egosoft, 2018~EA)
- **반응**: 초기혼재→현재 긍정권. 정보 과잉·학습곡선 가파름이 단골 주제.
- **거래 화면**: 정박 시 **Market/Trade 창** — ware별 재고·평균가·매수/매도 호가를 테이블로, 슬라이더로 수량 지정. 함선 운전자에게 우클릭 "Buy in/Sell in"으로 지역-ware-가격 조건의 반복주문(자동 무역로) 부여.
- **시세 표현**: **가격 숫자 색 코딩**(짙은 초록=플레이어에게 유리)과 평균가 기준 표시. 지도의 **Trade 오버레이/필터**로 ware별 공급가 분포를 지도 위 색상으로 직접 보여주는 것이 최대 특징.
- **경로/운송 UI**: 은하=섹터 노드 지도. 스테이션 저장 바가 파랑(현재재고)+초록(도래 예정)+갈색(반출 예정)으로 예약 물량까지 시각화.
- **HUD**: 상단 현금·시간, 함대/무역 현황은 통계·mod(Trade Analytics)로 보완하는 문화.
- **특이점**: "시세판이 지도 위에 얹힌" 유일 사례급. 거래 조건(가격 임계)이 UI 일급 객체.

## 9. Airport CEO (Threshold, 2021 정식)
- **반응**: 긍정(약 7~8천 건, Mostly Positive). 2022 대규모 UI 개편으로 "무거움" 개선, 다만 반응은 반반.
- **거래 화면**: 자유 시세판 없음 — 항공사·지상조업·정부와 **계약 카드 리스트**(수익·위반 조항·기간 표시)로 시장 거래를 대체. 재무 창에 손익·대출 표.
- **시세 표현**: 가격 그래프 없음. 게이트/보딩Bridge/주차 등 용량 부족을 색·아이콘 오버레이로 표시.
- **경로/운송 UI**: 3D 공항 부지가 곧 UI. 여객 동선(체크인→보안→게이트) 오버레이, 노선(취항지)은 공항 리스트 창.
- **HUD**: 상단 바에 현금·평판·날짜·여객 수요. 알림/메일 리본.
- **특이점**: "거래=계약 체결"로 치환한 관리 시뮬. 시세표 없이 수급 게이지·계약 조건표로 경제적 선택을 유도.

## 10. Rise of Industry (Dapper Penguin/Epic, 2019)
- **반응**: 긍정 약 73%. 물류 깊이는 호평, 콘텐츠·운영(스튜디오 폐업) 우려.
- **거래 화면**: 도시 패널에 품목별 **현재 시세 + 시장가 대비 %** 리스트. 스팟 시장에서 원자재 즉시 매수, 타 기업과 **계약(정기 인도, 시장가 대비 116~127% 등 % 기준)** 창 별도.
- **시세 표현**: 가격 추세(시장가 대비 %·상승/하락 화살표) 중심, 가격 히스토리 그래프 제공 여부 확인 안 됨.
- **경로/운송 UI**: 오픈월드 맵에 트럭/열차/함대 실이동, 창고·인수 거점 아이콘. 노선은 화물 종류별 수송업체 화면에서 지정.
- **HUD**: 상단 현금·일자, 선택 건물 우측 패널에 재고·수율.
- **특이점**: "공급망 시뮬 + B2B 계약 UI". 시세는 숫자%로, 수익성은 계약 조건으로 드러내는 재무적 정보디자인.

## 공통 레이아웃 패턴 요약
- **시세판 = 표(테이블) 한 장**: 행=품목, 열=매수/매도가·수량·상태. 도시/거점 전환은 좌측 리스트나 상단 탭. 도시 간 시세 비교는 "같은 표를 도시별로 넘겨보기" 방식이 지배적(비교 전용 뷰는 X4 지도 오버레이 정도).
- **거래 버튼은 행 인라인 + 슬라이더/Max**: 별도 확인창 없이 행 안에서 수량 조절→즉시 체결(Patrician 슬라이더, MotS Max 버튼). 실수 방지보다 속도 우선.
- **가격 그래프는 거의 없다**: 대부분 "현재가 + 수급 인디케이터"로 대체 — Patrician 4-dot/다이아 가격대, PR4 4-pip, X4 가격 색 코딩, RoI 시장가 대비 %. 추세보다 "지금 싼지 비싼지"의 즉시 판정.
- **경로는 지도 노드 + 루트 편집 창 2계층**: 지도(섬/도시/섹터와 항로 실선)에서 공간 인식, 별도 편집 창에서 "경유지 순서 + 역별 살/팔 항목·수량·가격조건". X4의 Buy-in/Sell-in, Patrician의 규칙 편집이 정점.
- **HUD는 상단 고정 바**: 현금·(인구/평판)·날짜/시간을 우측 또는 좌측에, 화물 재고는 함선/창고 인벤토리 패널(아이콘 슬롯)이라는 3분할이 표준.
- **자동화가 UI complexity의 주축**: 초기엔 수동 사고팔기, 중후반은 조건부 자동 루트(가격 임계·생산기반 원터치)로 이행. 자동 규칙의 조건 입력 UI가 곧 게임의 깊이이며, 이 부분이 부실하면(Rise of Venice) 평가에서 감점.
