# 턴제 덱빌딩 피벗 계획

## 목표와 범위

- 1턴=3시간 턴제 위에서 게임을 **숙련도·평판 중심 + "화물 구성 = 덱 콤보" 덱빌딩**으로 재편한다.
- 승리 조건(112턴 빚 상환)은 유지한다. 숙련·평판이 상환을 빨리·여유롭게 만드는 성장 축이다.
- 기존 시스템을 재활용한다: 숙련도(태그별 레벨·가격 보정), 태그 기반 시너지 규칙, 평판 게이트(의뢰 슬롯).
- 노션 반영·프리팹 작업·경제 재측정·SmokeCheck는 이 계획 밖(사용자 요청 시).

## 진행 현황(2026-11-18, 오케스트레이션 5단계 완료)

- 1단계(이동 1턴): `EvaluateTravel` 소모 턴=1, `PuzzleRoutePlanner` 가중치=홉 수, `ShortestTravelTurns`=최단 홉 수, `QuoteRoutePlan` 총 턴=구간 수, `PreviewTurns`=1. 의뢰 테이블 홉 기준 재조정(fresh 2~4·칸당 3, parcel 3~7·칸당 2). 커밋 50bcb1d.
- 1단계(역 행동): 술집·화차 진입 무료화(TryEnterFacility는 시장 전용), 소문 청취 `ListenRumor` 1턴·청취마다 기록(lastRumorVisit 제한 폐지), 화차 구매 1대당 1턴(검증→턴→객차 순서, 시뮬레이터 경로 `_spendsTurn: false`), 버튼 게이트·라벨 정리. 커밋 0c2c4f8.
- 1단계(표기·분석): 이동 확인창·견적·프리뷰·지도 정보를 1턴/거리 기준으로, 지도 노선 라벨은 "거리 N"(`presentation.map.routeDistance` 신설), 에디터 라벨 3종 동일, `PuzzleTimeManager.TravelTurns` 삭제, EconomySimulation/Probe 홉·거리 분리. 커밋 df70c98.
- 2단계(평판 게이트): `reputationLevels[].wagonLimitBonus`(평판 4→+1, 8→+2), `wagonProducts[].requiredReputation`(냉장 화차=평판 2), `MaxWagonCount` 계산 프로퍼티, `rules.wagon.locked`, 수첩 숙련 탭에 다음 게이트 표시. 커밋 1e9b121.
- 3단계(덱 콤보): 인접 가치 시너지 재활성(비활성화 계획의 역순), 숙련 콤보 보강 `proficiencyComboPercentPerLevel`(기본 1.0 — 규칙 대상·발생원 중 숙련 태그 레벨 합 × 계수를 multiplier에 %p 보강, 조회 델리게이트 훅으로 주입해 보드는 세션 상태 미보유), 수첩 상성표 탭 빌드 요약(태그 분포 + 성립 콤보 + 보강치; 상성표 닫힘→수첩 닫힘 결합만 제거). 커밋 09a5200.
- 후속 조정(2026-11-18, 사용자 피드백): 시작 화차를 5×5 전체 25칸으로 복원, 소문 재생 주기 신설(`refreshTurns` 잠정 16턴)과 소식 없음 안내, **시설 진입 전면 무료화**(시장 포함 — `TryEnterFacility`·`IsFacilityEntry` 제거), 도축·정제 확인 비용 10$ 부여(개조는 기존 모드당 150$ 유지). 커밋 cfcad04·이후 커밋.
- 검증: 단계마다 런타임·에디터 `dotnet build` 오류 0, JSON 파싱 통과. 플레이 확인은 사용자.

## 규칙 요약(피벗 후)

| 행동 | 턴 | 비고 |
|---|---:|---|
| 이동(노선 1구간) | 1 | 운임 = 기본요금 + 거리(route.turns)×단가 + 점유 칸×적재 단가 |
| 시장·술집·화차 시설 진입 | 0 | 시장은 밤에만 못 들어감. 들어가 있는 동안 거래 무료 |
| 술집·화차 시설 진입 | 0 | 화면을 여는 데 턴 없음 |
| 소문 듣기 | 1 | 청취할 때마다 기록. 들을 소문이 없으면 턴 소모 없음 |
| 화차 구매 | 1 | 1대당. 냉장 화차는 평판 2 필요 |
| 휴식 | 1 | 기존과 같음 |
| 작업대 확정(도축·정제·개조) | 1 | 확정한 턴이 지나면 수령 |
| 의뢰 수락·거래·배치·증차 외 조작 | 0 | 기존과 같음 |

- 의뢰 거리는 최단 이동 턴(=최단 홉 수) 기준. 보상 = baseReward + rewardPerCellTurn × 칸 수 × 홉 수, 기한 = 홉 수 × deadlinePercent(올림) + deadlineExtraTurns.
- 덱 파워: 화물 배치 콤보(인접·보드 시너지) × 숙련 보강. 숙련(구매·판매로 축적)이 특정 태그 콤보를 강화하고, 평판(숙련 레벨 합)이 증차 상한·냉장 해금·의뢰 슬롯을 연다.
