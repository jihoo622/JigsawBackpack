# JigsawBackpack 게임 기획서

## 1. 게임 개요

기차를 타고 여러 지역을 오가며 물건을 거래하는 인벤토리 관리 게임이다. 플레이어는 제한된 격자 공간에 화물을 배치하고, 지역별 공급·수요와 이동 시간·비용을 비교해 자금을 모은다.

| 항목 | 내용 |
|---|---|
| 핵심 플레이 | 화물 배치·회전, 시장 거래, 인접 시너지, 교역 경로 선택 |
| 기본 조작 | 마우스·키보드 |
| 지도 규모 | 생산 5개 지역 21개 마을 + 수도권 5개 + 일반 마을 4개, 양방향 연결 44개 |
| 시작 지점 | 공업 지역 5개 마을 중 한 곳 |
| 상환 목표 | 공업에서 출발해 2주 안에 수도권 금융마을에서 채무 전액 상환 |
| 지도 표현 | 지역별 색 노선과 원형 역 표식을 사용하는 지하철 노선도 |

이 문서는 게임의 목표·규칙·플레이 경험을 정의한다. 수치는 밸런스 조정 전 초안이며 설계 미정 사항은 10장에 모은다.

### 기획 의도

- 공간 관리: 한정된 화물칸 안에서 적재량과 유리한 인접 배치를 선택한다.
- 지역 교역: 같은 상품도 지역과 마을에 따라 다른 가격을 갖도록 한다.
- 경로 선택: 가까운 이동의 편의와 먼 이동의 시간·운송비·가치 변화를 비교하게 한다.
- 확장 판단: 증차에 쓸 자금과 최종 목표에 남길 자금 사이에서 선택하게 한다.

## 2. 플레이 흐름과 완료 조건

1. 현재 마을의 시장에서 품목·가격과 기차의 빈 공간을 확인한다.
2. 화물을 구매하고 회전·배치해 적재 공간과 시너지를 조정한다.
3. 노선도에서 직접 연결된 목적지의 수요·시간·이동 비용을 확인한다.
4. 이동 비용을 지불하고 경과 시간과 화물 가치 변화를 반영한다.
5. 도착 시장에서 판매·재구매하거나 화물칸을 증차한다.
6. 기한 안에 수도권 금융마을에서 채무 전액을 상환한다.

### 상환과 승패

- 잠정 출발지는 공업 지역의 에른아 공업역이다. 공업 5개 마을 중 선택·무작위 출발은 별도 검토하며, 한 판의 기한은 14일(336시간)이다.
- 수도권 금융마을에서 기한 안에 채무 전액을 상환하면 승리한다. 일찍 도착해도 상환할 수 있다.
- 도착만으로 자동 상환되지 않으며 플레이어가 상환을 선택한다.
- 기한까지 갚지 못하면 게임 오버다. 336시간 시점의 상환은 허용한다.
- 이동 비용 부족은 해당 이동을 차단하며 자금 부족 자체를 즉시 패배로 처리하지 않는다.

## 3. 지역과 마을

### 지역별 생산 구조

지역의 대표 특산품과 생산 가능한 품목을 구분한다. 마을은 해당 지역의 생산 후보 안에서 주력 특산품을 갖는다. 수도권은 생산 지역 대신 수입·집산 거점으로 취급한다.

| 지역 | 대표 지역 특산품 | 생산 후보·역할 | 마을 구성 |
|---|---|---|---|
| 광산 지역 | 금속 + 광물 | 금속·광물·소금 | 라센턴·리오브루크·카르카·다르안 |
| 목축 지역 | 동물 | 고기·동물 | 다르폴·헤일하임·오스그라드·라센폴 |
| 공업 지역 | 기계 | 기계 | 에른아 공업역·노르노바·헤일포드·카르포트·포르베르 |
| 수도권 | 없음 | 수입·집산 중심 | 아이포트 중앙·디아안·트렌포드·세르그라드·금융마을 |
| 해안 지역 | 생선 | 생선·물 | 피오아 항·테라티아·발렌리에·테라카 |
| 농업 지역 | 과일 | 곡물·과일·목재 | 이브트·테라폴·다르트·베르스카 |
| 일반 마을권 | 없음 | 특화 없음·일반 물가 | 테라그라드·세르아·오스베르·메르트 |

공업·수도권은 각각 5개, 광산·목축·해안·농업은 각각 4개 마을이다. 일반 마을 4개는 공업과 수도권 사이에 띄엄띄엄 배치하며 생산 특화·흔함·귀함 없이 기본 거래 배율과 일반 물가를 사용한다. 기존 상점 틀을 재사용해 집산품·수입품·랜덤 재고를 제공한다. 별도 지역 물가 할증은 두지 않는다. 수도권 5곳은 같은 규칙을 쓰며 전 품목 기본 배율이 구매·판매 125%이고, 일반 마을은 100%다.

마을 이름은 레일 생성 데이터(seed 20265146)의 역 이름을 그대로 쓴다. 저장소의 마을 ID는 이전 지도의 것을 유지하므로 표시 이름과 ID는 따로 관리하고, 같은 이름이 다른 ID에 붙을 수 있다.

농업은 저지대, 목축은 고지대라는 배치 콘셉트이며 고도에 따른 별도 효과는 없다. 지도는 실제 대한민국 철도망을 재현하지 않는 교역용 도식이다.

### 이동 시간의 기준

소요 시간은 지도에 표시하는 선의 전체 구간 길이에 따라 정한다. 역 위치나 경유점·선 모양을 바꾸면 이동 시간도 달라진다. 같은 선 길이를 요금용 거리 산출에도 사용하며 화면 확대율과 교차점의 표시 틈은 계산에 영향을 주지 않는다. K는 아직 검증되지 않은 임시값이므로 문서 전체가 예비치 상태다.

`소비 시간(시간) = 폴라인 실합계 ÷ K`, **K는 임시값 28픽셀/시간**

| 연결 성격 | 소요 시간 산출 |
|---|---|
| 지역 내·근접 연결 | 노드 간 거리가 가까워 통상 짧은 시간 구간이 나오고, 일출 18시간 동안 3개 안팎을 연달아 지나가도 여유가 있을 정도로 걸린다 |
| 장거리 간선 | 하루를 넘기거나 야간에 걸칠 수 있는 장거리 직통이 나올 수 있다 |
| 최장 직통 | 전체 경로에서 가장 먼 단일 레일로 도착이 밤 시간대일 수 있다 |

직통이 없으면 연결된 지역·마을을 거치며 각 구간 소요 시간을 합산한다. 소요 시간과 운송비 산정용 거리의 환산 기준은 별개 축으로, 두 값을 한 노선에서 서로 다르게 둘 수 있고 각각 조정 가능하다.

### 중심 길과 분기

레일 생성 데이터(seed 20265146)의 43개 철도를 유지하고, 공업 지역 카르포트와 가장 가까운 공업역 포르베르를 잇는 왕복 노선 한 개를 추가해 총 44개 철도를 쓴다. 두 갈래 간선이 지도를 관통한다.

- 교역 간선: 에른아 공업역 → 라센턴 → 피오아 항 → 이브트 → 아이포트 중앙 → 금융마을. 긴 지역 간 구간과 수도권 내부 구간의 소요 시간은 각각의 폴라인 길이로 정한다.
- 통과 간선: 에른아 공업역 → 테라그라드 → 세르아 → 오스베르 → 메르트 → 금융마을. 일반 마을 4개가 정차점이다. 앞 3구간이 통과 간선이고 오스베르 이후 2구간은 권장 교역에 속한다.

나머지 34개는 지역 허브와 마을을 잇는 보조선과 허브 내부 연결이다. 차수 1인 막다른 역을 왕복으로 두 번 지나가면 왕복 양 끝 구간의 실합계가 더해져 왕복 2회에 상응하는 시간 비용이 쌓이고, 왕복 모두 같은 비율 K(잠정 28픽셀/시간)로 계산된다.

| 공업 출발 마을 | 금융마을까지 최단 시간(거리 비례식 적용 후 확정, 확정 전 잠정) |
|---|---|
| 카르포트 | 25시간 52분(잠정) |
| 에른아 공업역 | 35시간 28분(잠정) |
| 노르노바 | 37시간 50분(잠정) |
| 헤일포드 | 41시간 35분(잠정) |
| 포르베르 | 30시간 21분(잠정) |

표의 시간은 K=28로 이동만 합산한 잠정 경로 설계 기준이며 대기·거래·자금은 포함하지 않는다. 단일 레일은 3시간 41분~20시간 37분으로 산출된다. 하루는 일출 18시간과 야간 6시간으로 구성하고, 역 방문 횟수의 별도 상한은 두지 않는다. 일출 안의 연속 정차 수와 장거리의 야간 도착을 거리 비례로 유도한다. 14일(336시간) 기한과 막다른 역 왕복·자금 압박을 함께 조정하며, 모든 마을 순회를 강제하지 않는다. 원본 데이터의 권장 동선과 도착 수치는 새 비율·야간 대기에 따른 플레이 검증 전까지 확정하지 않는다.

### 근거리 교역 제한

같은 특산품 마을끼리 연결할 수 있다. 대신 지역 내부에서 공급과 수요가 바로 맞물리는 연결은 제한한다.

- 고정 재고·지역 재고 중 출발지의 흔한 품목 또는 지역 대표 특산품에 해당하는 보장 공급을 확인한다.
- 해당 물건이 이웃 마을에서 귀한 품목으로 판정되면 두 마을을 직접 잇지 않는다. 어느 한 방향이라도 해당하면 제한한다.
- 복수 태그 상품은 실제 거래와 같은 합산 배율로 판정한다. 단순히 대표 태그 이름 하나만 비교하지 않는다.
- 우연히 재고로 들어온 일반 랜덤 수입품 전체를 그 마을의 생산 공급으로 취급하지는 않는다.

## 4. 아이템과 태그

- 송아지는 번식으로만 얻을 수 있다. 가로 2칸, 세로 1칸을 차지하며 기본 가치는 40원이다. `Animal`과 `Baby`(애기) 태그를 가지며 소와 같은 규칙으로 배설물을 만든다. `Baby` 태그가 있는 동물은 도축할 수 없다. 송아지는 시장 재고에 등장하지 않으며 판매한 송아지도 시장 진열에 남지 않는다.
- 송아지는 보유 48시간 후 같은 객차에서 소가 된다. 성체 모양이 들어갈 자리가 없으면 성장은 마지막 1시간에서 대기하고 이동·휴식 등 게임 진행은 막히지 않는다. 자리가 생긴 뒤 1시간이 더 지나면 소가 된다.

### 아이템 테마

기본 상품 테마는 기계·생선·과일·소금·동물·목재·곡물·물·금속·상자·고기의 11개다. 상품마다 기본 가치와 점유 모양이 있으며 같은 종류라도 각 화물의 실제 가치는 따로 누적된다. 같은 테마에도 모양과 태그가 다른 상품을 둘 수 있다. 과일 상자와 한 칸 사과처럼 같은 테마의 여러 상품이 일반 재고 후보로 등장할 수 있다.

### 태그 규칙

시너지용과 거래용 분류를 별도 체계로 나누지 않는다. 하나의 상품이 복수 태그를 가지며 같은 태그를 배치 효과와 가격 판정에 함께 사용한다.

| 예시 상품 | 보유 태그 |
|---|---|
| 기계 프레임 | 기계·금속 |
| 과일 상자 | 화물·음식·과일 |
| 곡물 포대 | 음식·보급품·곡물 |
| 고기 포장 | 음식·고기 |
| 빈 상자 | 화물·상자 |

‘화물’ 같은 넓은 공통 태그와 거래 품목으로서의 ‘상자’는 같은 태그가 아니다. 한 상품이 여러 가격 조건에 맞으면 일치한 규칙을 모두 적용한다. 각 규칙의 (배율 − 100%)를 마을 기본 배율에 더하는 합연산이며 구매와 판매를 따로 계산한다. 예를 들어 기본 가치 10인 상품이 금속·기계 태그를 갖고 그 마을이 금속 110%·기계 90%라면 100% + 10% − 10% = 100%로 10이 된다. 최종 배율은 0 이하가 될 수 있다. 판매 배율이 음수면 팔 때 그만큼 돈을 내고, 구매 배율이 음수면 살 때 돈을 받는다.

## 5. 시장과 공급·수요

### 시장 재고

| 구분 | 수량 | 구성 방식 |
|---|---:|---|
| 마을 특산품 | 3개 | 해당 마을의 주력 품목을 고정 배치 |
| 지역 특산품 | 1개 | 소속 지역의 대표 특산품 후보에서 추첨 |
| 일반 랜덤 상품 | 2개 | 마을의 후보 목록에서 추첨 |
| 합계 | 6개 | 시장 보드에 사전 정의된 영역 사용 |

수량은 서로 다른 종류 수를 뜻하지 않는다. 마을 특산품과 지역 특산품이 같으면 같은 테마의 상품이 4개 나올 수 있다. 랜덤 후보는 중복 추첨할 수 있다. 수도권과 일반 마을은 특산 생산이 없으므로 고정 집산품 3개·수입품 1개·랜덤 2개를 사용한다.

### 흔함·귀함·희귀

- 흔함: 해당 마을의 주력 특산품 태그에 유리한 구매·판매 배율을 부여한다(판매 70%).
- 귀함: 생산 지역별로 정한 태그를 각 마을에 적용한다(판매 130%). 공업은 음식·금속·목재, 광산은 음식·기계·물, 목축은 금속·곡물, 농업은 기계·금속, 해안은 금속·곡물·목재·기계다. 수도권과 일반 마을은 기존 규칙을 유지한다.
- 희귀: `Map Editor`에서 마을별로 지정하는 등급으로 기본 대비 +50%를 구매·판매에 대칭으로 반영한다(구매·판매 모두 150%). 같은 태그의 기존 등급(흔함·귀함·일반)을 교체해 지정하고 행의 구매 배율도 150%로 맞춘다. 현재 흔함인 마을 특산 태그는 흔함 검증과 충돌하므로 희귀로 바꾸지 못한다.
- 일반: 해당 상품의 태그에 적용할 가격 규칙이 없으면 마을의 기본 배율을 사용한다.
- 한 마을의 같은 태그에는 행이 하나뿐이라 여러 판매 등급을 겹쳐 등록하지 않는다. 서로 다른 태그가 여러 개 일치하면 각 (배율 − 100%)를 기본 배율에 더한다. 흔함·귀함·희귀가 함께 일치하면 세 보정값을 모두 더하고, 같은 등급이 두 태그로 일치하면 두 번 더해진다.

예를 들어 공업 지역 카르포트의 흔함은 기계이고 귀함은 음식·금속·목재다. 기계와 금속 태그를 함께 가진 화물은 흔함과 귀함의 보정을 모두 받는다. 희귀 태그가 하나만 일치하고 다른 보정이 없으면 구매·판매 배율은 모두 150%지만, 기본이 125%인 수도권에서는 구매·판매 모두 175%가 된다. 수요는 재고 추첨과 무관하게 유지한다.

### 재입고

- 시장을 처음 만들 때 지역 상품과 일반 상품을 추첨한다.
- 마을을 떠날 때 출발 시장만 같은 구성 규칙으로 재생성한다. 도착 시장을 이동 순간 다시 뽑지는 않는다.
- 재입고된 물건은 새 화물이며 이미 산 기차 화물을 시장으로 되돌리지 않는다. 같은 종류가 반복 입고되는 것은 허용한다.
- 기차의 물건·배치·회전·실제 가치는 이동 후에도 보존한다.

## 6. 인벤토리와 시너지

### 공간 관리

기차는 5×5 화물칸으로 시작하고 증차하면 같은 크기의 칸이 추가된다. 마을 시장은 7×6이다. 화물은 여러 칸을 차지할 수 있고 90도 단위로 회전한다. 모든 점유 칸이 보드 안에 들어가고 다른 화물과 겹치지 않아야 한다.

화물칸마다 인접 시너지를 독립적으로 계산한다. 서로 다른 화물칸 사이에는 시너지가 없지만 이동 적재 요금은 모든 화물칸의 점유량을 합산한다. 

기차의 다른 화물칸으로도 무료로 옮길 수 있다. 화물을 잡은 채 다른 칸을 선택해 배치하거나 화물칸 버튼에 놓으면 빈자리를 찾아 옮긴다. 위치 맞교환은 제공하지 않는다.

### 가치 변화

- 같은 보드에서 상하좌우로 접한 서로 다른 화물에 시너지를 적용한다.
- 같은 이웃과 여러 면이 접하면 닿은 면 수만큼 효과를 받는다. 예를 들어 기계 프레임의 오목한 칸에 넣은 한 칸 화물은 3면이 닿아 효과를 세 번 주고받는다. 같은 종류의 다른 화물이 각각 이웃이면 따로 계산한다. 화면에는 면마다 화살표를 그리고 툴팁은 이웃별로 "×N면"과 합계를 표시한다. 냉장 프레임의 유통기한 감소만은 여러 면이 닿아도 프레임당 한 번이다.
- 시너지와 역시너지를 구분하지 않고 모든 효과의 (배율 − 100%)를 더한다(합연산). `시너지 계산값 = 기본 가치 × (100% + 효과 합)`이며 하한 없이 음수가 될 수 있다.
- 게임 시작부터 6시간마다 기차 화물의 시너지를 한 번 정산한다. 06:00 시작이면 12:00·18:00·00:00·06:00에 적용한다. 시작 순간에는 적용하지 않는다.
- 이동·휴식·아침 대기가 같은 정산 주기를 공유한다. 경계에 도달하기 전에는 비례 적용하지 않고, 한 행동에서 경계를 여러 번 넘으면 그 횟수만큼 적용한다. 배치 변경·구매·도착은 정산 시각을 초기화하지 않는다.

`정산 횟수 = floor(행동 후 경과 분 / 360) − floor(행동 전 경과 분 / 360)`

`정산 후 실제 가치 = 정산 전 실제 가치 + (해당 시각 배치의 시너지 계산값 − 기본 가치)`

행동 중 배설·식품 만료·성장·출산으로 배치가 달라지면 이후 정산은 바뀐 배치를 사용한다. 같은 시각에는 정산·배설·식품 만료·성장·출산 순으로 처리한다. 3시간 이동 후 3시간을 쉬면 총 한 번 정산한다. 정산 경계에 도착하는 행동에도 그 회차를 포함한다. 시장의 실제 가치에는 이 주기 정산을 적용하지 않는다. 시장 보드에도 같은 인접 시너지가 화살표로 표시되지만 시장 화물의 실제 가치는 바뀌지 않으므로 가격에 영향을 주지 않는다.

호버 정보는 해당 이동의 예상 정산 횟수와 도착 후 실제 가치를 표시한다. 구매 후 보유 시간은 별도로 분 단위로 추적한다. 초안에서는 실제 가치의 소수 변화량을 그대로 누적하고 0으로 제한하지 않아 음수를 허용한다. 음수 판매는 그 절댓값만큼 자금을 지불하는 처분이며 자금이 부족하면 거절한다. 처분한 화물은 시장에 남지 않고 즉시 사라져 다시 살 수 없다.

판매한 화물은 누적된 실제 가치와 신선도를 그대로 지닌 채 그 시장에 남는다. 다시 사면 그 상태 그대로 사며 구매가도 그 실제 가치를 기준으로 한다. 출발할 때 그 시장이 재입고되면 사라진다. 별도 하한·상한·누적 반올림 정책의 도입은 추후 검토한다.

### 내구도와 동물

- 음식은 기차에 보관하는 동안 유통기한을 소모한다. 신선도 %는 음식별 보관 시간의 6시간 경계까지 소모한 유통기한을 반영한다. 유통기한을 모두 소모하면 그 자리에서 한 칸짜리 똥으로 바뀐다(동물의 똥과 같은 품목·효과). 재배치·판매·구매 시 유통기한 진행을 보존한다.
- 냉장 프레임은 같은 객차에서 상하좌우로 맞닿은 음식의 유통기한 소모율을 개당 50% 낮춘다. 같은 프레임과 여러 면이 닿아도 한 번만 계산한다. 프레임 한 개가 6시간 내내 인접하면 유통기한은 3시간 줄고, 합계가 100% 이상이면 줄지 않는다.
- 화물의 시작 내구도는 100이다. 유통기한이 없는 음식의 신선도 표시는 내구도를 사용한다. 충격과 내구도 보호는 별도 검토안이다.
- 이동·휴식·아침 대기가 자정을 넘을 때마다 동물 한 마리당 한 칸짜리 똥 하나를 그 동물이 있는 객차에 놓는다. 같은 행동에서 여러 자정을 넘으면 경계마다 처리한다. 빈자리가 없거나 기한이 지났으면 해당 생성을 생략한다.
- 똥의 기본 가치는 −10이다. 똥과 동물의 영향도 시너지이며 다른 시너지와 같이 6시간 정산마다 누적된다. 똥 하나는 상하좌우로 맞닿은 화물에 −50%를 더하며 가축(동물)은 똥의 영향을 받지 않는다. 동물 한 마리는 맞닿은 `Cargo` 화물에 −10%를 더한다. 다른 효과가 없는 화물이 똥 하나와 계속 맞닿아 있으면 정산마다 기본 가치의 절반씩, 똥 두 개면 기본 가치 전부, 세 개면 1.5배를 잃어 실제 가치가 0을 지나 음수가 된다. 똥 자체는 시너지 대상에서 제외한다. 음수 판매는 처분 비용을 내며 농업의 비료 매입은 확장안이다.
- 같은 객차에서 성체 소 두 마리가 상하좌우로 맞닿아 48시간을 보내면 송아지 한 마리를 낳는다. 송아지는 성체가 된 뒤부터 쌍을 맺을 수 있다. 한 마리는 한 쌍에 속하고, 시간이 흐르기 전에 같은 쌍을 다시 붙이면 진행도를 유지한다. 분리된 상태로 시간이 흐르면 초기화한다.
- 새끼는 부모 객차의 빈자리에 놓는다. 공간이 부족하면 해당 회차를 건너뛰며, 쌍이 계속 맞닿으면 다음 48시간 주기를 시작한다.
- 현재 소금은 음식의 가치에 +20% 효과를 주며 생선 내구도 보존 효과는 없다. 상자의 내구도 보호도 별도 검토한다.

## 7. 가격과 운송 비용

### 구매·판매 가격

| 구분 | 구매 배율 | 판매 배율 |
|---|---:|---:|
| 흔함 | 80% | 70% |
| 일반 | 100% | 100% |
| 귀함 | 150% | 130% |
| 희귀 | 150% | 150% |

- 거래 기준 가치: `현재 실제 가치 × 신선도 구간 배율`. 새 재고의 실제 가치는 기본 가치와 같다.
- 마을 구매·판매 배율: `마을 기본 배율 + Σ(일치한 태그 규칙 배율 − 100%)`, 하한 없음
- 구매가: `거래 기준 가치 × 마을 구매 배율`
- 판매가: `거래 기준 가치 × 마을 판매 배율`

| 신선도 | 구간 배율 |
|---|---:|
| 60% 이상 | 100% |
| 20~59% | 80% |
| 1~19% | 50% |

유통기한이 없는 화물은 구간 배율 100%다. 0%가 되면 똥으로 바뀐다.

백분율은 계산 시 각각 100으로 나눈다. 모든 배율을 적용한 최종 금액만 정수로 반올림하고 정확히 중간이면 0에서 멀어지는 방향으로 처리한다. 구매 허용·판매 허용 여부는 마을마다 설정할 수 있다.

위 표는 일반 마을 기준이며 흔함·귀함·희귀는 기본 배율에 각각 −20%/−30%, +50%/+30%, +50%/+50%를 더하는 규칙이다. 희귀는 구매·판매 대칭 +50%다. 수도권은 기본 배율이 125%라 가치 100을 기준으로 일반 상품은 구매 125·판매 125, 귀한 상품은 구매 175·판매 155, 희귀 태그만 일치하면 구매 175·판매 175가 된다. 실제 가치는 거래 과정과 시간 경과에 따라 달라질 수 있다.

별도 공통 구매 할증을 추가할지는 미정이다. 이 초안의 구매가에는 추가 할증을 곱하지 않는다.

거래 숙련 이득(11장 거래 숙련과 평판)은 위 배율을 모두 적용한 최종 금액에 곱한다.

### 이동과 시간

`소비 시간(시간) = ceil(지도에 표시하는 선의 전체 길이 ÷ K)`(K는 임시값 28지도 단위/시간이며, 플레이 검증 전에 확정치로 대체한다). 이동은 정시간 단위로 걸리며 25시간 44분 거리는 26시간을 쓴다.

`이동 비용 = 노선 기본요금 + 노선 거리 × 거리 단가 + 전체 기차 점유 칸 수 × 적재 단가`

출발 직전에 비용을 다시 확인하고 차감한다. 자금 부족·연결 없음·계산 범위 초과 등으로 이동이 실패하면 도시·시간·화물 가치·시장·자금을 보존한다. 게임 내 시간은 이동 확정 시 즉시 증가하며 같은 길이의 실제 대기를 요구하지 않는다. 이동 횟수는 한 구간당 1회, 경과 시간은 해당 구간의 소비 시간만큼 증가한다.

| 술집 | 지도 전체의 미방문·판매 허용 마을에서 고가 수요의 마을·품목 조합을 같은 확률로 하나 선택. 방문당 한 번 듣고 대화 버튼 비활성화. 들은 소식은 우측 접이식 소문 로그에 기록하고 새 마을 도착 시 다시 대화 가능 |
| 휴식 | 정해진 시간만큼 보내기 또는 야간에 다음 일출까지 대기. 일반 휴식 간격은 잠정 60분 |
| 다른 역으로 이동 | 노선도를 열어 직접 연결된 목적지 선택 |
| 화물 드래그 | 같은 보드 안 이동 또는 기차↔시장 구매·판매 |

| 상환 버튼 | 목표 마을에서 기한·자금 조건 충족 시 상환·승리 |

즉시 거래는 현재 회전으로 왼쪽 위부터 빈자리를 찾고, 없으면 나머지 회전도 순서대로 확인한다. 같은 보드 안 이동은 무료다. 공간·자금·거래 허용 조건이 맞지 않으면 물건과 자금을 보존한다.

노선도는 어두운 배경에 생산 5개 지역과 수도권의 6색·일반 마을 회색 노선·흰색 지역 간 연결선·원형 역 표식을 사용한다. 지역 간 연결역은 큰 이중 링으로 구분하고 선은 수평·수직·45도로 정리한다. 현재 역에서 직접 갈 수 있는 노선에만 소비 시간을 표시한다. 선택·호버한 다른 역의 노선은 시간 표시 대상으로 추가하지 않는다. 선 위 숫자는 소비 시간이며, 선이 꺾이는 점이나 역 표식 없는 교차점은 별도 역·환승 지점이 아니다.

마을 이름·연결·방문 여부와 지역 이름은 처음부터 표시하고, 전 품목 배율·특산품·흔함·귀함 등 교역 정보는 방문 후 공개한다. 술집에서는 지도 전체의 미방문 마을에 대한 고가 수요 소식을 별도로 들을 수 있다. 소문을 들은 대상 마을은 지도 이름 옆에 `?`로 미확인 정보임을 표시하고, 마우스를 올리면 해당 마을에 대해 들은 소문의 날짜·시간, 들은 장소와 내용을 보여준다. 소문만으로 그 마을의 전체 교역 정보를 공개하지 않는다. 방문 후에는 `?`를 없애고 확인된 교역 정보를 표시하며, 기존 소문은 로그에 보존한다. 소식은 우측에서 접고 펼치는 대화 로그에 `들은 게임 날짜·시간 - 들은 마을 - 소문 내용` 순서로 기록한다. 들은 순서대로 쌓고 새 기록은 맨 아래에서 확인하며 이전 기록은 스크롤로 조회한다. 접어둔 패널은 새 소문을 들어도 자동으로 펼치지 않는다. 지도와 역 화면은 같은 로그를 사용하고 재시작하면 기록은 초기화한다. 로그는 우측 영역만 차지하며 나머지 화면 조작을 막지 않는다. 지도는 처음 열 때 전체 보기로 맞추고 같은 플레이에서 다시 열 때 확대 배율과 지도 이동 위치를 유지한다. 전체 보기와 현재 위치 버튼은 명시적으로 화면을 이동한다. 지도에는 직접 연결된 목적지만 이동 대상으로 제공한다. 역을 누르면 "이동하시겠습니까?" 확인창에서 확인·취소를 선택한다. 취소하면 도시·시간·자금은 유지한다. 확인하면 기차 이동 연출을 보여주고, 연출 완료 시 이동을 한 번 확정한 뒤 도착을 표시하고 지도를 닫는다. 확인창·이동 연출 중에는 중복 이동과 지도 조작을 막는다. 지도 열림 중 배경 드래그·즉시 거래를 차단한다. 승리·기한 초과 패배 모두 결과 패널을 열어 시간을 멈추고 인벤토리 입력을 비활성화하며 재시작·종료를 제공한다.

시간은 06:00부터 시작한다. 이동 소요 시간은 시간 단위로 올림하고 표시·가치 누적·보유 시간에 같은 시간을 쓴다. 시계와 기한은 분 단위를 유지한다. 야간에는 시장 구매·판매·시장 내 재배치를 막고 기차 내 조작과 이동은 허용한다. 휴식은 시계·보유 시간과 기한 판정을 진행하며 이동 요금·이동 횟수·시장 재고는 바꾸지 않으며 6시간 경계를 넘으면 시너지를 정산한다. 아침 대기는 다음 06:00까지 진행한다. 호버 미래 가치는 지도에서 이동할 역을 선택했을 때만 해당 목적지 기준으로 계산하며, 선택하지 않았으면 표시하지 않는다. K와 경제 수치는 플레이 검증 전까지 잠정치다.

## 9. 기획 범위

보드 거래·증차·복수 태그·인접 시너지·지역형 노선도·시간 소비·2주 상환 목표를 한 판의 핵심 경험으로 삼는다.

전투·온라인 멀티플레이·실제 기차 주행 시뮬레이션은 이 기획 범위에 포함하지 않는다. 술집 의뢰는 교역을 돕는 보조 수입으로 포함하며 규칙은 11장에 정리한다. 이어지는 퀘스트라인은 이후 확장으로 둔다.

## 11. 확장 기획 검토안

다음 항목은 교역·배치·경로 선택을 확장하는 설계 후보다. 채택 여부와 구체 규칙을 결정하기 전까지 앞 장의 기본 규칙을 대체하지 않는다.

### 배치의 두 가지 재미

모양을 빈틈없이 끼워 넣는 공간 퍼즐과 물건 간 상호작용을 설계하는 재미를 함께 추구한다. 상품의 모양·크기 다양성과 인접 효과의 선택을 함께 검토한다. 어느 쪽에 더 비중을 둘지는 미정이다.

### 내구도와 인접 효과

동물의 이동으로 인한 내구도 감소, 상자의 지탱과 소금의 절이기에 따른 내구도 보호, 농업 마을의 비료 매입은 확장안이다. 내구도와 가치의 관계 및 기존 가치 시너지와의 병행 여부는 미정이다.

### 전용 화물칸과 운송 특화

냉장칸으로 신선 식품의 부패 속도를 낮추거나, 유조차로 위험 액체·가스, 물탱크칸으로 물을 운송하는 안을 검토한다. 특정 품목에 집중하는 전문 운송과 다양한 품목을 다루는 잡화 운송 사이에 선택을 주는 것이 목적이다. 전용칸의 구매 비용·적재 제한·효과 범위와 일반칸과의 관계는 미정이다.

### 술집 의뢰

술집에서 의뢰를 받아 교역 외의 보조 수입을 얻는다. 지금은 단발 의뢰만 다루고, 이후 의뢰를 이어 퀘스트라인으로 확장할 수 있게 구성한다.

| 항목 | 결정 |
|---|---|
| 의뢰 종류 | 운송 의뢰: 의뢰 화물을 받아 지정 마을에 전달하고 보상을 받는다. 납품 의뢰: 지정 물품을 구해 의뢰 마을에 납품하고 보상을 받는다 |
| 수주 | 술집에서만 받는다. 마을 방문마다 의뢰가 새로 걸리고, 같은 방문에서는 목록이 유지된다. 수락한 의뢰는 우측 소문 로그 옆 탭에 목록으로 표시한다 |
| 의뢰 화물 | 일반 화물처럼 기차 칸을 차지하고 인접 시너지·유통기한·거래 숙련을 똑같이 적용받는다. 의뢰를 받은 마을에서 얻은 화물로 본다. 의뢰 전용 태그로 구분한다. 시장 재고로는 나오지 않는다 |
| 지도 표시 | 진행 중 의뢰의 목적지 역은 지도에서 전용 색 링과 이름 옆 의뢰 표식으로 표시하고, 표식에 남은 시간을 보인다. 같은 목적지 의뢰가 여럿이면 건수와 가장 급한 남은 시간을 보인다. 역에 마우스를 올리면 의뢰 화물·남은 시간·보수를 보인다 |
| 판매·폐기 | 의뢰 화물도 팔거나 버릴 수 있다. 그러면 화물이 사라지므로 그 의뢰는 실패한다. 유통기한이 다해 똥이 된 경우도 같다 |
| 완료 | 목적지 마을에 도착하면 자동으로 완료한다. 화물을 내리고 보상 + 도착 시 화물의 실제 가치 + 맡긴 보증금을 받고, 의뢰 화물의 생산 태그에 숙련 경험치를 받는다. 화물에 생산 태그가 없으면 의뢰 틀에 지정한 태그로 받는다 |
| 동시 진행 | 처음에는 1개다. 평판(숙련 레벨 합)이 오르면 동시에 여러 개를 진행할 수 있다 |
| 실패 패널티 | 의뢰마다 패널티 유형을 지정한다. 후보는 보증금 몰수, 해당 지역 거래 불이익, 받은 보상이 이후 문제를 일으키는 경우 등이다. 실패해도 숙련·평판은 줄지 않는다 |

### 거래 숙련과 평판

교역할수록 다루는 품목에 숙련이 쌓이고, 숙련이 거래 이득과 평판이 된다. 성장해 사업 규모를 키운다는 감각을 주는 것이 목적이며 이득 자체는 작게 둔다.

| 항목 | 결정 |

| 경험치 | 다른 마을에서 얻은 화물을 팔면 판매 금액에 비례해 얻는다. 얻은 마을에서 팔면 얻지 않는다. 도축·정제 등 작업대 산출물은 만든 마을, 의뢰 화물은 의뢰를 받은 마을에서 얻은 화물로 본다. 생산 태그가 여럿이면 경험치를 나눠 준다. 구매로는 얻지 않는다 |
| 레벨 | 누적 경험치 기준으로 오르며 상한이 없다 |
| 거래 이득 | 레벨당 일정 비율만큼 최종 구매가를 깎고 최종 판매가를 올린다. 생산 태그가 여럿이면 가장 높은 레벨 하나를 쓴다. 상한이 없다 |
| 구매 취소 | 같은 방문 중 산 마을에 되팔면 구매 취소로 처리해 낸 금액을 그대로 돌려받는다. 숙련 이득·경험치는 없다. 유통기한이 다해 다른 품목이 되었으면 취소가 아닌 일반 판매다. 마을을 떠났다 돌아오면 일반 판매로 숙련 이득은 받지만 경험치는 없다 |
| 평판 | 모든 숙련 레벨의 합이다. 따로 쌓거나 깎지 않는다 |
| 의뢰 보상 | 평판 대신 의뢰 화물의 생산 태그에 숙련 경험치를 준다. 생산 태그가 없는 화물의 의뢰는 의뢰 틀에 경험치를 받을 태그를 지정한다 |
| 의뢰 실패 | 숙련·평판은 줄지 않는다. 의뢰에 지정된 보증금 몰수 또는 지역 거래 불이익(72시간)만 적용한다 |

잠정 수치(플레이 검증 전)는 다음과 같다.

| 항목 | 잠정값 |
|---|---|
| 판매 경험치 | 판매 금액 1당 1 |
| 레벨 기준(누적) | 50·150·350·700·1200, 이후 500마다 1레벨 |
| 거래 이득 | 레벨당 0.5% |
| 의뢰 경험치 | 의뢰 보상 금액 1당 1 |
| 동시 의뢰 수 | 평판 0·4·8에서 1·2·3개 |

미정 사항은 다음과 같다.

- 숙련을 판을 넘어 유지할지. 지금은 한 판 단위로 재시작하면 초기화된다.
- 특정 레벨에서 고유 효과(신선도 감소 완화·번식 가속·정제 산출 증가·시너지 강화 등)를 열지.
- 위 잠정 수치의 밸런스. 경험치가 이익이 아닌 판매 금액 기준이라 레벨이 예상보다 빨리 오를 수 있다.

### 이동 중 사건과 검문소

이동 시 확률적으로 긍정·부정 인카운터가 발생하는 안을 검토한다. 사건 종류·확률·선택지·시간 및 자금 영향은 미정이다. 별도로 검문소마다 금지 품목을 정하고 수량에 비례한 벌금 또는 압수를 적용하며, 다른 마을을 거쳐 우회할 수 있게 하는 안이 있다. 검사 위치·집행 조건·벌금·압수 선택 방식은 미정이다.

### 기관차 업그레이드

특정 마을에서 기관차를 업그레이드해 운송비를 절감하는 방향을 검토한다. 부정 인카운터 확률 감소는 추가 효과 후보이며 확정 효과가 아니다. 비용·단계·적용 구간과 중첩 규칙은 미정이다.

### 화물 재배치와 피드백

화물칸 사이 무료 이동은 6장의 기본 규칙에 포함한다. 다른 물건 위에 놓을 때 가능한 경우 두 물건의 위치를 맞바꾸는 편의 기능은 후순위다. 교환 시 빈 공간·회전·경계·이동 비용 처리와 실패 시 원상 보존 방식은 미정이다. 시너지 증가·감소 결과를 알아보기 쉽게 보여주는 방향도 검토하되 표시 시점과 연출은 미정이다.

### 철도 투자

비용을 투자해 원래 연결되지 않은 두 마을 사이에 철도를 건설하는 후순위 안이다. 건설 가능한 연결·투자 비용·소비 시간·새 노선의 운임·검문소 우회 허용 여부는 미정이다.

### 테마와 가격 표현

판타지·행성 간 이동·우주 해적과 정치·사회적 내러티브를 더하는 방향을 검토한다. 지역 생산·교역·배치의 기본 틀은 유지하면서 세계관을 바꿀지는 별도로 결정한다. ‘싯가’ 논의는 가격 증감 표현이 어울리는지에 대한 문제 제기 단계이며, 시세 변동 공식이나 기존 시너지 제거를 확정한 것으로 취급하지 않는다.
