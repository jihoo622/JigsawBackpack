# 현재 구현 범위

현재 유니티 프로젝트는 3D 환경이지만, 이번 게임은 2D로 구현한다.

5*5 격자 인벤토리에서 직소퍼즐 같은 블록(이하 블록)들을 배치할 수 있도록 구현한다.

## UI 구성
화면의 좌측에는 블록을 설치할 수 있는 팔레트가 있다.

우측에는 해당 블록을 조합할 수 있는 인벤토리가 있다.

## 조각 배치 규칙

1. 한 조각은 상하좌우로 연결된 하나 이상의 정사각형 슬롯으로 구성된다. 슬롯 하나가 보드 한 칸을 차지한다.
2. 슬롯의 북·동·남·서 변은 각각 `Flat`(평평함), `In`(홈), `Out`(돌출) 중 하나다. 같은 조각의 내부 연결 면은 양쪽 모두 `Flat`이다.
3. 서로 다른 조각의 인접 변에 `Out`이 있으면 반대편이 `In`이어야 한다. 양쪽에 `Out`이 없으면 허용한다. 홈과 돌출은 공용 규격을 쓴다.
4. 조각을 시계방향으로 90도씩 회전할 수 있다. 슬롯과 변 방향을 함께 회전하고, 잡은 원본 슬롯이 포인터를 따라간다.
5. 기본 슬롯은 격자 안에서 빈 칸에만 배치한다. 돌출부는 보드 경계 밖으로 나갈 수 있다.


## 인벤토리 규칙
1. 조각을 들고 포인터를 보드 셀에 올리면 후보의 외곽선에 배치 가능 여부를 표시한다.
2. 장착물은 격자의 셀 단위로만 배치할 수 있으며, 반드시 격자에 정렬되어야 한다.
3. 보드에서 일반 드래그는 조각 하나를, 좌·우 Shift를 누른 채 시작하는 드래그는 연결 묶음을 움직인다. 연결은 서로 다른 조각의 `Out`과 `In`이 인접해 맞물릴 때 생기며 연쇄적으로 이어진다.
4. 드래그 전에는 이동할 조각을 파란색으로 표시한다. 드래그 중에는 묶음 전체가 잡은 슬롯을 기준으로 움직이며, 모든 조각을 배치할 수 있을 때 한 번에 적용한다.

## 팔레트 규칙
1. 팔레트에 모양 원본이 존재하고, 해당 모양들을 끌어서 인벤토리에 장착할 수 있다.
2. 개별 조각이나 한 조각짜리 묶음을 팔레트에 돌려놓으면 해당 배치를 제거한다. 두 조각 이상인 묶음을 팔레트에 놓으면 이동을 취소한다.
3. 팔레트의 원본은 변형되지 않는다.


## 조각 데이터와 프리팹

- `Assets/Resources/Images/puzzles1.png`는 원본 7종의 실루엣 참고 자료다. 실제 형태는 `PuzzleTableData.json`의 조각 ID·슬롯 수·슬롯 좌표·네 방향 상태로 정의한다.
- 조각 좌표는 외접 사각형의 왼쪽 위에서 오른쪽과 아래로 증가한다. 보드 좌표는 왼쪽 아래에서 오른쪽과 위로 증가한다. 모델은 회전된 외접 사각형의 왼쪽 위를 기준으로 정규화한 후 보드 좌표로 변환한다.
- 슬롯은 공용 이등변 직각삼각형 `Flat`·`In`·`Out`으로 표시한다. `PuzzleSlot`의 네 Image는 슬롯 중심을 기준으로 네 방향을 향한다. 팔레트·배치·고스트·외곽선은 `PuzzleInventoryUI`에 미리 배치한 슬롯을 재사용한다.
- 외곽선은 해당 조각 안에서 맞닿는 변을 숨기고 바깥 변만 그린다. 변 끝의 둥근 마감이 겹쳐 꼭짓점에서 이어진다.
