세 축과 고정 UI

  • 화면은 세 축이다: 왼쪽 = 백팩(선택한 화물칸의 짐), 아래 = 기차(화물칸 바), 오른쪽 = 도착지(지금 역에서 할 일과 다음에 갈 곳).
  • 고정 UI: 상태 안내, 화물칸 바, 정보 바는 어떤 화면(지도·이동 확인·이동 연출·수첩·상성표)에서도 가려지지 않는다. 예외는 일시정지(전체 화면 모달)뿐이다.
  • 지도는 도착지 축을 통째로 바꾼다. 다음 목적지를 고르는 도구라 도착지 축에 속한다. 지도를 보는 동안에도 백팩과 기차가 보인다.
  • 소문·의뢰는 "다음에 갈 곳" 정보라 도착지 축 위쪽 요약 띠에 상시 보이고, 전체 기록은 접이식 수첩에 둔다. 상성·정산은 화물끼리의 규칙이라 화물칸 바 왼쪽 고정 UI에 둔다.
  • 제목: E안 3차 — 세 축 (백팩 · 기차 · 도착지)

단점·주의

  • 지도 뷰포트 축소 (현행 1824×624에서 1232×580으로 줄어 한 화면에 보이는 역 수가 줄어든다 — 전체 보기·현재 위치 버튼과 줌으로 보완).
  • 수첩을 펼치면 도착지 오른쪽 정보와 의뢰 요약이 가려진다.
  • 요약 띠의 "관련 소문" 고르기는 새 코드(시장 상품 태그와 소문 대상 매칭)가 필요하다.
  • 정보 바가 화면 맨 아래라 창 모드 작업 표시줄·스팀 오버레이 알림(기본 오른쪽 아래)과 겹칠 수 있다.
  • 지도를 보면서 기차 보드를 쓰려면 코드 수정이 필요하다(지금은 지도가 열리면 인벤토리 입력과 툴팁을 막는다).
  • 지도 역 라벨 태그 칩과 이동 미리보기는 지도 코드(PuzzleMapView, PuzzleMapPresenter) 수정이 필요하다.
  • 인접 효과 미리보기는 드래그 중 시너지 계산을 추가로 돌려야 한다(성능 확인 필요).
  • 잠긴 칸 표시는 화물칸 바 슬롯 8개를 항상 켜 두는 방식으로 바뀐다.
